000400* PROGRAMS:  EUP731 - COMPARE A CONTACT NAME                    *         
000500*                                                               *         
000600* LANGUAGE:  OS/390 COBOL                                       *         
000700*  PURPOSE:  1) COMPARE A CONTACT NAME TO ITS SELF TO DETERMINE *         
000800*               IF IT IS A VALID NAMESEARCH NAME (I.E. IT DOES  *         
000900*               NOT CONTAIN ALL NOISE WORDS.                    *         
001000*            2) COMPARE A CONTACT NAME TO ANOTHER CONTACT NAME  *         
001100*               SO THAT THE COMPARISON SCORE MAY BE COMPARED TO *         
001200*               A THRESHOLD TO DETERMINE IF THE NAME CHANGE IS  *         
001300*               VALID                                           *         
001400*                                                               *         
001500* CALL FORMAT: CALL WS-EUP731 USING EUX731-PARMS                *         
001600*                                                               *         
001700* EXAMPLE 1: DETERMINE IF A CONTACT NAME IS A VALID NAMESEARCH  *         
001800*            CONTACT NAME                                       *         
001900*                                                               *         
002000* WORKING-STORAGE SECTION.                                      *         
002100* 01  WS-EUP731                  PIC  X(08) VALUE 'EUP731'.     *         
002200*                                                               *         
002300* COPY EUX731 REPLACING ==:EUX731:== BY ==EUX731==.             *         
002400*                                                               *         
002500* PROCEDURE DIVISION.                                           *         
002600*     INITIALIZE EUX731-PARMS                                   *         
002700*     MOVE INPUT-CONTACT-NAME TO EUX731-NAME-IN-1               *         
002800*                                EUX731-NAME-IN-2               *         
002900*     CALL WS-EUP731 USING EUX731-PARMS                         *         
003000*     IF EUX731-SCORE = 100                                     *         
003100*        THIS IS A VALID NAME AND MAY BE INSERTED               *         
003200*     ELSE                                                      *         
003300*        THIS IS AN INVALID NAME AND MAY NOT BE INSERTED INTO   *         
003400*        THE DATA BASE, SEND A MESSAGE TO THE USER THAT THEY    *         
003500*        SHOULD CONTACT IT.                                     *         
003600*                                                               *         
003700* EXAMPLE 2: COMPARE A CONTACT NAME TO ANOTHER CONTACT NAME     *         
003800*                                                               *         
003900* WORKING-STORAGE SECTION.                                      *         
004000* 01  WS-EUP731                  PIC  X(08) VALUE 'EUP731'.     *         
004100*                                                               *         
004200* COPY EUX731 REPLACING ==:EUX731:== BY ==EUX731==.             *         
004300*                                                               *         
004400* PROCEDURE DIVISION.                                           *         
004500*     INITIALIZE EUX731-PARMS                                   *         
004600*     MOVE INPUT-CONTACT-NAME   TO EUX731-NAME-IN-1             *         
004700*     MOVE CHANGED-CONTACT-NAME TO EUX731-NAME-IN-2             *         
004800*                                                               *         
004900*     CALL WS-EUP731 USING EUX731-PARMS                         *         
005000*     IF EUX731-SCORE >= THRESHOLD-SCORE                        *         
005100*        THIS IS A VALID NAME CHANGE                            *         
005200*     ELSE                                                      *         
005300*        THIS IS AN INVALID NAME CHANGE, AN ERROR MESSAGE       *         
005400*        INDICATING SUCH SHOULD BE DISPLAYED.                   *         
005500*                                                               *
