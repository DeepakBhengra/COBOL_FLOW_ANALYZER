      ****************************************************************          
      *  COPYBOOK:  EDT060                                           *          
      ****************************************************************          
      *                                                              *          
      * OVERVIEW:                                                    *          
      *  USED IN SUB-ROUTINES EDV060 TO SUPPLY A CALLING PROGRAM     *          
      *  ACTIONS, DATA, AND AN AREA TO RETURN DATA AND RESULT CODE   *          
      *  INFORMATION.                                                *          
      *                                                              *          
      *     INPUT: EDV060-INPUT-DATA                                 *          
      *            - OBJECT ID                                       *          
      *            - ACTION CODE                                     *          
      *            - USER ID                                         *          
      *            - COMPANY CODE                                    *          
      *            - PARTNER ID                                      *          
      *     INPUT/OUTPUT: EDV060-INPUT-OUTPUT-ARRAY-AREA             *          
      *            - ARRAY COUNT                                     *          
      *            - EDV060-ARRAY (OCCURS UP TO 20 TIMES)            *          
      *              - EDV060-CO-CD                                  *          
      *              - EDV060-PARTNER-ID                             *          
      *              - EDV060-CREDIT-MEMO-FLG                        *          
      *              - EDV060-ASSET-TAG-FLG                          *          
      *              - EDV060-EDI-PO-FLG                             *          
      *              - EDV060-ZERO-VALUE-FLG                         *          
      *              - EDV060-REFUSAL-FLG                            *          
      *              - EDV060-COMPONENTS-FLG                         *          
      *              - EDV060-INTEREST-INV-FLG                       *          
      *              - EDV060-LST-CHG-TS                             *          
      *              - EDV060-LST-CHG-NAM                            *          
      *              - EDV060-SHIP-BR-XMIT-FLG                       *  AZS08252
      *                                                              *          
      *    OUTPUT: EDV060-OUTPUT-DATA                                *          
      *          - EDV060-ROW-COUNT                                  *          
      *          - EDV060-MODULE-RESULT-CD                           *          
      *          - EDV060-MODULE-MESSAGE                             *          
      *          - EDV060-DATABASE-RESULT-CODES:                     *          
      *              - EDV060-SQLCA VALUES                           *          
      *              - EDV060-SQLCODE                                *          
      *              - EDV060-SQLSTATE                               *          
      *                                                              *          
      *                                                              *          
      *   EDV060 EXAMPLE FOR REQUESTING A SINGLETON SELECT ACTION.   *          
      *     INITIALIZE EDV060-COMMUNICATIONS-AREA.                   *          
      *     MOVE PGM-PARTNER-ID TO EDV060-PARTNER-ID.                *          
      *     MOVE 'S ' TO EDV060-ACTION-CD.     .                     *          
      *     MOVE 'IE_MISC_CHARGES' TO EDV060-OBJECT-ID.              *          
      *                                                              *          
      *     CALL 'EDV060' USING EDV060-COMMUNICATIONS-AREA.          *          
      *     IF EDV060-STATUS-OK                                      *          
      *     THEN                                                     *          
      *          CONTINUE WITH EXPECTED PROCESSING                   *          
      *     ELSE                                                     *          
      *          CONTINUE CHECK FOR DETAILED ERROR CONDITIONS AND    *          
      *          TAKE APPROPRIATE ACTIONS.                           *          
      *                                                              *          
      *      NOTE: THIS EXAMPLE SHOWS A TYPICAL CALL FROM AN         *          
      *            APPLICATION PROGRAM. IN THIS CASE THE PROGRAMMER  *          
      *            IS REQUESTING A SINGLETON SELECT ACTION TO RETURN *          
      *            DATA FOR A PARTICULAR PARTNER_ID.                 *          
      *                                                              *          
      *            THE PROGRAMMER SHOULD ALWAYS CHECK MODULE RESULT  *          
      *            CODE RETURNED FROM EDV060 TO VALIDTE THAT IT      *          
      *            WORKED PROPERLY (SEE THE COPYBOOK EDR001 FOR A    *          
      *            LIST OF ERROR CODES).                             *
