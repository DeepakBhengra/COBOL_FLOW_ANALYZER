      *    READ CFSHED SEGMENT VIA PRIMARY KEY CONFIG ID                        
           CALL 'CBLTDLI' USING        GU                                       
                                       CFPCB-PRI0                               
                                       CFH-CFSHED                               
                                       WS-CFSHED-SSA.                           
           IF CFPCB-PRI0-NORESP                                                 
               MOVE 'Y'                TO  WS-CFSHED-IO-SW                      
           ELSE                                                                 
               IF CFPCB-PRI0-NOTFND                                             
                   MOVE 'N'            TO  WS-CFSHED-IO-SW                      
               ELSE                                                             
                   MOVE 'I010'         TO  WS-ABCODE                            
                   MOVE CFPCB-PRI0-STS TO  WS-STATUS                            
                   MOVE 'DL/1'         TO  WS-ERROR-CODE                        
                   MOVE SPACES         TO  WS-ERROR-OPTIONAL-DATA               
                   MOVE CFPCB-PRI0     TO  WS-ERROR-DL1-PCB                     
                   MOVE WS-ABCODE      TO  WS-ERROR-DL1-ABCODE                  
                   PERFORM 999-ABEND.
