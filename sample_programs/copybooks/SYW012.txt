      ***************************************************************           
      *          SYU012 CURRENCY FORMAT ROUTINE COPY BOOK           *           
      *                                                             *           
      * CURRENCY MAY BE IN SEVARAL FORMATS, SOME CURRENCY USE       *           
      * COMMA FOR THOUSANDS SEPARATOR AND PERIOD FOR DECIMAL        *           
      * SEPARATOR. THIS ROUTINE WILL:                               *           
      *   1) FORMAT CURRENCY DEPENDING ON CURRENCY CODE, IT WILL    *           
      *      DEFAULT TO DEM CURRENCY IF SYU12-CURRENCY-CODE = ' '   * JBP98170  
      *   2) NOT DISPLAY NEGATIVE SIGN IF REQUESTED, DEFAULT TO     *           
      *      DISPLAY NEGATIVE SIGN                                  *           
      *   3) SUPPRESS THOUSANDS SEPARATOR, INSTEAD OF Z,ZZZ,ZZZ.ZZ- *           
      *      IT WILL DISPLAY ZZZZZZZ.ZZ-                            *           
      *   4) IT CAN HAVE MAX OF 4 DECIMAL OR 0 DEPENDING ON         *           
      *      THE NUMBER OF DEC SPECIFIED                            *           
      *   5) IT WILL FORMAT THE OUTPUT IN THE GIVEN OUTPUT LENGTH.  *           
      *      SUPPRESS THOUSANDS SEPARATOR IF NEEDED, IT WILL ISSUE  *           
      *      A RETURN CODE "E" FOR  HIGH ORDER TRUNCATION           *           
      *   6) ZERO SUPPRESS (SYU12-ZERO-SUPPRESS-SW)                 *           
      *      DEFAULT TO 0.0000                                      *           
      *      VALUE 'A' = BLANK WHEN ZERO                            *           
      *      VALUE 'D' = .0000                                      *           
      *      VALUE '1 THRU 9' = NUMBER OF WHOLE NUMBER TO DISPLAY   *           
      *             ZERO STARTING AT THE RIGHTMOST WHOLE NUMBER     *           
      *        EX VALUE '2' = 00.0000                               *           
      *        EX VALUE '3' = 000.0000                              *           
      *   7) NOTATE SW (SYU12-NOTATE-SW)                            *           
      *      ' '  = NO NOTATION                                     *           
      *      'Y'  = ONLY IF COUNTRY ALLOWS NOTATION                 *           
      *      'A'  = NOTATE REGARDLESS OF CURRENCY                   *           
      *                                                             *           
      *  EX:  INITIALIZE SYU12-INPUT-PARAMETERS.                    *           
      *       MOVE NUMERIC-VALUE   TO  SYU12-INPUT-FIELD            *           
      *       PERFORM 9995-FORMAT-AMOUNTS.       .                  *           
      *       MOVE SYU12-OUTPUT TO DISPLAY AREA.                    *           
      *                                                             *           
      *                                                             *           
      *  NOTE: YOU CAN CHECK THE RETURN CODE FOR HIGH ORDER         *           
      *        TRUNCATION.                                          *           
      *        DISPLAY AREA MUST BE PIC X (ALPHA FIELD)             *           
      *        YOU NEED SYR012 COPY MEMBER ADDED IN YOUR            *           
      *        PROCEDURE DIVISION                                   *           
      * 06/30/04 MSI  ADD PGM NAME FIELD TO BE USED FOR DYNAMIC     *   MSI04182
      *               CALLS                                         *   MSI04182
      * 09/10/98 BAM  ADD 'PTE' AS NO DECIMAL CURRENCY              *   BAM98253
      * 06/19/98 JBP  DEFAULT IS EUROPEAN (DEM) FORMAT              *   JBP98170
      * 02/05/98 AXG  ADDED 'CLP' TO 88 LEVEL                       *   AXG98036
      * 01/17/97 KLM ADDED 'IDR' TO NO-DECIMAL-CURRENCY 88-LEVEL    *   KLM97017
      * 09/26/94 PRP NEW FIELD 'SYU012-FORCED-K-SW                  *   PRP94266
      * 09/26/94 PRP CONTIGUOUS-K ' 123,456 K123,456 K '            *   PRP94266
      *              VERSUS       ' 123,456K 123,456K  '            *   PRP94266
      * 07/22/94 RXD REMOVED SPAIN FROM RECEIVING NOTATED AMOUNTS   *   RXD94203
      ***************************************************************
