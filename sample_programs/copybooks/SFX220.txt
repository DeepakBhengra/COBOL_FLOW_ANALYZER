      * DESCRIPTION:                                                  *         
      *  THIS COPYBOOK IS USED FOR THE COMMAREA THAT IS USED          *         
      *  TO COMMUNICATE A LINE INSERT TO SFP220.                      *         
      *****************************************************************         
      * PRIMARY FIELDS OF INTEREST:                                   *         
      *                                                               *         
      *      1) SF220-LINE-TYPE-SW:                                   *         
      *         THIS SWITCH DETERMINES THE TYPE OF LINE THAT WILL     *         
      *         BE ADDED.  IN TURN, THIS SWITCH DETERMINES THE CONTROL*         
      *         PARAGRAPH THAT WILL BE EXECUTED FROM THE 2000- MODULE.*         
      *         THIS IS A MANDATORY FIELD.                            *         
      *      2) SF220-COMPANY-CODE:                                   *         
      *         THIS FIELD SPECIFIES THE COMPANY FOR THE ORDER,       *         
      *         TO WHICH THE LINE SHOULD BE ADDED.                    *         
      *         THIS IS A MANDATORY FIELD.                            *         
      *      3) SF220-SALES-BR-NBR:                                   *         
      *         THIS FIELD SPECIFIES THE BRANCH FOR THE ORDER,        *         
      *         TO WHICH THE LINE SHOULD BE ADDED.                    *         
      *         THIS IS A MANDATORY FIELD.                            *         
      *      4) SF220-ORDER:                                          *         
      *         THIS FIELD SPECIFIES THE ORDER AND SHIP HDR SEGMENTS  *         
      *         TO WHICH THE LINE SHOULD BE ADDED.                    *         
      *         THIS IS A MANDATORY FIELD.                            *         
      *      5) SF220-ISRT-LINE-SW:                                   *         
      *         THIS SWITCH DETERMINES THE LOGIC WHICH WILL BE USED   *         
      *         TO DO THE ACTUAL INSERT OF THE LINE.  IT CAN HAVE     *         
      *         FOUR VALUES:                                          *         
      *                                                               *         
      *         'R' - THIS WORKS IN CONJUNCTION WITH SF220-LINE-NBR.  *         
      *               THE LINE NUMBER SPECIFIED WILL BE DELETED, IF   *         
      *               IT EXISTS, AND THIS SAME LINE NUMBER WILL BE    *         
      *               INSERTED.                                       *         
      *         'N' - THIS WORKS IN CONJUNCTION WITH SF220-LINE-NBR.  *         
      *               THE LINE NUMBER SPECIFIED WILL BE INSERTED, BUT *         
      *               ONLY IF IT DOES NOT CURRENTLY EXIST.            *         
      *         'A' - THIS WORKS IN CONJUNCTION WITH SF220-LINE-NBR.  *         
      *               AT INSERT WILL BE ATTEMPTED ON THE SPECIFIED    *         
      *               LINE NUMBER.  IF THAT LINE ALREADY EXISTS,      *         
      *               THE PROGRAM WILL INCREMENT THE LINE NUMBER,     *         
      *               AND ATTEMPT THE INSERT AGAIN.  IT WILL DO THIS  *         
      *               UP TO 100 TIMES.                                *         
      *               THE LINE NUMBER THAT IS FINALLY INSERTED WILL   *         
      *               BE PLACED IN SF220-LINE-NBR.                    *         
      *         'H' - THIS IGNORES SF220-LINE-NBER COMPLETELY.        *         
      *               INSTEAD, IT USES ORH-LAST-LINE-NBR AS ITS       *         
      *               BEGINNING VALUE.  IT WILL INCREMENT THIS BY     *         
      *               1, AND ATTEMPT AN INSERT.  IF THE INDICATED LINE*         
      *               ALREADY EXISTS, IT WILL AGAIN INCREMENT THE LINE*         
      *               NUMBER, AND ATTEMPT AN INSERT.  IT WILL LOOP IN *         
      *               THIS FASHION UP TO 100 TIMES.                   *         
      *               THE LINE NUMBER THAT IS FINALLY INSERTED WILL   *         
      *               BE PLACED IN SF220-LINE-NBR.                    *         
      *         THIS IS A MANDATORY FIELD.                            *         
      *      6) SF220-CURRENCY-RATE:                                  *         
      *         THIS IS AN OVERRIDE RATE FOR FOREIGN ORDERS.  DO NOT  *         
      *         SET THIS, UNLESS YOU WISH TO OVERRIDE THE RATE GIVEN  *         
      *         ON ORSHED, WHICH IS THE RATE USED BY OTHER LINES ON   *         
      *         THE ORDER.  IF NOT SET, THIS FIELD WILL CONTAIN THE   *         
      *         RATE FINALLY USED, WHEN CONTROL IS RETURNED TO THE    *         
      *         CALLING PROGRAM.                                      *         
      *      7) SF220-COMMOD-CODE:                                    *         
      *         THIS IS THE MISCELLANEOUS CHARGE CODE FOR THE ORDER   *         
      *         LINE.  IT WILL BE VALIDATED AGAINST TBXMCHG.          *         
      *         IF THIS IS TO BE A MISCELLANEOUS CHARGE COMMENT LINE, *         
      *         THEN THIS IS A MANDATORY FIELD.                       *
