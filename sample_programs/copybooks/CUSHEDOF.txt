      * NOTE: THE DBA GROUP MUST BE CONTACTED IF A NEW OVERFLOW        *        
      *       SEGMENT TYPE IS TO BE CREATED. IN ADDITION, THEY         *        
      *       SHOULD BE INFORMED WHEN NEW DATA ELEMENTS ARE ADDED      *        
      *       TO EXISTING SEGMENTS. THIS IS TO INSURE THAT COLUMNS     *        
      *       ARE PROVIDED FOR THE DATA IN THE INVOICE HISTORY DB2     *        
      *       DATABASES.                                               *        
      *                                                                *        
      * CUOF-CUSHEDOF IS THE GENERIC GROUP LEVEL ITEM FOR ALL IO       *        
      * MODULES. THESE MODULES READ INTO AND WRITE FROM THIS GROUP     *        
      * ITEM.                                                          *        
      * THE ACTUAL DATA ELEMENTS ARE DEFINED IN THE OTHER LAYOUTS.     *        
      * THIS METHODOLOGY WAS ESTABLISHED TO PERMIT AVAILABILITY OF     *        
      * INFORMATION FROM MULTIPLE CUSHED OVERLOW SEGMENTS. THIS        *        
      * ELIMINATES THE NEED TO SAVE DATA IN PROGRAM SPECIFIC           *        
      * WORKING-STORAGE FIELDS AS WOULD OCCUR IF CUOF-CUSHEDOF WERE    *        
      * REDEFINED FOR OTHER SEGMENT TYPES.                             *        
      *                                                                *        
      * FOR EXAMPLE, FIELDS IN CUOF-CUSHEDOF-0 WOULD BE POPULATED      *        
      * WITH DATA, TO INCLUDE CUOF-CUSHEDOF-KEY-0 WHICH IS '0'.        *        
      * GROUP ITEM CUOF-CUSHEDOF-0 WOULD THEN BE MOVED TO GROUP        *        
      * ITEM CUOF-CUSHEDOF WHICH WOULD THEN BE WRITTEN TO THE          *        
      * DATABASE.                                                      *        
      *                                                                *        
      * THE REVERSE WOULD OCCUR DURING A READ FROM THE DATABASE. THE   *        
      * DATA WOULD BE READ INTO CUOF-CUSHEDOF AND THEN MOVED TO        *        
      * CUOF-CUSHEDOF-0 (OR OTHER LAYOUT AS REQUIRED) SO THE           *        
      * INFORMATION CAN BE USED BY THE PROGRAM.                        *        
      *                                                                *        
      * AVAILABLE SPACE THAT WOULD NORMALLY BE LABELLED AS FILLER      *        
      * WAS GIVEN A FIELD NAME (AS IN CUOF-FILLER OR CUOF-FILLER-0)    *        
      * TO FACILITATE THE USE OF THE INITIALIZE VERB. THIS VERB MOVES  *        
      * SPACES AND ZEROES TO VALID FIELD NAMES BASED UPON THEIR        *        
      * DEFINITION. IT DOES NOT MOVE SPACES TO AREAS LABELLED WITH     *        
      * THE RESERVED WORD 'FILLER'.                                    *        
      *                                                                *
