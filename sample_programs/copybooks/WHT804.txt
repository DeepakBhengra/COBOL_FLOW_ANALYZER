      ****************************************************************          
      *  COPYBOOK:  WHT804                                           *

      *                                                              *          
      * OVERVIEW:                                                    *          
      *  USED IN SUB-ROUTINES WHV804 TO SUPPLY A CALLING PROGRAM     *          
      *  ACTIONS, DATA, AND AN AREA TO RETURN DATA AND RESULT CODE   *          
      *  INFORMATION.                                                *          
      *                                                              *          
      *     INPUT: WHV804-INPUT-DATA                                 *          
      *            - OBJECT ID                                       *          
      *            - ACTION CODE                                     *          
      *            - USER ID                                         *          
      *            - COMPANY CODE                                    *          
      *            - CARRIER CODE                                    *          
      *     INPUT/OUTPUT: WHV804-INPUT-OUTPUT-ARRAY-AREA             *          
      *            - ARRAY COUNT                                     *          
      *            - WHV804-ARRAY (OCCURS UP TO 20 TIMES)            *          
      *              - WHV804-CO-CD                                  *          
      *              - WHV804-PARTNER-ID                             *          
      *              - WHV804-PARTNER-DES                            *          
      *              - WHV804-PRNT-PARTNER-ID                        *          
      *              - WHV804-ACTV-DT                                *          
      *              - WHV804-DEACTV-DT                              *          
      *              - WHV804-NOTE-TXT                               *          
      *              - WHV804-LST-CHG-TS                             *          
      *              - WHV804-LST-CHG-NAM                            *          
      *              - WHV804-PRCS-OPTN-FLG                          *          
      *                                                              *          
      *    OUTPUT: WHV804-OUTPUT-DATA                                *          
      *          - WHV804-ROW-COUNT                                  *          
      *          - WHV804-MODULE-RESULT-CD                           *          
      *          - WHV804-MODULE-MESSAGE                             *          
      *          - WHV804-DATABASE-RESULT-CODES:                     *          
      *              - WHV804-SQLCODE                                *          
      *              - WHV804-SQLSTATE                               *          
      *              - WHV804-SQL-MESSAGE                            *          
      *                                                              *          
      *                                                              *          
      *   WHV804 EXAMPLE FOR REQUESTING A SINGLETON SELECT ACTION.   *          
      *     INITIALIZE WHV804-COMMUNICATIONS-AREA.                   *          
      *     MOVE PGM-CARRIER-CD TO WHV804-CARRIER-CODE.              *          
      *     MOVE 'S ' TO WHV804-ACTION-CD.     .                     *          
      *     MOVE 'DV_INSURANCE      ' TO WHV804-OBJECT-ID.           *          
      *                                                              *          
      *     CALL 'WHV804' USING WHV804-COMMUNICATIONS-AREA.          *          
      *     IF WHV804-STATUS-OK                                      *          
      *     THEN                                                     *          
      *          CONTINUE WITH EXPECTED PROCESSING                   *          
      *     ELSE                                                     *          
      *          CONTINUE CHECK FOR DETAILED ERROR CONDITIONS AND    *          
      *          TAKE APPROPRIATE ACTIONS.                           *          
      *                                                              *          
      *      NOTE: THIS EXAMPLE SHOWS A TYPICAL CALL FROM AN         *          
      *            APPLICATION PROGRAM. IN THIS CASE THE PROGRAMMER  *          
      *            IS REQUESTING A SINGLETON SELECT ACTION TO RETURN *          
      *            DATA FOR A PARTICULAR CARRIER_CODE.               *          
      *                                                              *          
      *            THE PROGRAMMER SHOULD ALWAYS CHECK MODULE RESULT  *          
      *            CODE RETURNED FROM WHV804 TO VALIDTE THAT IT      *          
      *            WORKED PROPERLY (SEE THE COPYBOOK WHT018 FOR A    *          
      *            LIST OF ERROR CODES).                             *          
      *                                                              *
