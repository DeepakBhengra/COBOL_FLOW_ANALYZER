      ****************************************************************          
      *  COPYBOOK:  EDT411                                           *          
      ****************************************************************          
      *                                                              *          
      * OVERVIEW:                                                    *          
      *  USED IN SUB-ROUTINES EDV411 TO SUPPLY A CALLING PROGRAM     *          
      *  ACTIONS, DATA, AND AN AREA TO RETURN DATA AND RESULT CODE   *          
      *  INFORMATION.                                                *          
      *                                                              *          
      *     INPUT: EDV411-INPUT-DATA                                 *          
      *            - COMPANY CODE                                    *          
      *            - PARTNER ID                                      *          
      *            - STATE CODE PRIOR                                *          
      *            - STATE CODE CURRENT                              *          
      *            - FORMAT ID                                       *          
      *            - DOC ID                                          *          
      *                                                              *          
      *     INPUT/OUTPUT: EDV411-INPUT-OUTPUT-ARRAY-AREA             *          
      *            - ARRAY COUNT                                     *          
      *            - EDV411-ARRAY (OCCURS UP TO 500 TIMES)           *          
      *                 - VARIOUS DATA FROM CURSOR JOIN              *          
      *                                                              *          
      *    OUTPUT: EDV411-OUTPUT-DATA                                *          
      *             - EDV411-ROW-COUNT                               *          
      *             - EDV411-MODULE-RESULT-CD                        *          
      *             - EDV411-MODULE-MESSAGE                          *          
      *             - EDV411-DATABASE-RESULT-CODES:                  *          
      *                 - EDV411-SQLCODE                             *          
      *                 - EDV411-SQLSTATE                            *          
      *                 - EDV411-SQL-MESSAGE                         *          
      *                                                              *          
      *   EDV411 EXAMPLE FOR REQUESTING CURSOR OPEN.                 *          
      *                                                              *          
      *    INITIALIZE EDV411-COMMUNICATIONS-AREA.                    *          
      *    MOVE 'EDP155    '             TO EDV411-USER-ID.          *          
      *    MOVE 'US'                     TO EDV411-KEY-CUST-CO-CD.   *          
      *    MOVE '10EDP740'               TO EDV411-KEY-STATE-CD-PRI. *          
      *    MOVE '15EDP760'               TO EDV411-KEY-STATE-CD-CUR. *          
      *    MOVE 'CU'                     TO EDV411-KEY-PRTNR-TYPE.   *          
      *    MOVE 'X12       '             TO EDV411-KEY-FORMAT-ID.    *          
      *    MOVE 'PO ACK    '             TO EDV411-KEY-DOC-ID.       *          
      *    SET EDV411-CURSOR-OPEN        TO TRUE.                    *          
      *    SET EDV411-PO-DATA-SELECT     TO TRUE.                    *          
      *                                                              *          
      *    CALL 'EDV411' USING EDV411-COMMUNICATIONS-AREA.           *          
      *                                                              *          
      *    IF EDV411-STATUS-OK                                       *          
      *    THEN                                                      *          
      *       CONTINUE WITH EXPECTED PROCESSING                      *          
      *    ELSE                                                      *          
      *       CONTINUE CHECK FOR DETAILED ERROR CONDITIONS AND       *          
      *       TAKE APPROPRIATE ACTIONS.                              *          
      *                                                              *          
      *    NOTE: THIS EXAMPLE SHOWS A TYPICAL CALL FROM AN           *          
      *          APPLICATION PROGRAM. IN THIS CASE THE PROGRAMMER    *          
      *          IS REQUESTING AN OPEN FOR A CURSOR WHILE PASSING    *          
      *          APPROPRIATE SELECTION CRITERIA.                     *          
      *                                                              *          
      *          THE PROGRAMMER SHOULD ALWAYS CHECK MODULE RESULT    *          
      *          CODE RETURNED FROM EDV411 TO VALIDATE THAT IT       *          
      *          WORKED PROPERLY (SEE THE COPYBOOK EDT411 FOR A      *          
      *          LIST OF ERROR CODES).                               *          
      *                                                              *
