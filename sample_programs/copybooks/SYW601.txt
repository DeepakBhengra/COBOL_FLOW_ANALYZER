      *   PROGRAM:                                                   *          
      *      CICS: SYU601 - LINKED TO                                *          
      *     BATCH: SYV601 - CALLED BY (NOTE: IF THE BRANCH PROFILE   *          
      *                                      IS TO BE UPDATED IN     *          
      *                                      SYV601, THE FILE CANNOT *          
      *                                      BE OPEN FOR UPDATE IN   *          
      *                                      THE CALLING PROGRAM.    *          
      *                                      THE CALLING PROGRAM     *          
      *                                      INSURE THAT THE PROGRAM *          
      *                                      IS ACCESSED TO CLOSE    *          
      *                                      BPLMST AND TBXCORP3     *          
      *                                      PRIOR TO ENDING.)       *          
      *                                                              *          
      ****************************************************************          
      ****************************************************************          
      *                                                              *          
      *  COPYBOOK: SYW601                                            *          
      *                                                              *          
      *  PROGRAM FUNCTION:                                           *          
      *                                                              *          
      *  THE PROGRAMS ARE DESIGNED TO ACCESS TBXCORP3 AND BPLMST.    *          
      *  THEY WILL RETURN EITHER THE NEXT SALES ORDER NUMBER OR      *          
      *  THE NEXT SEQUENTIAL INVOICE NUMBER OR BOTH IF BOTH ARE      *          
      *  REQUESTED. IF THE SALES ORDER NUMBER IS REQUESTED, TBXCORP3,*          
      *  BPLMST, AND CUSHED WILL DETERMINE IF THE NUMBER WILL BE IN  *          
      *  NUMERIC OR ALPHANUMERIC FORMAT.                             *          
      *                                                              *          
      *  COMPANY AND BRANCH MUST ALWAYS BE PASSED FROM THE CALLING   *          
      *  PROGRAM.                                                    *          
      *  1. REQUESTING THE SALES ORDER NUMBER FROM BPLMST:           *          
      *     A. SET THE ORDER PROCESS MODE FLAG TO UPDATE OR READ     *          
      *        ONLY. THE SALES ORDER NUMBER TO BE USED WILL BE       *          
      *        RETURNED IN EITHER MODE, HOWEVER BPLMST WILL BE       *          
      *        UPDATED WITH THE NEXT NUMBER TO BE USED ONLY IF       *          
      *        UPDATE MODE IS SELECTED.                              *          
      *     B. POPULATE SY601-CU-ALPHA-ORD-SW WITH THE VALUE IN      *          
      *        CU-USE-ALPHA-ORD-SW. THIS WILL ALLOW THE PROGRAM      *          
      *        TO DETERMINE WHETHER A NUMERIC OR ALPHANUMERIC ORDER  *          
      *        NUMBER SHOULD BE RETURNED. IF THIS FIELD IS BLANK,    *          
      *        THE NUMERIC FORMAT WILL ALWAYS BE USED.               *          
      *     C. THE SALES ORDER NUMBER TO BE USED WILL BE RETURNED    *          
      *        IN THE SY601-ORDER-NBR FIELD.                         *          
      *                                                              *          
      *  2. REQUESTING THE SEQUENTIAL INVOICE NUMBER FROM BPLMST:    *          
      *     A. SET THE SEQUENTIAL INVOICE NUMBER MODE FLAG TO        *          
      *        UPDATE OR READ ONLY. THE SEQUENTIAL INVOICE NUMBER    *          
      *        TO BE USED WILL BE RETURNED IN EITHER MODE, HOWEVER   *          
      *        BPLMST WILL BE UPDATED WITH THE NEXT NUMBER TO BE     *          
      *        USED ONLY IF UPDATE MODE IS SELECTED.                 *          
      *     B. IF BRANCH LEVEL SEQUENTIAL INVOICING IS BEING USED    *  RDM04114
      *        (SWITCH ON TBXBRN3) SET SY601-ALT-SEQ-INV-NBR-SW TO 'B'  RDM04114
      *        PRIOR TO CALLING SYV601 (ORP804 CURRENTLY DOES THIS). *  RDM04114
      *     C. THE SEQUENTIAL INVOICE NUMBER AND THE SEQUENTIAL      *  RDM04114
      *        INVOICE SWITCH WILL BE RETURNED IN THE                *          
      *        SY601-SEQ-INV-NBR AND SY601-SEQ-INV-NBR-SW FIELDS.    *          
      *                                                              *          
      *  3. IF UPDATE MODE IS SELECTED FOR EITHER OR BOTH OF THE     *          
      *     NUMBERS, BPLMST WILL BE OPENED FOR UPDATE. IF THIS IS    *          
      *     THE CASE, BPLMST CANNOT BE OPENED FOR UPDATE IN THE      *          
      *     CALLING PROGRAM DURING BATCH PROCESSING.                 *          
      *                                                              *          
      *  4. THE BATCH VERSION OF THE PROGRAM HAS ITS OWN DD TO       *          
      *     ACCESS BPLMST. IF THE CALLING PROGRAM ALSO REQUIRES      *          
      *     ACCESS TO BPLMST, A SEPERATE DD MUST BE IN THE JCL       *          
      *     AND THE CALLING PROGRAM CANNOT OPEN THE FILE FOR UPDATE. *          
      *                                                              *          
      * NOTE:  TO INSURE THAT ONLY A NUMERIC SALES ORDER NUMBER      *          
      *        IS RETURNED BY SYU601 AND SYV601 MAKE THE FIELD       *          
      *        SY601-CU-ALPHA-ORD-SW BLANK.                          *          
      *        IF THIS FIELD IS 'Y', AN ALPHANUMERIC ORDER NUMBER    *          
      *        MAY BE RETURNED BASED UPON TBXCORP3 AND BPLMST.       *          
      *                                                              *          
      *                                                              *
