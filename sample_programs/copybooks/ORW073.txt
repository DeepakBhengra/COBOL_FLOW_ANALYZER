      ******************************************************************        
      * COMMUNICATION AREA FOR INVOKING ORP073 - FINAL REVIEW EVALUATION        
      *                                                                         
      * USAGE STEPS:                                                            
      *   1. MOVE VALUES TO ALL INPUT FIELDS FOR AN ORDER ON IMS                
      *   2. LINK TO ORP073 (FOR EXAMPLES, SEE RWP566IM & ORP560MD)             
      *   3. CHECK RESULTS IN OUTPUT FIELDS:                                    
      *      NORMAL  - INDICATES ORDER PASSED FINAL REVIEW EVALUATION           
      *                AND SHOULD CONTINUE NORMAL PROCESSING (PRINTING)         
      *      HOLD    - INDICATES THE ORDER WAS PLACED ON A SALES HOLD           
      *                BECAUSE IT MATCHED AN ACTIVE MODE PROFILE                
      *      MONITOR - INDICATES THE ORDER WAS NOT PLACED ON HOLD,              
      *                BUT THAT IT MATCHED A MONITOR-ONLY PROFILE               
      *      ERROR   - INDICATES THAT AN ERROR PREVENTED FINAL REVIEW           
      *                EVALUATION, AS DESCRIBED IN THE STATUS TEXT
