      * TBXVATID - BREXIT CONFIGURATION TABLE                                   
      *                                                                         
      * FIELD EXPLANATIONS                                                      
      * COMPANY - COMPANY CODE                                                  
      * COUNTRY CODE - WHERE THE ORDER IS SHIPPING TO                           
      *  - EX: IE / NL                                                          
      * RESELLER TAX CODE - TAX CODE FOR THE CUSTOMER SHIPPING TO               
      *    THE SAID COUNTRY CODE                                                
      *  - EX: IE FOR IE COUNTRY, AND NL OR IC FOR NL COUNTRY                   
      * RUN BX VALIDATION - DETERMINES WHETHER ORDERS WILL BE VALIDATED         
      *    FOR BX HOLD                                                          
      *  - EX: Y / N                                                            
      * RESELLER VAT ID - IF EVALUATING FOR BREXIT HOLD, RESELLER MUST          
      *    HAVE THIS VAT ID PREFIX (IE***, NL***) TO SHIP AN ORDER TO           
      *    THE SAID COUNTRY.                                                    
      *  - IF VALUE IS --, RESELLER VAT ID WILL NOT BE INCLUDED IN              
      *    THE CONDITIONS                                                       
      *  - EX: IE / NL                                                          
      * POSTAL CODE - IF EVALUATING FOR BREXIT HOLD, RESELLER MUST HAVE         
      *    THIS POSTAL CODE.                                                    
      *  - EX: EIRE                                                             
      * POSTAL CODE LENGTH - LENGTH OF POSTAL CODE TO BE VALIDATED              
      *  - EX: 04                                                               
      * IMUK VAT ID USES BX FLAG - WHETHER THE SELECTION FOR THE                
      *    INGRAM VAT ID DEPENDS ON BREXIT FLAG (PHYS/NONPHYS)                  
      *  - EX: IF Y, ONLY BREXIT PHYS WILL GET THE CORRESPONDING                
      *    COUNTRY'S VATID                                                      
      *  - EX: IF N, ALL ORDERS WILL GET THE CORRESPONDING COUNTRY'S            
      *    VATID                                                                
      * IMUK VAT ID - INGRAM VAT ID TO BE DISPLAYED IN THE INVOICE              
      *  - EX: IE123456789                                                      
      * IM VAT TEXT / 2 / 3 - TOTAL 90-BYTES FOR FISCAL REPRESENTAION           
      *    TO BE DISPLAYED IN THE INVOICE                                       
      * TAX USES DIFF GL ACCT - TAX AMOUNTS UNDER THIS TAX CODE WILL            
      *    BE WRITTEN ON THEIR RESPECTIVE GL ACCOUNTS (SEE SYLTAX)
