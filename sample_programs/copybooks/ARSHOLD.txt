      ******************************************************************        
      *     NAME: ARSHOLD                                                       
      *           CLONED FROM SYHHOLDT FOR USE                                  
      *           IN CREDIT SUBROUTINES ARVHLD & ARUHLD.                        
      *-----------------------------------------------------------------        
      *     FUNCTION: FIRST, ICP554MD READS THROUGH THE CUSTOMER HEADERS        
      *               AND ZEROES OUT ALL CU-OPEN-ORDERS FIELDS.  AS THE         
      *               PROGRAM ICP555MD DETERMINES SHIPPABLE QUANTITY FOR        
      *               EACH ORDER, IT THEN ADDS THAT OPEN ORDER AMOUNT TO        
      *               THE CU-OPEN-ORDERS FIELD FOR THAT CUSTOMER, SO            
      *               THAT CREDIT HOLD PROCESSING IN THIS ROUTINE IS            
      *               CUMULATIVE, FIFO.  ANY ORDER WITH A SHIPPABLE             
      *               AMOUNT ENTERS THIS LOGIC.  ORDERS THAT HAVE BEEN          
      *               PRINTED OR VOIDED BYPASS ANY FURTHER PROCESSING.          
      *               CREDIT MEMOS, MEMO ORDERS, AND FUTURE ORDERS ALSO         
      *               DROP OUT AND ARE NOT PROCESSED FURTHER.  ALL              
      *               ORDERS THAT HAVE A CREDIT HOLD VALUE SET FOR THEM         
      *               IN THIS ROUTINE WILL HAVE A CREDIT HOLD RECORD            
      *               CREATED FOR THEM WHICH WILL SHOW ON THE                   
      *               APPROPRIATE ORDER REVIEW SCREEN.  IF THE CUSTOMER         
      *               IS ON "HARD-9" CREDIT HOLD, THEN THE ORDER IS PUT         
      *               ON CREDIT HOLD, "C".  IF THE ORDER HAS A BILL-TO          
      *               SUFFIX OF "111", THEN IT IS PUT ON CREDIT HOLD,           
      *               "C".  IF THE CUSTOMER HAS A CREDIT OF "4", THEN           
      *               THE ORDER IS PUT ON PAST-DUE/OVER-LIMIT HOLD, "B".        
      *               IF THE CUSTOMER HAS A CREDIT OF "5", THEN THE             
      *               ORDER IS PUT ON PAST-DUE HOLD, "P".  IF THE               
      *               CUSTOMER HAS A CREDIT OF "6", THEN THE ORDER IS           
      *               PUT ON OVER-LIMIT HOLD, "L".  FOR ANY ORDERS THAT         
      *               HAVE NOT BEEN SET FOR CREDIT HOLD THE CUSTOMER'S          
      *               OUTSTANDING BALANCE IS COMPUTED AND A/R RISK CLASS        
      *               LIMIT MULTIPLIER IS SET.  THE BALANCE IS THE SUM          
      *               OF ALL AGINGS FOR THE CUSTOMER AND ANY SHIPPABLE          
      *               QUANTITIES PREVIOUSLY PROCESSED.  THE CUSTOMER'S          
      *               OUTSTANDING BALANCE IS THEN COMPARED TO THE               
      *               CUSTOMER'S ADJUSTED CREDIT LIMIT.  IF THE BALANCE         
      *               IS GREATER, THEN THE ORDER IS PUT ON OVER-LIMIT           
      *               HOLD, "B".  IF THE ORDER IS ON TAG-HOLD, THEN SET         
      *               IT FOR TAG-HOLD, "G", SO THAT A REVIEW RECORD WILL        
      *               BE CREATED FOR THE ORDER.  IF THE ORDER IS ON             
      *               PENDING-HOLD, THEN SET IT FOR PENDING-HOLD, "N",          
      *               SO A REVIEW RECORD WILL BE CREATED FOR THE ORDER.         
      *-----------------------------------------------------------------        
      *      PURPOSE: THIS ROUTINE WILL DO ALL PROCESSING FOR DECIDING          
      *               HOW TO PUT AN ORDER ON CREDIT HOLD AS FOLLOWS:            
      *                                                                         
      *                SET FLAG SO THAT ALL ORDERS ARE CHECKED FOR HOLD.        
      *                                                                         
      *                BYPASS CREDIT HOLD TEST LOGIC IF THE ORDER IS A          
      *                  THE ORDER HAS BEEN PRINTED,                            
      *                  CREDIT-MEMO ORDER,                                     
      *                  MEMO ORDER,                                            
      *                  FUTURE ORDER,                                          
      *                  OR THE ORDER HAS BEEN VOIDED                           
      *                  ORDER-DATE-RELEASED IS THAN 7 DAYS OLD.                
      *                                                                         
      *                IF CHECK-ORDER-HOLD-STATUS                               
      *                  IF CUSTOMER-HEADER-CREDIT-HOLD                         
      *                    PUT ORDER ON CREDIT HOLD.                            
      *                                                                         
      *                IF CHECK-ORDER-HOLD-STATUS                               
      *                  IF CUSTOMER-CREDIT-CODE = '4'                          
      *                    PUT ORDER ON                                         
      *                      BOTH-PAST-DUE-OVER-LIMIT CREDIT HOLD.              
      *                                                                         
      *                IF CHECK-ORDER-HOLD-STATUS                               
      *                  IF CUSTOMER-CREDIT-CODE = '5'                          
      *                    PUT ORDER ON PAST-DUE CREDIT HOLD.                   
      *                                                                         
      *                IF CHECK-ORDER-HOLD-STATUS                               
      *                  IF CUSTOMER-CREDIT-CODE = '6'                          
      *                    PUT ORDER ON OVER-LIMIT CREDIT HOLD.                 
      *                                                                         
      *                MOVE ZERO TO CUSTOMER-ORDER-BALANCE.                     
      *                                                                         
      *                COMPUTE CUSTOMER-ORDER-BALANCE.                          
      *                                                                         
      *                CHECK CUSTOMERS RISK CLASS AND USE THESE RULES           
      *                  TO SEE IF ORDER PUTS CUSTOMER OVER CREDIT LIMIT        
      *                                                                         
      *                  RISK                                                   
      *                  CLASS  OVER LIMIT                                      
      *                  ----- ---------------------------------------          
      *                    A    IF CREDIT LIMIT IS EXCEEDED                     
      *                    B    IF CREDIT LIMIT + 10% IS EXCEEDED               
      *                    C    IF CREDIT LIMIT + 15% IS EXCEEDED               
      *                    D    IF CREDIT LIMIT + 20% IS EXCEEDED               
      *                    E    IF CREDIT LIMIT + 25% IS EXCEEDED               
      *                                                                         
      *                IF CHECK-ORDER-HOLD-STATUS                               
      *                  IF THE CUSTOMER DOES NOT HAVE UNLIMITED CREDIT         
      *                    IF CHECK-CREDIT-LIMIT                                
      *                      COMPUTE CUSTOMER-ORDER-BALANCE                     
      *                      COMPUTE AVAILABLE CREDIT USING CHART               
      *                      IF OVER CREDIT-LIMIT                               
      *                        PUT ORDER ON OVER-LIMIT CREDIT HOLD.             
      *                                                                         
      *                IF ORDER STATUS = 'G'                                    
      *                   SET TAG HOLD CREDIT HOLD STATUS.                      
      *                                                                         
      *                IF ORDER STATUS = 'N'                                    
      *                   SET PENDING CREDIT HOLD STATUS.                       
      *
