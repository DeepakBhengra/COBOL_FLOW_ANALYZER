      *                                                                *        
      *   CHECK CUSTOMER'S VENDOR AUTHORIZATION.                       *        
      *                                                                *        
      *      INPUT : OET-COMPANY           - COMPANY CODE              *        
      *              OET-CUST-BR           - CUSTOMER BRANCH           *        
      *              OET-CUST-NBR          - CUSTOMER NUMBER           *        
      *              OET-CUST-SUF          - CUSTOMER BILL-TO SUFFIX   *        
      *              OET-CUST-SHIP-TO-SUF  - CUSTOMER SHIP-TO SUFFIX   *        
      *              INI-VENDOR-NBR        - INVENTORY VENDOR NUMBER   *        
      *              INI-RESTRICTED-SW     - ITEM'S RESTRICTION SWITCH *        
      *                                                                *        
      *      OUTPUT: WS-SYXAUTH-AUTHORIZATION-SW : 'Y' = AUTHORIZED    *        
      *                                            'N' = UNAUTHORIZED. *        
      *                                                                *        
      ******************************************************************        
      *                                                                         
      *     ORSHED / OERTSQA EQUIVALENT COPYBOOK VARIABLES:                     
      *                                                                         
      *     OET-COMPANY          -        ORH-COMPANY                           
      *     OET-CUST-BR          -        ORH-BILL-TO-BR-NBR                    
      *     OET-CUST-NBR         -        ORH-BILL-TO-CUST-NBR                  
      *     OET-SHIP-TO-SUF      -        ORH-SHIP-TO-SUFFIX                    
      *     OET-FLOOR-SUF        -        ORH-FLOOR-SUF                         
      *     OET-CUST-SUF         -        ORH-BILL-TO-SUFFIX                    
      ******************************************************************        
      *   REQUIRED COPYBOOKS:                                                   
      *   CUKVNA   - CUSTOMER/VENDOR AUTHORIZATION SKA                          
      *   CURVNA   - CUSTOMER/VENDOR AUTHORIZATION                              
      *   INSHED   - INVENTORY D/B HEADER SEGMENT                               
      *   OERTSQA  - ORDER ENTRY TEMPORARY STORAGE QUEUE                        
      *   SYWAUTH  - AUTHORIZATION ROUTINE WORKING STORAGE                      
      ******************************************************************        
                                                                                
      *     ONE-TIME INITIALIZATION                                             
                                                                                
            SET WS-SYXAUTH-AUTHORIZED     TO  TRUE                              
                                                                                
      *    BYPASS PROCESSING                                                    
                                                                                
           IF OET-CUST-NBR = '111111' OR                                        
              OET-TYPE-INTER-SYSTEM-TRANSFER OR                         RGB98068
              OET-CUST-NBR = '999999'                                           
              GO TO 7000-SYXAUTH-EXIT.                                          
                                                                                
      *    CUSTOMER LEVEL KEY INITIALIZATION                                    
                                                                                
           MOVE OET-COMPANY               TO  WS-CULVNA-COMPANY                 
           MOVE OET-CUST-BR               TO  WS-CULVNA-BR-NBR                  
           MOVE OET-CUST-NBR              TO  WS-CULVNA-CUST-NBR                
                                                                                
           IF OET-SHIP-TO-SUF NUMERIC                                           
              MOVE OET-SHIP-TO-SUF        TO  WS-CULVNA-CUST-SUFFIX             
           ELSE                                                                 
              IF OET-FLOOR-SUF                                                  
                 MOVE '000'               TO  WS-CULVNA-CUST-SUFFIX             
              ELSE                                                              
                 MOVE OET-CUST-SUF        TO  WS-CULVNA-CUST-SUFFIX.            
                                                                                
      *   CHECK TO SEE IF THERE IS A AUTH AS OVERRIDE                           
           MOVE 'A'                       TO  WS-CULVNA-SEGMENT-TYPE.           
           MOVE SPACE                     TO  WS-CULVNA-VENDOR                  
                                              WS-CULVNA-RESTRICT-CODE           
                                              CULVNA-ATAS-CUST.                 
                                                                                
           PERFORM 7000-SYXAUTH-READ.                                           
                                                                        KMP06352
           IF WS-CULVNA-ERROR                                           KMP06352
              SET WS-SYXAUTH-UNAUTHORIZED TO TRUE                       KMP06352
              SET WS-SYXAUTH-CULVNA-ERROR TO TRUE                       KMP06352
              GO TO 7000-SYXAUTH-EXIT                                   KMP06352
           END-IF.                                                      KMP06352
                                                                        KMP06352
           IF WS-CULVNA-NORESP                     AND                          
              CULVNA-ATAS-BR-NBR      NOT = SPACES AND                          
              CULVNA-ATAS-CUST-NBR    NOT = SPACES AND                          
              CULVNA-ATAS-CUST-SUFFIX NOT = SPACES                              
              MOVE CULVNA-ATAS-BR-NBR      TO WS-CULVNA-BR-NBR                  
              MOVE CULVNA-ATAS-CUST-NBR    TO WS-CULVNA-CUST-NBR                
              MOVE CULVNA-ATAS-CUST-SUFFIX TO WS-CULVNA-CUST-SUFFIX             
           END-IF.                                                              
                                                                                
      *    SEARCH FOR GENERIC AUTHORIZE AS CUSTOMER                             
      *       SEARCH FIRST FOR A POSITIVE RESPONSE IF THAT IS                   
      *       NOT FOUND THE SEARCH FOR A NEGATIVE RESPONSE.                     
      *       IF A RESPONSE IS FOUND THEN MOVE THE KEY OF THE RECORD            
      *          TO WS-CULVNA-KEY FOR THE FOLLOWING READ.                       
           IF WS-CULVNA-NORESP    AND                                           
              CULVNA-ATAS-GENERIC                                               
              MOVE WS-CULVNA-KEY  TO WS-SYXAUTH-KEY                             
              MOVE LOW-VALUES     TO WS-CULVNA-KEY(11:9)                        
              PERFORM 7000-SYXAUTH-STARTBR                                      
                                                                        KMP06352
              IF WS-CULVNA-ERROR                                        KMP06352
                 SET WS-SYXAUTH-UNAUTHORIZED TO TRUE                    KMP06352
                 SET WS-SYXAUTH-CULVNA-ERROR TO TRUE                    KMP06352
                 GO TO 7000-SYXAUTH-EXIT                                KMP06352
              END-IF                                                    KMP06352
                                                                        KMP06352
              IF WS-CULVNA-NORESP                                               
                 PERFORM 7000-SYXAUTH-READNEXT WITH TEST AFTER                  
                   UNTIL NOT WS-CULVNA-NORESP                    OR             
                         CULVNA-KEY(1:10) NOT = WS-SYXAUTH-KEY1  OR             
                        (CULVNA-KEY(1:10)     = WS-SYXAUTH-KEY1 AND             
                         CULVNA-SEGMENT-TYPE  = 'I'             AND             
                         CULVNA-VENDOR        = INI-VENDOR-NBR  AND             
                        (CULVNA-RESTRICT-CODE = SPACES OR                       
                                            INI-RESTRICTED-SW)  AND             
                         CULVNA-RES-POS)                                        
                                                                        KMP06352
                 IF WS-CULVNA-ERROR                                     KMP06352
                    SET WS-SYXAUTH-UNAUTHORIZED TO TRUE                 KMP06352
                    SET WS-SYXAUTH-CULVNA-ERROR TO TRUE                 KMP06352
                    GO TO 7000-SYXAUTH-EXIT                             KMP06352
                 END-IF                                                 KMP06352
                                                                        KMP06352
                 IF WS-CULVNA-NORESP                      AND                   
                    CULVNA-KEY(1:10)    = WS-SYXAUTH-KEY1 AND                   
                    CULVNA-SEGMENT-TYPE = 'I'             AND                   
                    CULVNA-VENDOR       = INI-VENDOR-NBR  AND                   
                   (CULVNA-RESTRICT-CODE = SPACES OR                            
                                      INI-RESTRICTED-SW)  AND                   
                    CULVNA-RES-POS                                              
                    MOVE CULVNA-KEY TO WS-CULVNA-KEY                            
                 ELSE                                                           
                                                                                
                    PERFORM 7000-SYXAUTH-ENDBR                                  
                    MOVE WS-SYXAUTH-KEY TO WS-CULVNA-KEY                        
                    MOVE LOW-VALUES     TO WS-CULVNA-KEY(11:9)                  
                    PERFORM 7000-SYXAUTH-STARTBR                                
                                                                        KMP06352
                    IF WS-CULVNA-ERROR                                  KMP06352
                       SET WS-SYXAUTH-UNAUTHORIZED TO TRUE              KMP06352
                       SET WS-SYXAUTH-CULVNA-ERROR TO TRUE              KMP06352
                       GO TO 7000-SYXAUTH-EXIT                          KMP06352
                    END-IF                                              KMP06352
                                                                        KMP06352
                    IF WS-CULVNA-NORESP                                         
                       PERFORM 7000-SYXAUTH-READNEXT WITH TEST AFTER            
                         UNTIL NOT WS-CULVNA-NORESP                   OR        
                               CULVNA-KEY(1:10) NOT = WS-SYXAUTH-KEY1 OR        
                              (CULVNA-KEY(1:10)    = WS-SYXAUTH-KEY1 AND        
                               CULVNA-SEGMENT-TYPE  = 'I'            AND        
                               CULVNA-VENDOR        = INI-VENDOR-NBR AND        
                              (CULVNA-RESTRICT-CODE = SPACES OR                 
                                                  INI-RESTRICTED-SW) AND        
                               CULVNA-RES-NEG)                                  
                                                                        KMP06352
                       IF WS-CULVNA-ERROR                               KMP06352
                          SET WS-SYXAUTH-UNAUTHORIZED TO TRUE           KMP06352
                          SET WS-SYXAUTH-CULVNA-ERROR TO TRUE           KMP06352
                          GO TO 7000-SYXAUTH-EXIT                       KMP06352
                       END-IF                                           KMP06352
                                                                        KMP06352
                       IF WS-CULVNA-NORESP                      AND             
                          CULVNA-KEY(1:10)    = WS-SYXAUTH-KEY1 AND             
                          CULVNA-SEGMENT-TYPE = 'I'             AND             
                          CULVNA-VENDOR       = INI-VENDOR-NBR  AND             
                         (CULVNA-RESTRICT-CODE = SPACES OR                      
                                            INI-RESTRICTED-SW)  AND             
                          CULVNA-RES-NEG                                        
                          MOVE CULVNA-KEY TO WS-CULVNA-KEY                      
                       END-IF                                                   
                    END-IF                                                      
                 END-IF                                                         
              END-IF                                                            
              PERFORM 7000-SYXAUTH-ENDBR                                        
           END-IF.                                                              
                                                                                
      *--- CHECK FOR GENERIC VENDOR ENTRY IF FOUND THEN CHECK FOR       AZC21064
      *--- SKU RESTRICT CODE AND AUTHORIZED IF RESTRIC PLUS             AZC21064
           IF TB-CPO2-GEN-VENDOR                                        AZC21064
              MOVE 'I'                       TO WS-CULVNA-SEGMENT-TYPE  AZC21064
              MOVE '****'                    TO WS-CULVNA-VENDOR        AZC21064

              PERFORM 7000-SYXAUTH-READ                                 AZC21064
              EVALUATE TRUE                                             AZC21064
                  WHEN WS-CULVNA-NORESP                                 AZC21064
                       MOVE 'I'               TO WS-CULVNA-SEGMENT-TYPE AZC21064
                       MOVE INI-VENDOR-NBR    TO WS-CULVNA-VENDOR       AZC21064
                       IF INI-RESTRICTED-SW  = 'N'                      AZC21064
                          MOVE SPACES         TO WS-CULVNA-RESTRICT-CODEAZC21064
                       ELSE                                             AZC21064
                          MOVE INI-RESTRICTED-SW                        AZC21064
                                              TO WS-CULVNA-RESTRICT-CODEAZC21064
                       END-IF                                           AZC21064
                       PERFORM 7000-SYXAUTH-READ                        AZC21064
                       IF WS-CULVNA-ERROR                               AZC21064
                          SET WS-SYXAUTH-UNAUTHORIZED TO TRUE           AZC21064
                          SET WS-SYXAUTH-CULVNA-ERROR TO TRUE           AZC21064
                          GO TO 7000-SYXAUTH-EXIT                       AZC21064
                       END-IF                                           AZC21064
                       IF WS-CULVNA-NOTFND                              AZC21064
                       OR CULVNA-RES-NEG                                AZC21064
                          SET WS-SYXAUTH-UNAUTHORIZED TO TRUE           AZC21064
                       END-IF                                           AZC21064
                       GO TO 7000-SYXAUTH-EXIT                          AZC21064
                  WHEN WS-CULVNA-ERROR                                  AZC21064
                       SET WS-SYXAUTH-UNAUTHORIZED TO TRUE              AZC21064
                       SET WS-SYXAUTH-CULVNA-ERROR TO TRUE              AZC21064
                       GO TO 7000-SYXAUTH-EXIT                          AZC21064
                  WHEN OTHER                                            AZC21064
                       CONTINUE                                         AZC21064
             END-EVALUATE                                               AZC21064
           END-IF                                                       AZC21064
