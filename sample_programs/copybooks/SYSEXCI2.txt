      * NAME:    SYSEXCI2                                                       
      * PURPOSE: THIS IS THE IMI EXCI CALLABLE CLIENT LONG CALL VERB            
      *                                                                         
      *      USE WITH WORKING STORAGE COPYBOOK SYWEXCI                          
      *=================================================================        
      * DATE      PGR   DESC                                                    
      * 04/14/97  LMH   NEW COPYBOOK                                    LMH97104
      * ****************************************************************        
      *                                                                         
           MOVE 'IMB501'             TO EXCI-CALLABLE-CLIENT.                   
           CALL EXCI-CALLABLE-CLIENT USING USRREQ                               
                                           USRFUN                               
                                           USRRSP                               
                                           USRSYS                               
                                           USRRSC                               
                                           USRTYP                               
                                           USRKYL                               
                                           USRKEY                               
                                           USRARL                               
                                           USRARA.                              
      *                                                                         
      * ****************************************************************        
      * SPECIAL NOTE                                                            
      *        YOU CAN USE THE SYWEIB COPYBOOK TO CHECK THE RETURN CODE         
      *        THAT IS PASSED BACK IN FIELD USRRSP BY MOVING IT TO              
      *        WS-EIBRESP. THIS IS ONLY IF THE RETURN CODE IS WITHIN THE        
      *        RANGE OF 0 TO 255, THEN THE MEANING OF THE CODE IS AS            
      *        DOCUMENTED UNDER "RESP VALUES" IN THE CICS/ESA USER'S            
      *        HANDBOOK. IF THE RETURN CODE IS NOT IN THAT RANGE CHECK          
      *        THE 88 LEVEL UNDER THE USRRSP FIELD TO DETERMINED IF THE         
      *        EXCI CALLABLE CLIENT INDICATED A ERROR
