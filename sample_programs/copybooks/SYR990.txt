      ******************************************************************        
      *   *  COPYBOOK: SYR990                                          *        
      *   *                                                            *        
      *   *  PURPOSE : HOLDS THE VARIABLES USED TO INSERT LOG DATA INTO*        
      *   *            IMPULSE APPLICATION ERROR LOG TABLE.            *        
      *   *            THIS COPYBOOK IS USED ALONG WITH SYU990/SYV990. *        
      *   *                                                            *        
      *   *  USAGE   :                                                 *        
      *   *  ---------                                                 *        
      *   *  PLUG IN INSTRUCTIONS -                                    *        
      *   *          - IDENTIFY THE PROCESS NEEDS LOGGER.              *        
      *   *          - INSERT THE LOG PROCESS IN DB2 TABLE             *        
      *   *            IMP_APP_ERR_LOG_PRS WITH EVENT LOGGER SWITCH    *        
      *   *             DATA VALIDATION -                              *        
      *   *             DB2 COLUMN   VS COMMAREA FIELD                 *        
      *   *             LOG_PROCS_CD =  SYR990-LOG-PROCS-CD            *        
      *   *             PGM_ID       =  SYR990-PGM-ID                  *        
      *   *             CO_CD        =  SYR990-CO-CD                   *        
      *   *             EVENT_LOG_SW =  Y - LOG THE EVENT              *        
      *   *                             N - SKIP LOGGING               *        
      *   *          - ADD COPYBOOK SYR990 IN WORKING SECTION.         *        
      *   *          - USE COMMON VARIABLE FOR FOLLOWING MANDATORY     *        
      *   *            FIELDS TO IDENTIFY LAST CHANGES IN THE PROGRAM  *        
      *   *               WS-REVISION-LEVEL-STAMP  - REVISION STAMP    *        
      *   *               WS-LAST-CONTAINER-CHANGE - CONTAINER #       *        
      *   *               FOR BATCH                                    *        
      *   *               ~~~~~~~~~                                    *        
      *   *               WS-PROGRAM - PROGRAM NAME                    *        
      *   *          - FORMAT THE DATA NEEDS TO BE LOOGED IN THE DB2   *        
      *   *            FROM SOURCE VARIABLES TO SYR990-IN-AREA.        *        
      *   *          - PERFORM 990-IMP-ERR-MSG                         *        
      *   *               THRU 990-IMP-ERR-MSG-EXIT                    *        
      *   *          - ADD COPYBOOK IN PROCEDURAL DIVISION             *        
      *   *               SYSERREC - FOR ONLINE MODULES                *        
      *   *               SYSERREB - FOR BATCH  MODULES                *        
      *   *          - REFER PUP393 FOR ONLINE SAMPLE - STARTED TASK   *        
      *   *          - REFER PUP657 FOR BATCH  SAMPLE - CALLED ROUTINE *        
      *   *          - IF SYU990 IS TRIGGERED AS LINKED MODULE BY      *        
      *   *            PASSING VALUE IN SYR990-ROUTINE - ENSURE DLI IS *        
      *   *            TERMINATED AS PER PROGRAM FLOW.                 *        
      *   *          - ERROR LOG TABLE NAME IMPULSE_APPL_ERR_LOG       *
