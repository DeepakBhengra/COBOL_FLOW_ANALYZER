         02 SYWSPS-REQUEST-RESPONSE-AREAS.                                      
                                                                                
      ***************************************************************           
      *    THE STRATEGIC PRICING REQUEST AREA FOR MULTIPLE SKUS                 
      ***************************************************************           
                                                                                
           03 SYWSPS-REQUEST-GROUP.                                             
                                                                                
            04 SYWSPS-REQUEST-AREAS                                             
                 OCCURS 25 TIMES.                                               
               05 SYWSPS-REQUEST-AREA.                                          
                                                                                
      *    (THE REQUEST AREA CONTAINS EACH SKU TO BE PRICED)                    
       COPY SYWSPSRQ.                                                           
                                                                                
      ***************************************************************           
      *    THE STRATEGIC PRICING RESPONSE AREA FOR MULTIPLE SKUS                
      ***************************************************************           
                                                                                
           03 SYWSPS-RESPONSE-GROUP.                                            
                                                                                
            04 SYWSPS-RESPONSE-AREAS                                            
                 OCCURS 25 TIMES.                                               
               05 SYWSPS-RESPONSE-AREA.                                         
                                                                                
      *    (THE RESPONSE AREAS REPEAT TO RETURN EACH PRICE RESPONSE)            
       COPY SYWSPSRS.
