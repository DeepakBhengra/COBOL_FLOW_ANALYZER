002100*DIFFERENCES BETWEEN 4510 & 3530 PRINTER:                                 
002200* 1- ON SOME OF THE BARCODE PARAMETERS UNIT OF MEASURE ARE DIFFERENT      
002300*    FOR IE 1/44 VS 1/20 OF INCH BECUASE OF THIS THE WIDTH OF BAR         
002400*    CODE WILL NOT BE THE SAME HOWEVER BOTH ARE READABLE.                 
002500* 2- THE DEFAULTS FOR THESE PRINTERS ARE NOT THE SAME SPECIALLY           
002600*    PARAMETERS USED IN PRINTING BARCODE. SO TO SOLVE THIS PB             
002700*    I HARD CODED ALL THE PARAMETERS. I THINK ONCE A BARCODE PARAMETER    
002800*    IS SET IT WILL REMAIN IN THE PRINTER UNTIL THE PRINTER IS            
002900*    REINITIALIZED TO FACTORY DEFAULT.                                    
003000* 3- THE SCROLLING BACK MOTION IS MUCH MORE VISIBLE IN 4510 THAN 3530     
003100*    HOWEVER THE RESULT IS THE SAME.                                      
003200* 4- THE TOP OF FORM LINE USING 3530 PRINTER TO PRINT BARCODE VS          
003300*    NO-BARCODE ARE DIFFERENT. I THINK SAME APPLIES FOR 4510.             
003400* NOTES:                                                                  
003500*      1-"CNTL J" WILL GIVE YOU "LF" IN BARCODE ACCORDING TO INTERMEC     
003600*        GENECOME TOLD ME PUT IN "$J" AND IT WORKED                       
003700*    NO-BARCODE ARE DIFFERENT. I THINK SAME APPLIES FOR 4510.             
003800*      2-EACH BARCODE HAS BEGINNING AND END '*' AS THE CHAR.              
003900*        IF YOU DONT SEND ANY '*' IT WILL PUT IT THERE FOR YOU.           
004000*        IF YOU WANT SEVERAL BARCODES PRINT AT SAME LINE PUT A            
004100*        BEG AND END '*' FOR EACH.
