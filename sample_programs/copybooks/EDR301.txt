      ****************************************************************          
      *  COPYBOOK:  EDR301                                           *          
      ****************************************************************          
      *                                                              *          
      * OVERVIEW:                                                    *          
      * `````````                                                    *          
      *  INTERFACE USED FOR SUB-ROUTINE EDV301 TO SUPPLY ACTION      *          
      *  CODES, DATA, AND AN ARRAY (DATA AREA TO BE SORTED) AND TO   *          
      *  RECEIVE PROCESSING RESULTS (RETURN CODE) FROM EDV301.       *          
      *                                                              *          
      * INPUT:                                                       *          
      * ``````                                                       *          
      *         EDV301-INPUT                                         *          
      *        - ACTION CODE : A - ASCENDING, D - DESCENDING         *          
      *        - ROW COUNT   : THE NUMBER OF ROWS IN THE ARRAY       *          
      *                        TO BE SORTED                          *          
      *        - ROW LENGTH  : THE LENGTH OF EACH ROW (IN NUMBER     *          
      *                        OF CHARACTERS)                        *          
      *        - KEY POSITION: THE START POSITION OF THE "KEY"       *          
      *                        WITHIN EACH ROW                       *          
      *        - KEY LENGTH  : THE LENGTH OF THE KEY WITHIN EACH     *          
      *                        ROW                                   *          
      *        - ARRAY       : THE ARRAY (4MG DATA AREA) TO BE       *          
      *                        SORTED                                *          
      * OUTPUT:                                                      *          
      * ```````                                                      *          
      *        EDV301-OUTPUT                                         *          
      *        - ARRAY       : THE SORTED ARRAY DATA AREA            *          
      *        - RETURN CODE : MODULE EDIT/PROCESSING RESULTS        *          
      *                                                              *          
      * USAGE EXAMPLE:                                               *          
      * ``````````````                                               *          
      * SCENARIO: A WORKING ARRAY (W-ARRAY) INTO WHICH W-ROW-CT      *          
      * ~~~~~~~~  ENTRIES HAVE BEEN LOADED. THE ENTRY "KEY" STARTS   *          
      *           IN, SAY, POSITION 12. THE PROGRAM NEEDS THE ARRAY  *          
      *           TO BE SORTED IN ASCENDING ORDER BY ENTRY KEY.      *          
      *                                                              *          
      *     IN THIS CASE, THE CALLING PROGRAM WOULD CALL EDV301      *          
      *     AS FOLLOWS:                                              *          
      *                                                              *          
      *     INITIALIZE EDV301-COMMUNICATIONS-AREA.                   *          
      *     SET EDV301-ASCENDING          TO TRUE.                   *          
      *     MOVE W-ROW-CT                 TO EDV301-ROW-CNT          *          
      *     MOVE LENGTH OF W-ENTRY(1)     TO EDV301-ROW-LEN          *          
      *     MOVE 12                       TO EDV301-KEY-POS          *          
      *     MOVE LENGTH OF W-ENTRY-KEY(1) TO EDV301-KEY-LEN          *          
      *     MOVE W-ARRAY                  TO EDV301-ARRAY            *          
      *     CALL 'EDV301' USING EDV301-COMMUNICATIONS-AREA.          *          
      *     IF EDV301-STATUS-OKAY                                    *          
      *        MOVE EDV301-ARRAY          TO W-ARRAY                 *          
      *     ELSE                                                     *          
      *        TAKE APPROPRIATE ACTIONS                              *          
      *     END-IF.                                                  *
