000500*                                                               *         
000600* LANGUAGE:  OS/390 COBOL                                       *         
000700*  PURPOSE:  COMPARE AN ADDRESS TO ANOTHER ADDRESS AND RETURN   *         
000800*            THE NAMESEARCH SCORE.                              *         
000900*                                                               *         
001000* CALL FORMAT: CALL WS-EUP733 USING EUX733-PARMS                *         
001100*                                                               *         
001200* EXAMPLE:                                                      *         
001300*                                                               *         
001400* WORKING-STORAGE SECTION.                                      *         
001500* 01  WS-EUP733                  PIC  X(08) VALUE 'EUP733'.     *         
001600*                                                               *         
001700* COPY EUX733 REPLACING ==:EUX733:== BY ==EUX733==.             *         
001800*                                                               *         
001900* PROCEDURE DIVISION.                                           *         
002000*     INITIALIZE EUX733-PARMS                                   *         
002100*     MOVE EU-ADDR-1-TXT TO EUX733-ADDR1-TXT-1                  *         
002200*     MOVE EU-ADDR-2-TXT TO EUX733-ADDR2-TXT-1                  *         
002300*     MOVE EU-ADDR-3-TXT TO EUX733-ADDR3-TXT-1                  *         
002400*     MOVE EU-CITY-NAM   TO EUX733-CITY-NAM-1                   *         
002500*     MOVE EU-ST-PVNC-CD TO EUX733-ST-PVNC-CD-1                 *         
002600*     MOVE EU-POST-CD    TO EUX733-POST-CD-1                    *         
002700*     MOVE EU-CTRY-CD    TO EUX733-CTRY-CD-1                    *         
002800*                                                               *         
002900*     MOVE NEW-ADDR-1-TXT TO EUX733-ADDR1-TXT-2                 *         
003000*     MOVE NEW-ADDR-2-TXT TO EUX733-ADDR2-TXT-2                 *         
003100*     MOVE NEW-ADDR-3-TXT TO EUX733-ADDR3-TXT-2                 *         
003200*     MOVE NEW-CITY-NAM   TO EUX733-CITY-NAM-2                  *         
003300*     MOVE NEW-ST-PVNC-CD TO EUX733-ST-PVNC-CD-2                *         
003400*     MOVE NEW-POST-CD    TO EUX733-POST-CD-2                   *         
003500*     MOVE NEW-CTRY-CD    TO EUX733-CTRY-CD-2                   *         
003600*                                                               *         
003700*     CALL WS-EUP733 USING EUX733-PARMS                         *         
003800*     IF EUX733-SCORE >= THRESHOLD-SCORE                        *         
003900*        THIS IS A VALID ADDRESS CHANGE                         *         
004000*     ELSE                                                      *         
004100*        THIS IS AN INVALID ADDRESS CHANGE.                     *
