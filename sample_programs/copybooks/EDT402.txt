      ****************************************************************          
      *  COPYBOOK:  EDT402                                           *          
      ****************************************************************          
      *                                                              *          
      * OVERVIEW:                                                    *          
      *  USED IN SUB-ROUTINE  EDV402 TO SUPPLY A CALLING PROGRAM     *          
      *  ACTIONS, DATA, AND AN AREA TO RETURN DATA AND RESULT CODE   *          
      *  INFORMATION.                                                *          
      *                                                              *          
      *     INPUT: EDV402-INPUT-DATA                                 *          
      *            - OBJECT ID                                       *          
      *            - ACTION CODE                                     *          
      *            - USER ID                                         *          
      *            - COMPANY CODE                                    *          
      *            - PARTNER ID                                      *          
      *     INPUT/OUTPUT: EDV402-INPUT-OUTPUT-ARRAY-AREA             *          
      *            - ARRAY COUNT                                     *          
      *            - EDV402-ARRAY (OCCURS UP TO 20 TIMES)            *          
      *              - EDV402-CO-CD                                  *          
      *              - EDV402-PARTNER-ID                             *          
      *              - EDV402-CREDIT-MEMO-FLG                        *          
      *              - EDV402-ASSET-TAG-FLG                          *          
      *              - EDV402-EDI-PO-FLG                             *          
      *              - EDV402-ZERO-VALUE-FLG                         *          
      *              - EDV402-REFUSAL-FLG                            *          
      *              - EDV402-COMPONENTS-FLG                         *          
      *              - EDV402-INTEREST-INV-FLG                       *          
      *              - EDV402-LST-CHG-TS                             *          
      *              - EDV402-LST-CHG-NAM                            *          
      *                                                              *          
      *    OUTPUT: EDV402-OUTPUT-DATA                                *          
      *          - EDV402-ROW-COUNT                                  *          
      *          - EDV402-MODULE-RESULT-CD                           *          
      *          - EDV402-MODULE-MESSAGE                             *          
      *          - EDV402-DATABASE-RESULT-CODES:                     *          
      *              - EDV402-SQLCA VALUES                           *          
      *              - EDV402-SQLCODE                                *          
      *              - EDV402-SQLSTATE                               *          
      *                                                              *          
      *                                                              *          
      *   EDV402 EXAMPLE FOR REQUESTING A SINGLETON SELECT ACTION.   *          
      *     INITIALIZE EDV402-COMMUNICATIONS-AREA.                   *          
      *     MOVE PGM-PARTNER-ID TO EDV402-PARTNER-ID.                *          
      *     MOVE 'S ' TO EDV402-ACTION-CD.                           *          
      *     MOVE 'IE_STORE_XREF     ' TO EDV402-OBJECT-ID.           *          
      *                                                              *          
      *     CALL 'EDV402' USING EDV402-COMMUNICATIONS-AREA.          *          
      *     IF EDV402-STATUS-OK                                      *          
      *     THEN                                                     *          
      *          CONTINUE WITH EXPECTED PROCESSING                   *          
      *     ELSE                                                     *          
      *          CONTINUE CHECK FOR DETAILED ERROR CONDITIONS AND    *          
      *          TAKE APPROPRIATE ACTIONS.                           *          
      *                                                              *          
      *      NOTE: THIS EXAMPLE SHOWS A TYPICAL CALL FROM AN         *          
      *            APPLICATION PROGRAM. IN THIS CASE THE PROGRAMMER  *          
      *            IS REQUESTING A SINGLETON SELECT ACTION TO RETURN *          
      *            DATA FOR A PARTICULAR PARTNER_ID.                 *          
      *                                                              *          
      *            THE PROGRAMMER SHOULD ALWAYS CHECK MODULE RESULT  *          
      *            CODE RETURNED FROM EDV402 TO VALIDTE THAT IT      *          
      *            WORKED PROPERLY (SEE THE COPYBOOK EDT402 FOR A    *          
      *            LIST OF ERROR CODES).                             *
