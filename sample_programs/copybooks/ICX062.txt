      *----------------------------------------------------------------*        
      *    ICX062: ICP062 INTERFACE PROVIDING VSAM FILE UPDATES                 
      *----------------------------------------------------------------*        
      * 08/09/19 MXV NEW INTERFACE FOR VSAM FILE UPDATES                MXV19221
      *----------------------------------------------------------------*        
      *    ACTION   DESCRIPTION                                                 
      *    UPDATE   READ AND REPLACE - OLD RECORD MUST EXIST.                   
      *    WRITE    WRITE            - OLD RECORD MUST NOT EXIST.               
      *    MERGE    WRITE NEW OR REPLACE OLD RECORD.                            
      *    DELETE   DELETE           - IGNORE MISSING RECORDS..                 
                                                                                
      *    ERROR CONTROL:                                                       
      *    IGNORE   - CONTINUE PROCESSING.  DEFAULT SETTING.                    
      *    ABEND    - ABEND ON ERRORS.                                          
      *    ROLLBACK - ROLLBACK CURRENT OPERATION,BUT CONTINUE PROCESSING        
                                                                                
      *    THE MODES ABOVE WILL COMMIT AFTER EACH OPERATION.                    
                                                                                
      *    ATOMIC   - ROLLBACK ALL OPERATIONS AND STOP.                         
      *               COMMIT AFTER LAST OPERATION.                              
                                                                                
       01  ICP062-INTERFACE.                                                    
           05  IC62-REQUEST-CONTROL.                                            
               10  IC62-ON-ERROR-SW              PIC X(01) VALUE SPACES.        
                   88  IC62-ON-ERROR-IGNORE      VALUE SPACES.                  
                   88  IC62-ON-ERROR-ABEND       VALUE 'B'.                     
                   88  IC62-ON-ERROR-ROLLBACK    VALUE 'R'.                     
                   88  IC62-ON-ERROR-ATOMIC      VALUE 'A'.                     
                                                                                
           05  IC62-REQUEST-DATA.                                               
               10  IC62-CNT                      PIC S9(04) COMP                
                                                 VALUE ZERO.                    
                   88  IC62-CNT-MAX              VALUE +25.                     
               10  IC62-REQUEST-ENTRY            OCCURS 25 TIMES                
                                                 INDEXED BY IC6X.               
                                                                                
                   15  IC62-ACTION               PIC X(01).                     
                       88  IC62-ACTION-UPDATE    VALUE 'U'.                     
                       88  IC62-ACTION-WRITE     VALUE 'W'.                     
                       88  IC62-ACTION-MERGE     VALUE 'M'.                     
                       88  IC62-ACTION-DELETE    VALUE 'D'.                     
                   15  IC62-FILE-NAME            PIC X(08).                     
                   15  IC62-KEY-LENGTH           PIC S9(04) COMP.               
                   15  IC62-REC-LENGTH           PIC S9(04) COMP.               
                   15  IC62-DATA                 PIC  X(1020).
