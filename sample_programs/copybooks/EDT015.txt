      *                                                              *          
      * OVERVIEW:                                                    *          
      *  USED IN SUB-ROUTINES EDV015 TO SUPPLY A CALLING PROGRAM     *          
      *  ACTIONS, DATA, AND AN AREA TO RETURN DATA AND RESULT CODE   *          
      *  INFORMATION.                                                *          
      *                                                              *          
      *     INPUT: EDV015-INPUT-DATA                                 *          
      *            - OBJECT ID                                       *          
      *            - ACTION CODE                                     *

      *            - COMPANY CODE                                    *          
      *            - PARTNER ID                                      *          
      *     INPUT/OUTPUT: EDV015-INPUT-OUTPUT-ARRAY-AREA             *          
      *            - ARRAY COUNT                                     *          
      *            - EDV015-ARRAY (OCCURS UP TO 20 TIMES)            *          
      *              - EDV015-CO-CD                                  *          
      *              - EDV015-PARTNER-ID                             *          
      *              - EDV015-BILL-TO-ADDR-FLG                       *          
      *              - EDV015-LINES-PRSNT-FLG                        *

      *              - EDV015-CREDIT-MEMO-FLG                        *          
      *              - EDV015-MISC-CHRG-FLG                          *          
      *              - EDV015-SERIAL-NBR-FLG                         *          
      *              - EDV015-SHIPPER-LINES-FLG                      *          
      *              - EDV015-ORDER-TYPE-FLG                         *          
      *              - EDV015-LST-CHG-TS                             *          
      *              - EDV015-LST-CHG-NAM                            *          
      *              - EDV015-ETA-DAYS                               *          
      *              - EDV015-XREF-CUST-PART-FLG                     *  SXP01141
      *              - EDV015-ORDR-PRNT-FLG                          *  JEH06233
      *              - EDV015-ORDR-CONF-SENT-FLG                     *  JEH06233

      *              - EDV015-RPT-BRK-CUST-FLG                       *  JEH06233
      *              - EDV015-RPT-BRK-SHIPTO-FLG                     *  JEH06233
      *              - EDV015-RPT-ORDR-STUS-CD                       *  JEH06233
      *                                                              *          
      *    OUTPUT: EDV015-OUTPUT-DATA                                *          
      *          - EDV015-ROW-COUNT                                  *          
      *          - EDV015-MODULE-RESULT-CD                           *          
      *          - EDV015-MODULE-MESSAGE                             *          
      *          - EDV015-DATABASE-RESULT-CODES:                     *          
      *              - EDV015-SQLCA VALUES                           *          
      *              - EDV015-SQLCODE                                *          
      *              - EDV015-SQLSTATE                               *          
      *                                                              *          
      *                                                              *          
      *   EDV015 EXAMPLE FOR REQUESTING A SINGLETON SELECT ACTION.   *          
      *     INITIALIZE EDV015-COMMUNICATIONS-AREA.                   *          
      *     MOVE PGM-PARTNER-ID TO EDV015-PARTNER-ID.                *          
      *     MOVE 'S ' TO EDV015-ACTION-CD.     .                     *          
      *     MOVE 'IE_OUT_ORDR_STS_SW' TO EDV015-OBJECT-ID.                      
      *                                                              *          
      *     CALL 'EDV015' USING EDV015-COMMUNICATIONS-AREA.          *          
      *     IF EDV015-STATUS-OK                                      *          
      *     THEN                                                     *          
      *          CONTINUE WITH EXPECTED PROCESSING                   *          
      *     ELSE                                                     *          
      *          CONTINUE CHECK FOR DETAILED ERROR CONDITIONS AND    *          
      *          TAKE APPROPRIATE ACTIONS.                           *          
      *                                                              *          
      *      NOTE: THIS EXAMPLE SHOWS A TYPICAL CALL FROM AN         *          
      *            APPLICATION PROGRAM. IN THIS CASE THE PROGRAMMER  *          
      *            IS REQUESTING A SINGLETON SELECT ACTION TO RETURN *          
      *            DATA FOR A PARTICULAR PARTNER_ID.                 *          
      *                                                              *          
      *            THE PROGRAMMER SHOULD ALWAYS CHECK MODULE RESULT  *          
      *            CODE RETURNED FROM EDV015 TO VALIDATE THAT IT     *          
      *            WORKED PROPERLY (SEE THE COPYBOOK EDT015 FOR A    *          
      *            LIST OF ERROR CODES).                             *
