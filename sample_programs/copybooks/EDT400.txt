      ***************************************************************           
      *  COPYBOOK:  EDT400                                          *           
      ***************************************************************           
      *                                                             *           
      * OVERVIEW:                                                   *           
      *  USED BY I/O MODULE SUBROUTINES AS THE PARAMETER            *           
      *  COMMUNICATIONS AREA TO CALL SUBROUTINE PROGRAM EDV400, THE *           
      *  AUDIT TRAIL LOGGING MODULE FOR MIE/REDI AND ABLE.          *           
      *                                                              *          
      *     INPUT: EDV400-INPUT-DATA                                 *          
      *            - ACTION CODE                                     *          
      *            - OBJECT ID                                       *          
      *            - PROGRAM NAME                                    *          
      *            - COMPANY CODE                                    *          
      *            - PARTNER ID                                      *          
      *            - USER ID                                         *          
      *            - TIMESTAMP                                       *          
      *            - BEFORE IMAGE LENGTH                             *          
      *            - BEFORE IMAGE ROW                                *          
      *            - AFTER  IMAGE LENGTH                             *          
      *            - AFTER  IMAGE ROW                                *          
      *                                                              *          
      *    OUTPUT: EDV400-OUTPUT-DATA                                *          
      *            - MODULE RESULT CODE                              *          
      *            - MODULE MESSAGE (IF ANY)                         *          
      *            - SQL CODE                                        *          
      *            - SQL STATE CODE                                  *          
      *            - SQL ERROR MESSAGE (IF ANY)                      *          
      *                                                              *          
      *   EDV400 EXAMPLE FOR REQUESTING A SINGLETON SELECT ACTION.   *          
      *     INITIALIZE EDV400-COMMUNICATIONS-AREA.                   *          
      *     MOVE PGM-PARTNER-ID TO EDV400-PARTNER-ID.                *          
      *     MOVE 'S '           TO EDV400-ACTION-CD.                 *          
      *     MOVE 'IE_OUT_ORDR_STS_SW' TO EDV400-OBJECT-ID.           *          
      *                                                              *          
      *     CALL 'EDV400' USING EDV400-COMMUNICATIONS-AREA.          *          
      *     IF EDV400-STATUS-OK                                      *          
      *     THEN                                                     *          
      *          CONTINUE WITH EXPECTED PROCESSING                   *          
      *     ELSE                                                     *          
      *          CONTINUE CHECK FOR DETAILED ERROR CONDITIONS AND    *          
      *          TAKE APPROPRIATE ACTIONS.                           *          
      *                                                              *          
      *      NOTE: THIS EXAMPLE SHOWS A TYPICAL CALL FROM AN         *          
      *            IMPULSE PROGRAM.  IN THIS CASE THE PROGRAMMER     *          
      *            WOULD LIKE TO SELECT THE COLUMN VALUES FOR A      *          
      *            PARTICULAR PARTNER_ID.                            *          
      *                                                              *          
      *            THE PROGRAMMER SHOULD ALWAYS CHECK THE RESULT     *          
      *            CODES RETURNED BY EDV400 TO MAKE SURE THAT THEY   *          
      *            WORKED PROPERLY (SEE THE COPYBOOK EDT400 FOR A    *          
      *            LIST OF ERROR CODES). ALSO, IF NO INFORMATION IS  *          
      *            FOUND FOR THIS SELECT, THE MODULE RESULT CODE WILL*          
      *            CONTAIN A VALUE OF 'NF', OR NOT FOUND FOR THE     *          
      *            PARTNER_ID SUPPLIED AS THE PRIMARY KEY.           *          
      *                                                              *
