      *             STRATEGIC PRICING MOVES - MULTIPLE SKUS           *         
      *                                                               *         
      * PURPOSE: STANDARD PROCEDURE DIVISION ROUTINES TO SETUP THE    *         
      *          PRICING PARAMETER AND HEADER AREAS TO SUPPORT        *         
      *          PRICING OF MULTIPLE SKUS                             *         
      *                                                               *         
      * USAGE:   COPY IN YOUR MULTIPLE SKU PRICING APPLICATION.       *         
      *          THIS VESION OF SP210 WILL BE PERFORMED BY SP200      *         
      *          (CONTAINED IN COPYBOOK SYSPMH). THE SP300            *         
      *          PARAGRAPH SHOULD BE PERFORMED BY THE APPLICATION     *         
      *          WHILE VARYING SYWSPSRQ-IDX FOR EACH REQUEST SKU      *         
      *          BEFORE THE SP900 STRATEGIC PRICING PARAGRAPH.        *         
      *                                                               *         
      *****************************************************************         
      *     REVISION LOG:                                             *         
      * 11/02/04 AXR       *** STRATEGIC PRICING - FULL SOLUTION ***  * AXR04307
      *               1. CREATED COPYBOOK.                            * AXR04307
      *                                                               *         
      *****************************************************************         
                                                                                
                                                                                
      **>>>-------------------------------------------------------<<<**         
      **>>> SETUP THE GENERAL REQUEST PARAMETERS TO SUPPORT A     <<<**         
      **>>> MULTIPLE SKU PRICING REQUEST.                         <<<**         
      **>>>                                                       <<<**         
      **>>>-------------------------------------------------------<<<**         
                                                                                
       SP210-SETUP-GENERAL-REQUEST.                                             
                                                                                
      *   (MULTI SKU APPLICATIONS SHOULD INITIALIZE EACH TABLE ARRAY)           
                                                                                
      *   (SET UP THE MULTI SKU DATA LAYOUT)                                    
           SET SYWSPP-LAYOUT-PRICING-MULT TO TRUE.                              
                                                                                
      *   (MULTI SKU APPLICATIONS SHOULD SET ACTUAL NUMBER OF REQUESTS)         
           MOVE 25                       TO SYWSPH-NBR-OF-REQUESTS              
                                         OF SYWSP-CONNECTOR-DATA.               
      *   (MULTI SKU APPLICATIONS SHOULD SET ACTUAL NUMBER OF RESPONSES)        
           MOVE 25                       TO SYWSPH-NBR-OF-RESPONSES             
                                         OF SYWSP-CONNECTOR-DATA.               
                                                                                
      *   (INITIALIZE THE REQUEST AND RESPONSE INDEXES TO 1)                    
           MOVE 1 TO SYWSPSRQ-IDX.                                              
           MOVE 1 TO SYWSPSRS-IDX.                                              
                                                                                
                                                                                
      **>>>-------------------------------------------------------<<<**         
      **>>> THIS ROUTINE IS PERFORMED TO SETUP THE MULTIPLE       <<<**         
      **>>> SKU PRICING REQUEST.                                  <<<**         
      **>>>                                                       <<<**         
      **>>>-------------------------------------------------------<<<**         
                                                                                
       SP300-SETUP-MULTI-SKU-REQUEST.                                           
                                                                                
      *   (SETUP LOGIC FOR A MULTIPLE SKU REQUEST WOULD BE DONE HERE)           
                                                                                
      *   (PERFORM COMMON SKU REQUEST SETUP LOGIC IN SP310)                     
           PERFORM SP310-SETUP-SKU-REQUEST.
