      * ------------------------------------------------------------ *          
      *   COMMAREA LENGTH  - SET BY THE SYXFLR COPYBOOK.                        
      *   ORDER-KEY        - MUST BE SET !                                      
      *   SHIPMENT-KEY     - REQUIRED TO PROCESS A SINGLE SHIPMENT.             
      *   DATABASE POINTER - SET IF YOU WANT TO LINK WITH PSB ALREADY           
      *                    - SCHEDULED BY INVOKING PROGRAM.                     
      *                    - RESHED BY SALESMAN NEEDED TO FIND OLD RESHE        
      *                    - ENTRIES.  DUPLICATES ON INSERTION ARE ALREA        
      *                    - HANDLED BY THE UPDATE PCB.                         
      *   PROCESS SWITCH:                                                       
      *        ORDER-LEVEL: USED DURING TRANSITION FROM ORDER LEVEL TO          
      *            SHIPMENT LEVEL PROCESSING.  ONE FLOORING APPLYS TO           
      *            ENTIRE SALES ORDER.   REFERENCED ONLY WHEN RECEIVING         
      *            FLOORING AUTHORIZATIONS BACK FROM THE PROVIDERS.             
      *                                                                         
      *        SHIPMENT-LEVEL: MULTIPLE FLOORING COMPANIES ARE                  
      *            APPLIED TO THE ORDER.  EACH TRANSMISSION APPLIES             
      *            TO A SINGLE SHIPMENT.                                        
      *                                                                         
      *   RESHED : PROCESS - BUILD ENTRIES FOR SALES,CAPS, & CREDIT HOLD        
      *          : DELETE  - DELETE ENTRIES ONLY !                              
      *          : SKIP    - NO PROCESSING.                                     
      *                                                                         
      *   PREVIOUS SHIP STATUS:  STATUS HAS ALREADY BEEN SUPPLIED BY            
      *      THE TIME ORP400 IS STARTED.  THIS IS USED                          
      *      WHEN DELETING PREVIOUS RESHED RECORD WHEN CHANGING STATUS          
      *      FROM ONE HOLD TO THE NEXT.  THE VECTOR INDEX IS THE DIST #.        
      *      THE SUFFIX MUST BE SUPPLIED FOR DELETING A SPECIFIC                
      *      BILL-TO SUFFIX ENTRY WHEN SPLIT-BILLING IS USED, OTHERWISE         
      *      ALL ENTRIES FOR THAT DIST/SHIP ARE DELETED.                        
      *                                                                         
      *   ORSSTO : PROCESS - BUILD ENTRIES AS NEEDED.                           
      *          : SKIP    - NO PROCESSING.                                     
      *                                                                         
      *   FLOORING: SEND   - SEND THE FLOORING TRANSACTION                      
      *           : SKIP   - NO PROCESSING.                                     
      *   FLOORING SEND SUFFIX:  ALLOWS A SPECIFIC BILL-TO SUFFIX               
      *           TO BE SENT.  THIS IS USED IN CREDIT RELEASE.                  
      *           THE DEFAULT IS TO SEND ALL FLOORING ENTRIES.                  
      *   OLD INSIDE-SALESMAN :  ALLOWS FOR I/S SALESMAN CHANGES.               
      *   OLD BILL-TO SUFFIX  :  ALLOWS FOR BILL-TO SUFFIX CHANGES.             
      *                                                                         
      *   PREVIOUS PROCESS:  WHAT TYPE OF FUNCTION INITIATED THE PROCESS        
      *                                                                         
      *   CUSTOMER VECTOR: IF THE PROGRAM IS REPEATEDLY LINKED-TO               
      *           FOR DIFFERENT SHIPMENTS OF THE SAME ORDER, THEN               
      *           THIS SAVE AREA WILL HOLD CUSTOMER DATA SO IT DOESN'T          
      *           NEED TO BE REBUILT.  ?????????                                
      *      MIGHT BE A WASTED EFFORT AS THE TASK IS LIKELY 'STARTED'
