      *ICSVRSVU-K110-REPL-INSLOR.                                               
      ******************************************************************

           END-IF.                                                      AXR05234
                                                                                
      *   (CALCULATE HOW MUCH OF RQST QTY CAN BE APPLIED TO SEQUENCE)           
      *   EXAMPLES WHERE REQUESTED QUANITY = 10                                 
      *                                                 VISRSV                  
      *      RESERVE-QTY  QTY-SHIPPED-TO-DATE  NETQTY   SEQQTY                  
      *      ===========  ===================  ======   ======                  
      *           100             100            0        0  :CASE1     AXR05234
      *           100              75           25       10  :CASE2     AXR05234
      *           100              90           10       10  :CASE2     AXR05234
      *           100              98            2        2  :CASE3     AXR05234
                                                                                
      *   (DETERMINE HOW MUCH OF RQST QTY CAN BE APPLIED FROM SEQUENCE) AXR05234
           EVALUATE TRUE

      *   (UPDATE INSLOR SEQUENCE WHEN RESERVE QUANTITY CAN BE APPLIED) AXR05234

              ADD ICWVRSV-VISRSV-SEQQTY      TO INL-QTY-SHIPPED-TO-DATE

              MOVE 'N'                       TO WS-INSLOR-IO-SW

      *         (AFTER THE UPDATE, FORMAT AND WRITE THE RESERVE AUDIT)  AXR05234

           END-IF.

           ADD 1                             TO ICWVRSV-ORSCAP-COUNT.           
                                                                                
           INITIALIZE ICWVRSV-ORSCAP-DATA (ICWVRSV-ORSCAP-COUNT).       AXR05234
                                                                        AXR05234

      *ICSVRSVU-K200-UPDT-INSBRN-RSV.                                           
      ******************************************************************

      *                                                                *        
      ******************************************************************

      *   (UPDATE TOTAL RESERVE QUANTITY ON INSBRN FOR SKU/BR)                  
           MOVE 'N'                          TO WS-INSBRN-IO-SW

           IF WS-INSBRN-NORESP                                                  
      *     (TEMPQTY CAN BE POSITIVE OR NEGATIVE ADJUSTMENT QTY)                
              IF INB-RES-QTY NUMERIC                                    AXR05234
                 COMPUTE INB-RES-QTY = INB-RES-QTY + ICWVRSV-TEMPQTY    AXR05234
              END-IF                                                    AXR05234
      *     (THE BRANCH RESERVE TOTAL CAN NOT BE NEGATIVE)              AXR05234
             IF INB-RES-QTY NEGATIVE                                    AXR05234
                MOVE ZERO                    TO INB-RES-QTY             AXR05234
             END-IF                                                     AXR05234
             MOVE 'N'                        TO WS-INSBRN-IO-SW                 
             PERFORM 1650-REPL-INSBRN

                SET ICWVRSV-STATUS-IO-ERR    TO TRUE

           ELSE                                                                 
              SET ICWVRSV-STATUS-IO-ERR      TO TRUE                            
              SET ICWVRSV-DONE-YES           TO TRUE                            
           END-IF.                                                              
                                                                                
                                                                                
      *ICSVRSVU-L000-REVERSE-VRSV-LN.                                           
      **>>>-------------------------------------------------------<<<**         
      **>>>-------------------------------------------------------<<<**         
      **>>> THIS ROUTINE RETRIEVES ALL THE RESERVE INVENTORY      <<<**         
      **>>> ORSCAP SEGMENTS ASSOCIATED TO AN ORDER LINE,          <<<**         
      **>>> REVERSING THE CORRESPONDING INSLOR SEGMENT DATA.      <<<**         
      **>>> IT ASSUMES THAT THE ORSLNE HAS ALREADY BEEN READ.     <<<**         
      **>>>                                                       <<<**

      ******************************************************************

      *   (ASSUME NO MATCHING INSLOR CORRESPONDS TO ORSCAP)                     
           MOVE 'N'                          TO ICWVRSV-MATCH-IND.              
                                                                                
      *   (SETUP INSLOR SSA WITH DATA FROM ORSCAP)

      *   (VERIFY THAT MATCHING INSLOR FOUND FOR CURRENT ORSCAP)

              AND INL-RSV-VISIBLE                                               
              AND INL-CUST-BR-NBR      = ORC-VRS-CUST-BR-NBR                    
              AND INL-CUST-NBR         = ORC-VRS-CUST-NBR                       
              AND INL-CUST-SEQ         = ORC-VRS-CUST-SEQ                       
              AND INL-EFFECT-DATE      = ORC-EFFECT-DATE
