      *                                                              *          
      * OVERVIEW:                                                    *          
      *  USED IN SUB-ROUTINES EDV018 TO SUPPLY A CALLING PROGRAM     *          
      *  ACTIONS, DATA, AND AN AREA TO RETURN DATA AND RESULT CODE   *          
      *  INFORMATION.                                                *          
      *                                                              *          
      *     INPUT: EDV018-INPUT-DATA                                 *          
      *            - OBJECT ID                                       *          
      *            - ACTION CODE                                     *          
      *            - USER ID                                         *          
      *            - COMPANY CODE                                    *          
      *            - PARTNER ID                                      *          
      *     INPUT/OUTPUT: EDV018-INPUT-OUTPUT-ARRAY-AREA             *          
      *            - ARRAY COUNT                                     *          
      *            - EDV018-ARRAY (OCCURS UP TO 20 TIMES)            *          
      *              - EDV018-CO-CD                                  *          
      *              - EDV018-PARTNER-ID                             *          
      *              - EDV018-PARTNER-DES                            *          
      *              - EDV018-PRNT-PARTNER-ID                        *          
      *              - EDV018-ACTV-DT                                *          
      *              - EDV018-DEACTV-DT                              *          
      *              - EDV018-NOTE-TXT                               *          
      *              - EDV018-LST-CHG-TS                             *          
      *              - EDV018-LST-CHG-NAM                            *          
      *              - EDV018-PRCS-OPTN-FLG                          *  MOG02107
      *              - EDV018-CYCLE-INTVL                            *  TWA04180
      *              - EDV018-CYCLE-LST-RUN-TS                       *  TWA04180
      *              - EDV018-CYC-STRT-TM                            *  VMA07052
      *              - EDV018-CYC-END-TM                             *  VMA07052
      *              - EDV018-BATCH-SPLIT-CNT                        *  AZS06045
      *                                                              *          
      *    OUTPUT: EDV018-OUTPUT-DATA                                *          
      *          - EDV018-ROW-COUNT                                  *          
      *          - EDV018-MODULE-RESULT-CD                           *          
      *          - EDV018-MODULE-MESSAGE                             *          
      *          - EDV018-DATABASE-RESULT-CODES:                     *          
      *              - EDV018-SQLCODE                                *          
      *              - EDV018-SQLSTATE                               *          
      *              - EDV018-SQL-MESSAGE                            *          
      *                                                              *          
      *                                                              *          
      *   EDV018 EXAMPLE FOR REQUESTING A SINGLETON SELECT ACTION.   *          
      *     INITIALIZE EDV018-COMMUNICATIONS-AREA.                   *          
      *     MOVE PGM-PARTNER-ID TO EDV018-PARTNER-ID.                *          
      *     MOVE 'S ' TO EDV018-ACTION-CD.     .                     *          
      *     MOVE 'IE_PARTNER_SETUP  ' TO EDV018-OBJECT-ID.           *          
      *                                                              *          
      *     CALL 'EDV018' USING EDV018-COMMUNICATIONS-AREA.          *          
      *     IF EDV018-STATUS-OK                                      *          
      *     THEN                                                     *          
      *          CONTINUE WITH EXPECTED PROCESSING                   *          
      *     ELSE                                                     *          
      *          CONTINUE CHECK FOR DETAILED ERROR CONDITIONS AND    *          
      *          TAKE APPROPRIATE ACTIONS.                           *          
      *                                                              *          
      *      NOTE: THIS EXAMPLE SHOWS A TYPICAL CALL FROM AN         *          
      *            APPLICATION PROGRAM. IN THIS CASE THE PROGRAMMER  *          
      *            IS REQUESTING A SINGLETON SELECT ACTION TO RETURN *          
      *            DATA FOR A PARTICULAR PARTNER_ID.                 *          
      *                                                              *          
      *            THE PROGRAMMER SHOULD ALWAYS CHECK MODULE RESULT  *          
      *            CODE RETURNED FROM EDV018 TO VALIDTE THAT IT      *          
      *            WORKED PROPERLY (SEE THE COPYBOOK EDT018 FOR A    *          
      *            LIST OF ERROR CODES).                             *
