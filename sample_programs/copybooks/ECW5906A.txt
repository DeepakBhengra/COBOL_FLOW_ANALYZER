       5906-GET-REMOTE-TBX-FLDS.                                                
                                                                                
      * THIS PROGRAM NEEDS SOME TBXCORP FIELDS FROM THE LOCAL TBLMST            
      * AND SOME FIELDS FROM THE TBLMST OF THE REGION WHERE THE ORDER           
      * WAS ENTERED. FOR ECW USERS THESE MAY NOT BE THE SAME REGION.            
      * USE COPY ... REPLACING == .. == BY == .. == TO MAKE THIS                
      * ROUTINE GET THE REMOTE FIELDS THAT YOUR PROGRAM NEEDS.                  
      * EXAMPLE :                                                               
      *                                                                         
      *    COPY ECW5906A REPLACING                                      JWO93341

      *         == WS-ECW03X == BY                                      JWO93341
      *         == TB-CPO-BILL-CONTROL-SW ==                            JWO93341
      *         == WS-ECW04X == BY                                      JWO93341
      *         == WS-CPO-BILL-CONTROL-SW ==.                           JWO93341
