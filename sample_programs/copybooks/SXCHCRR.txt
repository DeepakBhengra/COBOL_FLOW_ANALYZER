      *                   TIBCO Substation ES CICS                   *          
      *                   ------------------------                   *          
      *                                                              *          
      * DESCRIPTION -  Request/Reply(R/R) Interface Comms Area       *          
      *                                                              *          
      * FUNCTION    -  COMMAREA passed to R/R control program        *          
      *                (SXCREQR)                                     *          
      *                                                              *          
      * Reply          The reply routine will truncate data          *          
      *                if the RRI-User-Data area is not large        *          
      *                enough to contain the reply received          *          
      *                An RC = 4 and Rsn = 3908 is returned          *          
      *                                                              *          
      * NOTES:         The first 64 bytes are for the R/R Interface  *          
      *                header and the order of the fields specified  *          
      *                in this structure MAY NOT be altered.         *

      *      Request/Reply Interface Communications Area             *          
      *                                                              *          
      *==============================================================*          
                                                                                
         01  WS-RRI-Header-Len         PIC S9(4)  COMP   VALUE 64.              
         01  WS-RRI-Header-Len-FW      PIC S9(8)  COMP   VALUE 64.              
                                                                                
         01  WS-RRI-COMMAREA.                                                   
             05  WS-RRI-Header.                                                 
                 10  RRI-Reqst-Option  PIC  X         USAGE DISPLAY.            
      *                 INDICATE SEND OPTIONS - REQUIRED                        
      *  Default        C = User Data is part of this structure                 
      *                     and placed within the RRI-User-Data field           
                 10  RRI-Reply-Option  PIC  X         USAGE DISPLAY.            
      *                 INDICATE SEND OPTIONS - REQUIRED                        
      *  Default        T = Reply Data is written to a TSQ and the              
      *                     name of the TSQ is placed in the                    
      *                     RRI-Tsq-Name field                                  
      *                 C = Reply Data will be placed within this               
      *                     structure in the RRI-User-Data field                
                 10  RRI-Reserved      PIC  X(2)      USAGE DISPLAY             
                                                      VALUE SPACES.             
                 10  RRI-Wait-4-Reply  PIC  9(4)      USAGE COMP.               
      *                   = Value in seconds from 0 thru 60.                    
                 10  RRI-Data-Len      PIC  9(4)      USAGE COMP.               
      *                     User Data length for Request data.                  
      *                     This is the length of the sent data.                
      *                     When Reply_Option = C the reply length is           
      *                     determined from the commarea passed to              
      *                     the Substation CICS Requestor(SXCREQR)              
      *                     during the "CICS LINK" command.                     
                 10  RRI-Reserved2     PIC  X(20)     USAGE DISPLAY.

                 10  RRI-Reason        PIC S9(8)      USAGE COMP.               
                 10  RRI-Tsq-Name      PIC  X(8)      USAGE DISPLAY.
