      *****************************************************************         
      *  EUSPHN15 - PROCEDURE COPYBOOK TO EDIT A PHONE NUMBER         *         
      *                                                               *         
      *  DESCRIPTION: EDITS AN INPUT PHONE NUMBER.                    *         
      *                                                               *         
      *  COPY MEMBER EUWPHN15 FOR WORKING STORAGE IS USED WITH THIS   *         
      *  PROCEDURE DIVISION COPY MEMBER.  EUWPHN15 CONTAINS AN        *         
      *  A DESCRIPTION AND EXAMPLE OF USE OF THESE COPY MEMBERS.      *         
      *                                                               *         
      *****************************************************************         
      * REVISIONS:                                                    *         
      * 01/20/2003 ERR INITIAL.                                       * ERR03020
      *****************************************************************         
                                                                                
       765-EDIT-AND-FORMAT-PHONE.                                               
                                                                                
           SET WS-PHONE-OK TO TRUE                                              
                                                                                
           SET WS-P2-IDX   TO 1                                                 
                                                                                
           INITIALIZE WS-WORK-PHONE-OUT                                         
                      WS-WORK-PHONE-MSG                                         
                                                                                
      *                                                                         
      *-------- ALLOW ALPHA AND NUMERIC VALUES IN PHONE NUMBER                  
           PERFORM VARYING WS-P1-IDX FROM 1 BY 1                                
             UNTIL WS-P1-IDX > 15                                               
              IF (WS-WORK-PHONE-IN-CHAR (WS-P1-IDX) >= 'A'                      
                 AND WS-WORK-PHONE-IN-CHAR (WS-P1-IDX) <= '9')                  
                 MOVE WS-WORK-PHONE-IN-CHAR  (WS-P1-IDX)                        
                   TO WS-WORK-PHONE-OUT-CHAR (WS-P2-IDX)                        
                 SET WS-P2-IDX  UP BY 1                                         
              END-IF                                                            
           END-PERFORM                                                          
                                                                                
           IF WS-WORK-PHONE-OUT = SPACE                                         
              SET WS-PHONE-ERR-BLANK TO TRUE                                    
              MOVE 'INVALID PHONE NUMBER, IT MAY NOT BE SPACES'                 
                TO WS-WORK-PHONE-MSG.                                           
                                                                                
       765-EXIT.                                                                
           EXIT.
