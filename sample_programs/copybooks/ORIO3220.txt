      * 09/09/95 SAM SSA FOR LINE TYPE SEARCH CALL                     *SAM95249
      ******************************************************************        
           CALL 'CBLTDLI' USING        GN                                       
                                       ORPCB                                    
                                       ORL-ORSLNE                               
                                       WS-ORSHED-SSA                            
                                       WS-ORSSHH-SSA                            
                                       WS-ORSLNE3-SSA.                          
           IF ORPCB-NORESP                                                      
               MOVE 'Y'                TO  WS-ORSLNE-IO-SW                      
           ELSE                                                                 
               IF ORPCB-NOTFND                                                  
                   MOVE 'N'            TO  WS-ORSLNE-IO-SW                      
               ELSE                                                             
                   IF ORPCB-ENDFLE                                              
                       MOVE 'E'        TO  WS-ORSLNE-IO-SW                      
                   ELSE                                                         
                       MOVE '3220'     TO  WS-ABCODE                            
                       MOVE ORPCB-STS  TO  WS-STATUS                            
                       MOVE 'DL/1'     TO  WS-ERROR-CODE                        
                       MOVE SPACES     TO  WS-ERROR-OPTIONAL-DATA               
                       MOVE ORPCB      TO  WS-ERROR-DL1-PCB                     
                       MOVE WS-ABCODE  TO  WS-ERROR-DL1-ABCODE                  
                       PERFORM 999-ABEND.                                       
           IF NOT ORPCB-ENDFLE                                                  
               IF ORPCB-ORDER-KEY NOT EQUAL WS-ORSHED-KEY-VALUE                 
                  OR ORPCB-SHIP-KEY NOT EQUAL WS-ORSSHH-KEY-VALUE               
                   MOVE 'K'            TO  WS-ORSLNE-IO-SW.
