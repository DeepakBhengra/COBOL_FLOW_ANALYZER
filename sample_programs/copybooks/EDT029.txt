      ****************************************************************          
      *  COPYBOOK:  EDT029                                           *          
      ****************************************************************          
      *                                                              *          
      * OVERVIEW:                                                    *          
      *  USED IN SUB-ROUTINES EDV029 TO SUPPLY A CALLING PROGRAM     *          
      *  ACTIONS, DATA, AND AN AREA TO RETURN DATA AND RESULT CODE   *          
      *  INFORMATION.                                                *          
      *                                                              *          
      *     INPUT: EDV029-INPUT-DATA                                 *          
      *            - OBJECT ID                                       *          
      *            - ACTION CODE                                     *          
      *            - USER ID                                         *          
      *            - COMPANY CODE                                    *          
      *            - PARTNER ID                                      *          
      *     INPUT/OUTPUT: EDV029-INPUT-OUTPUT-ARRAY-AREA             *          
      *            - ARRAY COUNT                                     *          
      *            - EDV029-ARRAY (OCCURS UP TO 20 TIMES)            *          
      *              - EDV029-CO-CD                                  *          
      *              - EDV029-PARTNER-ID                             *          
      *              - EDV029-CREDIT-MEMO-FLG                        *          
      *              - EDV029-ASSET-TAG-FLG                          *          
      *              - EDV029-EDI-PO-FLG                             *          
      *              - EDV029-ZERO-VALUE-FLG                         *          
      *              - EDV029-REFUSAL-FLG                            *          
      *              - EDV029-COMPONENTS-FLG                         *          
      *              - EDV029-INTEREST-INV-FLG                       *          
      *              - EDV029-LST-CHG-TS                             *          
      *              - EDV029-LST-CHG-NAM                            *          
      *                                                              *          
      *    OUTPUT: EDV029-OUTPUT-DATA                                *          
      *          - EDV029-ROW-COUNT                                  *          
      *          - EDV029-MODULE-RESULT-CD                           *          
      *          - EDV029-MODULE-MESSAGE                             *          
      *          - EDV029-DATABASE-RESULT-CODES:                     *          
      *              - EDV029-SQLCA VALUES                           *          
      *              - EDV029-SQLCODE                                *          
      *              - EDV029-SQLSTATE                               *          
      *                                                              *          
      *                                                              *          
      *   EDV029 EXAMPLE FOR REQUESTING A SINGLETON SELECT ACTION.   *          
      *     INITIALIZE EDV029-COMMUNICATIONS-AREA.                   *          
      *     MOVE PGM-PARTNER-ID TO EDV029-PARTNER-ID.                *          
      *     MOVE 'S ' TO EDV029-ACTION-CD.     .                     *          
      *     MOVE 'IE_SPECIAL_LABEL' TO EDV029-OBJECT-ID.             *          
      *                                                              *          
      *     CALL 'EDV029' USING EDV029-COMMUNICATIONS-AREA.          *          
      *     IF EDV029-STATUS-OK                                      *          
      *     THEN                                                     *          
      *          CONTINUE WITH EXPECTED PROCESSING                   *          
      *     ELSE                                                     *          
      *          CONTINUE CHECK FOR DETAILED ERROR CONDITIONS AND    *          
      *          TAKE APPROPRIATE ACTIONS.                           *          
      *                                                              *          
      *      NOTE: THIS EXAMPLE SHOWS A TYPICAL CALL FROM AN         *          
      *            APPLICATION PROGRAM. IN THIS CASE THE PROGRAMMER  *          
      *            IS REQUESTING A SINGLETON SELECT ACTION TO RETURN *          
      *            DATA FOR A PARTICULAR PARTNER_ID.                 *          
      *                                                              *          
      *            THE PROGRAMMER SHOULD ALWAYS CHECK MODULE RESULT  *          
      *            CODE RETURNED FROM EDV029 TO VALIDTE THAT IT      *          
      *            WORKED PROPERLY (SEE THE COPYBOOK EDT001 FOR A    *          
      *            LIST OF ERROR CODES).                             *          
      *                                                              *
