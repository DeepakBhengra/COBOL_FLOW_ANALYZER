      *  COPY SYXEXT                                                            
      * PURPOSE:  USED FOR CHINA.  CHINA USES GB2312 FORMAT FOR                 
      *  PRINTING.  GB2312 IS AN ASCII FORMAT THAT HAS CHINESE CHAR.            
      *  CHINA ALSO USES AN OLD UNSUPPORTED EMULATOR CALLED "EXTRA".            
      *  'EXTRA' SAVE THE DATA IN EBCDIC FORMAT.   SO IT USES SIMPLE            
      *  SINGLE BYTE TRANSLATION, EVEN THOUGH CHINESE CHARACTERS ARE            
      *  IN DOUBLE BYTE FORMAT.  THE FINAL FORMAT ON MAINFRAME IN               
      *  'EXTRA' FORMAT IS NOT ACCORDING TO ANY STANDARD, BUT WHAT              
      *  'EXTRA' USES.   WE NEED TO DO ISO 8559-1 TO CODEPAGE 037               
      *  SINGLE BYTE TRANSLATION  WHEN BRINGING IN DATA FROM OUTSIDE            
      *  SOURCES (IE WEB).  WEB WILL PROVIDE DATA IN UTF8 FORMAT FOR            
      *  CERTAIN FIELDS THAT CAN CONTAIN CHINESE CHARACTERS.  INSIDE            
      *  LINE WILL CONVERT THOSE FIELDS FROM UTF8 TO GB2312 (CODEPAGE           
      *  1383) USING STANDARD COBOL FUNCTION COMMANDS.  THEN THIS               
      *  CODE WILL BE USED TO CONVERT THE GB2312 FORAMT INTO EBCDIC             
      *  FORMAT THAT EMULATOR 'EXTRA' USES ON MAINFRAME.                        
      *  SAME FOR DATA GOING FROM MAINFRAME BACK TO WEB.  HERE WE FIRST         
      *  CONVERT 037 TO GB2312. THEN INSIDE LINE PGMS WILL CONVERT THE          
      *  GB2312 TO UTF8 USING NORMAL COBOL FUNCTION COMMANDS.
