      * HOW TO USE THIS ROUTINE WITHIN AN INVOKING PROGRAM:                     
      * ---------------------------------------------------                     
      *   >FOR EXAMPLE OF THESE STEPS, SEE ORP610MD, CFP521IM, OTHERS<          
      * 1. ADD CFWAG62 W/S COPYBOOK TO DEFINE REQUIRED I/O VARIABLES            
      * 2. ADD TBICORP3 W/S COPYBOOK TO DEFINE CO TABLE3 I/O VARIABLES          
      * 3. ADD CFSLOGST PROC/DIV COPYBOOK TO INCLUDE THIS ROUTINE               
      *    (USE 'COPY REPLACING' IF DATA NOT FROM ORH-, ORSH-, TC-)             
      * 4. AT PROGRAM DB COMMIT POINT, INITIALIZE CFWAG62-ORDER-STATUS          
      * 5. MOVE PROGRAM-SPECIFIC VALUES TO THE FOLLOWING CFWAG62 FIELDS:        
      *    PROGRAM-NAME, UPDATE-TEXT, CHANGE-TYPE (USE SET OF 88 LEVEL)         
      *    AND OPTIONALLY POPULATE ANY OTHER FIELDS.  IF THE STANDARD           
      *    KEY MOVES IN THIS COPYBOOK DO NOT APPLY TO YOUR SITUATION,           
      *    THEN USE THE COPY REPLACING OPTION TO OVERRIDE THEM.                 
      *    TO REDUCE REDUNDANT I/O, MOVE VALUES TO THE CFWAG62 FIELDS   AXR02070
      *    FROM TBICORP3, TBICORP4 AND/OR CUSHED, OTHERWISE             AXR02070
      *    THIS ROUTINE AND/OR CFP062 WILL HAVE TO RE-DO THE I/O.       AXR02070
      * 6. PERFORM 000-CFSLOGST-LOG-ORDER-STATUS THRU 000-CFSLOGST-EXIT         
      * 7. SINCE THE CONDITIONAL LOGGING IS ASYNCHRONOUS, THERE IS              
      *    NO FURTHER STATUS CHECKING AVAILALBLE (OR REQUIRED).                 
      *                                                                         
      * GENERAL NOTES ABOUT THIS ROUTINE:                                       
      * ---------------------------------                                       
      * 1. INPUT INCLUDES: ORDER INFORMATION, INCLUDING IT'S STATUS,            
      *    WHO PUT IT INTO THE CURRENT STATUS, STATUS TEXT, ETC.                
      * 2. PROCESSING CAN ACCESS: TBXCORP3 AND TBXCORP4                 AXR02070
      *    -I/O ONLY PERFORMED IF NOT ALREADY POSITIONED PROPERLY               
      * 3. OUTPUT INCLUDES: NONE (SEE STARTED PROGRAM CFP062 FOR TABLES)        
      *    ALSO SEE TABLES MAINTAINED BY STARTED PROGRAMS ORP063, ORP064AXR02070
