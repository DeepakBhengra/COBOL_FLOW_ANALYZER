*******  MESSAGING SUBSYSTEM WITHIN THE NOTES DATA BASE.                JMK98362
*******  1. THE NOTES -MESSAGE STRUCTURE:                               JMK98362
******* 'CC Z XXXX KKKKKKKKKKKK DDD MT NNN TTTEXT......'                JMK98362
*******  CC    =    COUNTRY ISO CODE, IE GERMANY IS 'DE'                JMK98362
*******    Z        NOTES TYPE WHERE Z WILL BE FOR MESSAGES             JMK98362
*******     XXXX    SPACES                                              JMK98362
*******     KKKKKKKKKKKK    THIS IS USED FOR THE 'KEY' TO THE DATA, IE IJMK98362
*******                     ITEM, VENDOR CUSTOMER NUMBER OR MESSAGE     JMK98362
*******                     KEY ETC..                                   JMK98362
*******     DDD    THIS IS THE DATE OF THE NOTE                         JMK98362
*******     MT     MESSAGE TYPE (SEE BELOW)                             JMK98362
*******     NNN    LINE NUMBER                                          JMK98362
*******     TTTEXT...THE TEXT OF THE MESSAGE(NOTE: IF THESE ARE FOR     JMK98362
*******            INVOICES ETC, LIMITED TO 35 CHARACTERS / LINE.       JMK98362
*******                                                                 JMK98362
******* MESSAGE TYPE                    DEFAULT PRINT LOCATION          JMK98362
*******  SM = SALES MESSAGES             - LAST-INVOICE SPECIFIC        JMK98362
*******  IM = ITEM/PRODUCT  MESSAGES     - AFTER                        JMK98362
*******  PO = PURCHASE ORDER MESSAGES    - LAST                         JMK98362
*******  VN = VENDOR MESSAGES            - AFTER                        JMK98362
*******  CM = CUSTOMER MESSAGES          - FIRST                        JMK98362
*******  SA = SERVICE ADDRESS MESSAGES   - AFTER                        JMK98362
*******  WA = WARRANTY MESSAGES          - AFTER                        JMK98362
*******  EX = EXPORT MESSAGES            - TOP-                         JMK98362
*******  PM = PROMOTIONAL MESSAGE(SALES) - TOP-                         JMK98362
*******  TM = ADDITIONAL TERMS MESSAGES  - TOP-INVOICE OR PURCHASE ORDERJMK98362
*******  BI = BILLING MESSAGES           - LAST PACK SLIP / INVOICE     JMK98362
*******  XD = VIPER XTRA DESC            - AFTER                        JER01192
*******                                                                 JMK98362
******* F OR FULFILLMENT MESSAGES RELATE TO DROP SHIPMENTS OF OUR CUST  JMK98362
*******  FM = FULFILLMENT MESSAGE    - FIRST INVOICE                    JMK98362
*******  FR = FULFILLMENT RETURNS    - FIRST-WHERE/HOW TO HANDLE RETURNSJMK98362
*******  FT = FULFILLMENT TECH SUPPORT - FIRST- NBR TO CALL FOR TECH    JMK98362
*******                                         SUPPORT                 JMK98362
*******                                                                 JMK98362
******* TYPE OF DOCUMENT    VALUES ARE:                                 JMK98362
*******            I = INVOICE                                          JMK98362
*******            P= PURCHASE ORDER                                    JMK98362
*******            S = PACKING SLIP                                     JMK98362
*******            A = ALL DOCUMENTS                                    JMK98362
*******            B = BOTH PACKING SLIP AND INVOICE                    JMK98362
******* WHERE TO PRINT    VALUES ARE:                                   JMK98362
*******   L = LAST ON THE DOCUMENT (MEANS WILL PRINT AFTER ALL LINES ON JMK98362
*******        THE  DOCUMENT, BUT BEFORE TOTALS LINES)                  JMK98362
*******   F = FIRST ON THE DOCUMENT (MEANS WILL PRINT BEFORE THE LINES  JMK98362
*******       ON THE DOCUMENT BEGIN TO PRINT.)                          JMK98362
*******   A =  AFTER  THE LINE HAS PRINTED, THEN THE MESSAGES WILL PRINTJMK98362
*******   B =  BEFORE THE LINE HAS PRINTED, THE MESSAGES WILL PRINT).   JMK98362
*******  'BL' = USE DEFAULT LOCATION (BL = SPACES OR BLANK)             JMK98362
