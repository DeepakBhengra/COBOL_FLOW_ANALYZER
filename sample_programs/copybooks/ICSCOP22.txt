      *================================================================*        
      *  PURPOSE:                                                      *        
      *  =======                                                       *        
      *  THIS COPYBOOK IS USED TO POPULATE THE FIELDS USED IN LOGGING  *        
      *  ORDER LINE AND ACOP DETAILS WHOSE ORDER LINE GETS THE BEST    *        
      *  ACOP APPLIED USING ICPCOP AND WHEN AN ORDER/ORDER LINE IS     *        
      *  DELETED, THE ACOP MAX/MAQ QUANTITIES ARE RESET THROUGH ICP060.*        
      *  THESE FIELDS WILL BE USED ONLY                                *        
      *  WHEN MAX/MAQ LIMIT IS PRESENT FOR THE ACOP THAT IS APPLIED    *        
      *  TO THE ORDER LINE.                                            *        
      *  THIS FUNCTIONALITY WILL BE ENABLED ONLY WHEN                  *        
      *  TB-ACOP-MAQ-MAX-DB2-TRAC-SW IS TURNED ON.                     *        
      *                                                                *        
      *  TO LOG THE CHGS IN MAX/MAQ QUANTITIES FOR AN ACOP VIA ICPCOP, *        
      *  THE PROGRAM NEEDS LINE NUMBER, PGM ID, ENTRY DATE AND THE     *        
      *  DESCRIPTION OF THE FUNCTION THAT IS BEING PERFORMED FOR UPDT  *        
      *  IN MAX/MAQ QUANTITIES.                                        *        
      *  ICWCOP-MAX-MAQ-LG-EVENT-IDX - +10 MEANS 10TH EVENT PRESENT    *        
      *  UNDER ICWCOP20-ACOP-MAX-MAQ-EVNT-TYP VARIABLE WILL BE         *        
      *  PROCESSED.                                                    *        
      *                                                                *        
      *  USED IN THE PROGRAMS WHICH CALLS ICPCOP SUBROUTINE TO APPLY   *        
      *  ACOP FOR THE ORDER LINE OR IN PROGRAMS WHICH CALLS ICP060.    *        
      *                                                                *        
      *  THIS LOGIC IS CALLED BEFORE C100-CALL-COST-RTN OR WHEN ICP060 *        
      *  PROGRAM IS CALLED WHEN ORDER/ORDER LINE IS DELETED.           *        
      *================================================================*

      * REVISION INFO:                                                 *

      *              ORDER LINE DETAILS.                               *SPR20059
      *================================================================*

       M100-MOVE-ORD-LOG-DTL.                                                   
                                                                                
           MOVE ICWCOP20-LINE-NBR      TO ICWCOP-ORD-LINE-NBR.                  
           MOVE ICWCOP20-CALLED-PGM-ID TO ICWCOP-CALLED-PGM-ID.                 
           MOVE ICWCOP20-ORH-ENTRY-DT  TO ICWCOP-ORDER-DT.                      
           MOVE ICWCOP20-MAX-MAQ-LG-EVENT-IDX                                   
                                       TO ICWCOP-MAX-MAQ-LG-EVENT-IDX.          
                                                                                
       M100-MOVE-ORD-LOG-DTL-EXIT.                                              
           EXIT.                                                                
                                                                                
       M200-MOVE-ORD-LOG-DTL-ICP060.                                            
                                                                                
           MOVE ORH-ORDER-NBR          TO IC60ORH-ORDER-NBR.                    
           MOVE ORSH-DIST-NBR          TO IC60ORSH-DIST-NBR.                    
           MOVE ORSH-SHIP-NBR          TO IC60ORSH-SHIP-NBR.                    
           MOVE ORL-LINE-NBR           TO IC60ORL-LINE-NBR.                     
           MOVE ORH-ENTRY-DATE         TO IC60ORH-ENTRY-DATE.                   
                                                                                
       M200-MOVE-ORD-LOG-IC060-EXIT.                                            
           EXIT.
