      *  INFORMATION.                                                *          
      *                                                              *          
      *     INPUT: EDV028-INPUT-DATA                                 *          
      *            - OBJECT ID                                       *          
      *            - ACTION CODE                                     *          
      *            - USER ID                                         *          
      *            - COMPANY CODE                                    *          
      *            - PARTNER ID                                      *          
      *     INPUT/OUTPUT: EDV028-INPUT-OUTPUT-ARRAY-AREA             *          
      *            - ARRAY COUNT                                     *          
      *            - EDV028-ARRAY (OCCURS UP TO 20 TIMES)            *          
      *              - EDV028-CO-CD                                  *          
      *              - EDV028-PARTNER-ID                             *          
      *              - EDV028-CREDIT-MEMO-FLG                        *          
      *              - EDV028-ASSET-TAG-FLG                          *          
      *              - EDV028-EDI-PO-FLG                             *          
      *              - EDV028-ZERO-VALUE-FLG                         *          
      *              - EDV028-REFUSAL-FLG                            *          
      *              - EDV028-COMPONENTS-FLG                         *          
      *              - EDV028-INTEREST-INV-FLG                       *          
      *              - EDV028-LST-CHG-TS                             *          
      *              - EDV028-LST-CHG-NAM                            *          
      *                                                              *          
      *    OUTPUT: EDV028-OUTPUT-DATA                                *          
      *          - EDV028-ROW-COUNT                                  *          
      *          - EDV028-MODULE-RESULT-CD                           *          
      *          - EDV028-MODULE-MESSAGE                             *          
      *          - EDV028-DATABASE-RESULT-CODES:                     *          
      *              - EDV028-SQLCA VALUES                           *          
      *              - EDV028-SQLCODE                                *          
      *              - EDV028-SQLSTATE                               *          
      *                                                              *          
      *                                                              *          
      *   EDV028 EXAMPLE FOR REQUESTING A SINGLETON SELECT ACTION.   *          
      *     INITIALIZE EDV028-COMMUNICATIONS-AREA.                   *          
      *     MOVE PGM-PARTNER-ID TO EDV028-PARTNER-ID.                *          
      *     MOVE 'S ' TO EDV028-ACTION-CD.     .                     *          
      *     MOVE 'IE_BRANCH_SEQ' TO EDV028-OBJECT-ID.                *          
      *                                                              *          
      *     CALL 'EDV028' USING EDV028-COMMUNICATIONS-AREA.          *          
      *     IF EDV028-STATUS-OK                                      *          
      *     THEN                                                     *          
      *          CONTINUE WITH EXPECTED PROCESSING                   *          
      *     ELSE                                                     *          
      *          CONTINUE CHECK FOR DETAILED ERROR CONDITIONS AND    *          
      *          TAKE APPROPRIATE ACTIONS.                           *          
      *                                                              *          
      *      NOTE: THIS EXAMPLE SHOWS A TYPICAL CALL FROM AN         *          
      *            APPLICATION PROGRAM. IN THIS CASE THE PROGRAMMER  *          
      *            IS REQUESTING A SINGLETON SELECT ACTION TO RETURN *          
      *            DATA FOR A PARTICULAR PARTNER_ID.                 *          
      *                                                              *          
      *            THE PROGRAMMER SHOULD ALWAYS CHECK MODULE RESULT  *          
      *            CODE RETURNED FROM EDV028 TO VALIDTE THAT IT      *          
      *            WORKED PROPERLY (SEE THE COPYBOOK EDR001 FOR A    *          
      *            LIST OF ERROR CODES).                             *
