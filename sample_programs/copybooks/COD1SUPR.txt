      *           CHILD CUST THIRD PARTY     - (CUOF-ECOM-BYP-GRP1)    *AXS17062

      *           ZIPCODE PARENT CUST        - (ORTC1POS-FROM-POST-CD) *AXS17062
      *                                        (ORTC1POS-TO-POST-CD)   *AXS17062

      *                                                                *AXS17062
      *        2) SETS WS-BYPASS-CODE1-SW TO 'Y', IF ANY OF THOSE      *AXS17062

      *                                                                *AXS17062
      *----------------------------------------------------------------*AXS17062
      * DESC:  1) COD1SUPR IS A PROCEDURE DIVISION COPYBOOK USED IN    *AXS17125
      *           ORDER ENTRY PROCESS FOR SUPPRESSING CODE1 VALIDATION *AXS17125
      *                                                                *AXS17125
      *        2) COD1SUPR IS ADDED IN PROGRAM USING KEYWORD 'INCLUDE' *AXS17125
      *           AND USES BELOW INPUT WORKING STORAGE VARIABLES,      *AXS17125
      *           INPUT  :  ORDER#            - WS-CD1-ORDER-NBR       *AXS17125
      *                     FREIGHT OUT CODE  - WS-CD1-FRTO-CODE       *AXS17125

      *           COD1SUPR ROUTINE EITHER FROM MAP OR IMS DB           *AXS17125
      *                                                                *AXS17125
      *        3) IF THE INPUT WORKING STORAGE VARIABLES ARE NOT HAVING*AXS17125
      *           VALUES, THEN THE VALUES ARE TAKEN FROM ORDER DB      *AXS17125
      *           INSIDE THE COPYBOOK                                  *AXS17125
      *                                                                *AXS17125
      *EXAMPLE 1: IF CODE1 IS TO BE BYPASSED FOR A CUSTOMER, THEN      *AXS17125
      *           CUSTOMER ECOM BYPASS FLAG (CUOF-ECOM-BYP-GRP1)       *AXS17125

      *           TO 'Y'                                               *AXS17125
      *                                                                *AXS17125
      *EXAMPLE 2: IF CODE1 IS TO BE BYPASSED FOR A CUSTOMER, THEN      *AXS17125
      *           CUSTOMER SUFFIX BYPASS FLAG (ORTC1CUS-SFX-BYPAS-FLG) *AXS17125

           MOVE SPACES                       TO WS-BYPASS-CODE1-SW.             
                                                                                
           IF CU-PARENT-NBR NOT EQUAL  SPACES AND                               
              CU-PARENT-NBR NOT EQUAL  ZEROS  AND

                 MOVE CU-PARENT-BR-NBR       TO WS-CUSHED-BR                    
                 MOVE CU-PARENT-CUST-NBR     TO WS-CUSHED-CUST                  
                 PERFORM 1000-GU-CUSHED                                         
                                                                                
                 IF WS-CUSHED-NORESP                                            
                    MOVE '0'                 TO WS-CUSHEDOF-NBR                 
                    PERFORM 1201-GU-CUSHEDOF                                    
                    IF WS-CUSHEDOF-NORESP                                       
                       MOVE CUOF-CUSHEDOF    TO CUOF-CUSHEDOF-0                 
                       IF CUOF-ECOM-BYP-GRP1 = 'Y'                              
                          MOVE 'Y'           TO WS-BYPASS-CODE1-SW              
                          MOVE 'PARENT CUSTOMER ECOM BYPASS'            AXS17062
                                             TO WS-CD1-BYP-MESSAGE              
                          GO TO S1010-EXIT                                      
                       END-IF                                                   
                    END-IF                                                      
                 END-IF                                                         
              END-IF                                                            
           END-IF.
