      *  HOW TO USE THIS FROM A CALLING PROGRAM:                      *         
      *  THIS PD COPYBOOK CAN PERFORM 2 ACTIONS==>                    *         
      *  1. FETCH THE EXTENDED VPN WHEN IM PART IS AVAILABLE FROM DB2 *         
      *     TABLE PL_PARTS_LOCATOR.                                   *         
      *     FOR THIS OPERATION, IN CALLING PROGRAM DO THE FOLLOWING:  *         
      *     A. INCLUDE WORKING STORAGE COPYBOOK EDWVPN                *         
      *     B. INITIALIZE EDWVPN-IP-CO-CD & EDWVPN-IP-IM-PART-NBR     *         
      *     C. SET EDWVPN-FETCH-EXVPN TO TRUE                         *         
      *     D. MOVE THE COMPANY CODE TO EDWVPN-IP-CO-CD               *         
      *     E. MOVE THE IM PART NUMBER TO EDWVPN-IP-IM-PART-NBR       *         
      *     F. PERFORM E100-EDSVPN-PROCESS-REQ THRU E100-EDSVPN-EXIT  *         
      *     G. CHECK THE OUTPUT SWITCH EDWVPN-DATA-FOUND-SW:          *         
      *        'Y' (EDWVPN-DATA-FOUND) = DATA IS FOUND FOR REQUEST    *         
      *        'N' (EDWVPN-DATA-NOT-FND) = DATA NOT FOUND FOR REQUEST *         
      *     H. REQUESTED EXTENDED VPN WILL BE AVAILABLE IN FIELD      *         
      *        EDWVPN-OP-EXT-VPN                                      *         
      *                                                               *         
      *  2. FETCH THE IM PART WHEN EXTENDED VPN IS AVAILABLE FROM DB2 *         
      *     TABLE PL_PARTS_LOCATOR.                                   *         
      *     FOR THIS OPERATION, IN CALLING PROGRAM DO THE FOLLOWING:  *         
      *     A. INCLUDE WORKING STORAGE COPYBOOK EDWVPN                *         
      *     B. INITIALIZE EDWVPN-IP-CO-CD & EDWVPN-IP-EXT-VPN         *         
      *     C. INITIALIZE EDWVPN-PARTIAL-SKU1 & EDWVPN-PARTIAL-SKU2   * KZC18097
      *     D. SET EDWVPN-FETCH-IMPART TO TRUE                        * KZC18097
      *     E. MOVE THE COMPANY CODE TO EDWVPN-IP-CO-CD               * KZC18097
      *     F. MOVE THE EXTENDED VPN TO EDWVPN-IP-EXT-VPN             * KZC18097
      *     G. SPLIT EDWVPN-IP-EXT-VP INTO EDWVPN-PART-ALIGN1 AND     * KZC18097
      *        AND EDWVPN-PART-ALIGN2. THESE WILL BE USED TO          * KZC18097
      *        CALCULATE THE SCRUBBED EVPN EDWVPN-IP-SCR-EXT-VPN      * KZC18097
      *     H. PERFORM E100-EDSVPN-PROCESS-REQ THRU E100-EDSVPN-EXIT  * KZC18097
      *        HERE THE SCRUBBED EVPN WILL BE USED TO FETCH IMPART.   * KZC18097
      *     I. CHECK THE OUTPUT SWITCH EDWVPN-AUTH-DATA-FOUND-SW:     * KZC18097
      *        'Y' (EDWVPN-AUTH-DATA-FOUND) = DATA IS FOUND           *         
      *        'N' (EDWVPN-AUTH-DATA-NOT-FND) = DATA NOT FOUND        *         
      *     J. REQUESTED IM PART WILL BE AVAILABLE IN FIELD           * KZC18097
      *        EDWVPN-OP-IM-PART-NBR                                  *
