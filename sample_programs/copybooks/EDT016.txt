      ****************************************************************          
      *  COPYBOOK:  EDT016                                           *          
      ****************************************************************          
      *                                                              *          
      * OVERVIEW:                                                    *          
      *  USED IN SUB-ROUTINES EDV016 TO SUPPLY A CALLING PROGRAM     *          
      *  ACTIONS, DATA, AND AN AREA TO RETURN DATA AND RESULT CODE   *          
      *  INFORMATION.                                                *          
      *                                                              *          
      *     INPUT: EDV016-INPUT-DATA                                 *          
      *            - OBJECT ID                                       *          
      *            - ACTION CODE                                     *          
      *            - USER ID                                         *          
      *            - COMPANY CODE                                    *          
      *            - PARTNER ID                                      *          
      *     INPUT/OUTPUT: EDV016-INPUT-OUTPUT-ARRAY-AREA             *          
      *            - ARRAY COUNT                                     *          
      *            - EDV016-ARRAY (OCCURS UP TO 20 TIMES)            *          
      *              - EDV016-CO-CD                                  *          
      *              - EDV016-PARTNER-ID                             *          
      *              - EDV016-EDI-CO                                 *          
      *              - EDV016-LST-CHG-TS                             *          
      *              - EDV016-LST-CHG-NAM                            *          
      *                                                              *          
      *    OUTPUT: EDV016-OUTPUT-DATA                                *          
      *          - EDV016-ROW-COUNT                                  *          
      *          - EDV016-MODULE-RESULT-CD                           *          
      *          - EDV016-MODULE-MESSAGE                             *          
      *          - EDV016-DATABASE-RESULT-CODES:                     *          
      *              - EDV016-SQLCA VALUES                           *          
      *              - EDV016-SQLCODE                                *          
      *              - EDV016-SQLSTATE                               *          
      *                                                              *          
      *                                                              *          
      *   EDV016 EXAMPLE FOR REQUESTING A SINGLETON SELECT ACTION.   *          
      *     INITIALIZE EDV016-COMMUNICATIONS-AREA.                   *          
      *     MOVE PGM-CO-CD      TO EDV016-CO-CD.                     *          
      *     MOVE PGM-PARTNER-ID TO EDV016-PARTNER-ID.                *          
      *     MOVE PGM-EDI-CD     TO EDV016-EDI-CD.                    *          
      *     MOVE 'S ' TO EDV016-ACTION-CD.     .                     *          
      *     MOVE 'IE_PARTNER_EDI_XRF' TO EDV016-OBJECT-ID.           *          
      *                                                              *          
      *     CALL 'EDV016' USING EDV016-COMMUNICATIONS-AREA.          *          
      *                                                              *          
      *     IF EDV016-STATUS-OK                                      *          
      *     THEN                                                     *          
      *          CONTINUE WITH EXPECTED PROCESSING                   *          
      *     ELSE                                                     *          
      *          CONTINUE CHECK FOR DETAILED ERROR CONDITIONS AND    *          
      *          TAKE APPROPRIATE ACTIONS.                           *          
      *                                                              *          
      *      NOTE: THIS EXAMPLE SHOWS A TYPICAL CALL FROM AN         *          
      *            APPLICATION PROGRAM. IN THIS CASE THE PROGRAMMER  *          
      *            IS REQUESTING A SINGLETON SELECT ACTION TO RETURN *          
      *            DATA FOR A PARTICULAR PARTNER_ID.                 *          
      *                                                              *          
      *            THE PROGRAMMER SHOULD ALWAYS CHECK MODULE RESULT  *          
      *            CODE RETURNED FROM EDV016 TO VALIDTE THAT IT      *          
      *            WORKED PROPERLY (SEE THE COPYBOOK EDT016 FOR A    *          
      *            LIST OF ERROR CODES).                             *
