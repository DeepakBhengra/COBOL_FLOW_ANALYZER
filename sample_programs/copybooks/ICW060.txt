      *                                                              *          
      *  COPYBOOK: ICW060                                            *          
      *                                                              *          
      *  PROGRAM FUNCTION:                                           *          
      *                                                              *          
      *  THE PROGRAM IS DESIGNED TO BUILD THE KEYS REQUIRED TO       *          
      *  ACCESS CSLMST FOR MAXIMUM ALLOCATION QUANTITY PROCESSING    *          
      *  AND INCLOP FOR COST OVERRIDE PROCESSING.                    *          
      *                                                              *          
      *  WHEN INQUIRE MODE IS REQUESTED, THE KEYS TO CSLMST AND/OR   *          
      *  ICLCOP WILL BE RETURNED TO THE CALLING PROGRAM.             *          
      *                                                              *          
      *  WHEN DELETE MODE IS REQUESTED, THE KEYS TO CSLMST AND/OR    *          
      *  ICLCOP WILL BE RETURNED TO THE CALLING PROGRAM AND THE      *          
      *  ORDERED QUANTITY WILL BE REDUCED ON THE FILE(S).            *          
      *                                                              *          
      *  THE PROCESSING MODE IS BASED UPON THE VALUE PASSED IN       *          
      *  ICW060-FUNCTION-IND.                                        *          
      *                                                              *          
      *  THE FOLLOWING INFORMATION MUST BE PASSED FROM THE CALLING   *          
      *  PROGRAM TO ICP060.                                          *          
      *  NOTE: IF DELETE MODE IS BEING USED, THE ORL-QTY-ORDERED     *          
      *        MUST BE PASSED.                                       *          
      *                                                              *          
      *  TO ACCESS THE MAXIMUM ALLOCATION QUANTITY FOR ACOP, THE     *          
      *  FOLLOWING IS REQUIRED.                                      *          
      *  1.  THE COUNTRY/COMPANY CODE (ORH-COMPANY OR TC-COMPANY)    *          
      *  2.  THE INVENTORY SKU NUMBER (ORL-PART-NBR)                 *          
      *  3.  THE INVENTORY VENDOR (ORL-VENDOR-NBR)                   *          
      *  4.  THE CUSTOMER/SELLING BRANCH (ORH-BR-NBR OR TC-BR-NBR)   *          
      *  5.  THE CUSTOMER BRANCH (ORH-BILL-TO-BR-NBR)                *          
      *  6.  THE CUSTOMER NUMBER (ORH-BILL-TO-CUST-NBR)              *          
      *  7.  THE SHIP-TO SUFFIX (ORH-SHIP-TO-SUFFIX)                 *          
      *  8.  THE ACOP COST OVERRIDE INDICATOR                        *          
      *      (ORL-ACOP-COST-OVERRIDE-IND).                           *          
      *  9.  THE ACOP END USER NUMBER (ORL-ACOP-END-USER-NBR)        *          
      * 10.  THE ORDER QUANTITY (ORL-QTY-ORDERED)                    *          
      * 11.  THE ACOP TRACKING NUMBER (ORC-ACOP-TRK-NBR).            *          
      * 12.  THE ACOP CODE (ORC-ACOP-CODE).                          *          
      * 13.  THE ACOP OVERRIDE INDICATOR (ORC-ACOP-OVERRIDE-IND).    *          
      * 14.  THE MAXIMUM ALLOCATION QUANTITY INDICATOR (ORC-MAQ-IND) *          
      * 15.  THE ORDER QUANTITY (ORL-QTY-ORDERED)                    *          
      * 16.  THE REMAINING FIELDS SHOULD BE INITITALIZED TO ZEROES   *          
      *      AND SPACES.                                             *          
      * 17.  THE ACOP PROGRAM TYPE  (ORL-PROGRAM-TYPE).              *
