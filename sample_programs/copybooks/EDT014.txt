      *                                                              *          
      * OVERVIEW:                                                    *          
      *  USED IN SUB-ROUTINES EDV014 TO SUPPLY A CALLING PROGRAM     *          
      *  ACTIONS, DATA, AND AN AREA TO RETURN DATA AND RESULT CODE   *          
      *  INFORMATION.                                                *          
      *                                                              *          
      *     INPUT: EDV014-INPUT-DATA                                 *          
      *            - OBJECT ID                                       *          
      *            - ACTION CODE                                     *          
      *            - USER ID                                         *          
      *            - COMPANY CODE                                    *          
      *            - PARTNER ID                                      *          
      *     INPUT/OUTPUT: EDV014-INPUT-OUTPUT-ARRAY-AREA             *          
      *            - ARRAY COUNT                                     *          
      *            - EDV014-ARRAY (OCCURS UP TO 20 TIMES)            *          
      *              - EDV014-CO-CD                                  *          
      *              - EDV014-PARTNER-ID                             *          
      *              - EDV014-CREDIT-MEMO-FLG                        *          
      *              - EDV014-ASSET-TAG-FLG                          *          
      *              - EDV014-EDI-PO-FLG                             *          
      *              - EDV014-ZERO-VALUE-FLG                         *          
      *              - EDV014-REFUSAL-FLG                            *          
      *              - EDV014-COMPONENTS-FLG                         *          
      *              - EDV014-INTEREST-INV-FLG                       *          
      *              - EDV014-LST-CHG-TS                             *          
      *              - EDV014-LST-CHG-NAM                            *          
      *                                                              *          
      *    OUTPUT: EDV014-OUTPUT-DATA                                *          
      *          - EDV014-ROW-COUNT                                  *          
      *          - EDV014-MODULE-RESULT-CD                           *          
      *          - EDV014-MODULE-MESSAGE                             *          
      *          - EDV014-DATABASE-RESULT-CODES:                     *          
      *              - EDV014-SQLCA VALUES                           *          
      *              - EDV014-SQLCODE                                *          
      *              - EDV014-SQLSTATE                               *          
      *                                                              *          
      *                                                              *          
      *   EDV014 EXAMPLE FOR REQUESTING A SINGLETON SELECT ACTION.   *          
      *     INITIALIZE EDV014-COMMUNICATIONS-AREA.                   *          
      *     MOVE PGM-PARTNER-ID TO EDV014-PARTNER-ID.                *          
      *     MOVE 'S ' TO EDV014-ACTION-CD.     .                     *          
      *     MOVE 'IE_OUT_SHP_NOTC_SW' TO EDV014-OBJECT-ID.           *          
      *                                                              *          
      *     CALL 'EDV014' USING EDV014-COMMUNICATIONS-AREA.          *          
      *     IF EDV014-STATUS-OK                                      *          
      *     THEN                                                     *          
      *          CONTINUE WITH EXPECTED PROCESSING                   *          
      *     ELSE                                                     *          
      *          CONTINUE CHECK FOR DETAILED ERROR CONDITIONS AND    *          
      *          TAKE APPROPRIATE ACTIONS.                           *          
      *                                                              *          
      *      NOTE: THIS EXAMPLE SHOWS A TYPICAL CALL FROM AN         *          
      *            APPLICATION PROGRAM. IN THIS CASE THE PROGRAMMER  *          
      *            IS REQUESTING A SINGLETON SELECT ACTION TO RETURN *          
      *            DATA FOR A PARTICULAR PARTNER_ID.                 *          
      *                                                              *          
      *            THE PROGRAMMER SHOULD ALWAYS CHECK MODULE RESULT  *          
      *            CODE RETURNED FROM EDV014 TO VALIDTE THAT IT      *          
      *            WORKED PROPERLY (SEE THE COPYBOOK EDR001 FOR A    *          
      *            LIST OF ERROR CODES).                             *
