      ****************************************************************          
      *  COPYBOOK:  EDT412                                           *          
      ****************************************************************          
      *                                                              *          
      * OVERVIEW:                                                    *          
      *  USED IN SUB-ROUTINES EDV412 TO SUPPLY A CALLING PROGRAM     *          
      *  ACTIONS, DATA, AND AN AREA TO RETURN DATA AND RESULT CODE   *          
      *  INFORMATION.                                                *          
      *                                                              *          
      *     INPUT: EDV412-INPUT-DATA                                 *          
      *            - ACTION CODE                                     *          
      *            - USER ID                                         *          
      *                                                              *          
      *     INPUT/OUTPUT: EDV412-INPUT-OUTPUT-ARRAY-AREA             *          
      *            - OBJECT ID                                       *          
      *            - EDV412-CO-CD                                    *          
      *            - EDV412-CUST-CO-CD                               *          
      *            - EDV412-CUST-BR                                  *          
      *            - EDV412-CUST-NBR                                 *          
      *            - EDV412-CUST-SFX                                 *          
      *            - EDV412-CUST-PO-NBR                              *          
      *            - EDV412-SDQ-SEQ-NBR                              *          
      *            - EDV412-CUST-PO-DT                               *          
      *            - EDV412-CUST-PO-SEQ-NBR                          *          
      *            - EDV412-DATE-TIME-TS                             *          
      *            - EDV412-STATE-CD                                 *          
      *            - EDV412-IN-TSQ-NAM                               *          
      *            - EDV412-OUT-TSQ-NAM                              *          
      *                                                              *          
      *    OUTPUT: EDV412-OUTPUT-DATA                                *          
      *            - EDV412-MODULE-RESULT-CD                         *          
      *            - EDV412-MODULE-MESSAGE                           *          
      *            - EDV412-DATABASE-RESULT-CODES:                   *          
      *                - EDV412-EXCEPTION-MESSAGE(S)                 *          
      *                - EDV412-SQLCODE                              *          
      *                - EDV412-SQLSTATE                             *          
      *                - EDV412-SQL-MESSAGE                          *          
      *                                                              *          
      *   EDV412 EXAMPLE CALL FOR AN INSERT ACTION FOR               *          
      *          THE ED_AUD_TRAIL_INFO TABLE:                        *          
      *                                                              *          
      *    INITIALIZE     EDV412-COMMUNICATIONS-AREA.                *          
      *    SET EDV412-INSERT           TO TRUE.                      *          
      *                                                              *          
      *    MOVE CUST COMPANY CODE        TO EDV412-CUST-CO-CD.       *  TWADB201
      *    MOVE CUST BRANCH              TO EDV412-CUST-BR.          *  TWADB201
      *    MOVE CUST NBR                 TO EDV412-CUST-NBR.         *  TWADB201
      *    MOVE CUST SFX                 TO EDV412-CUST-SFX.         *  TWADB201
      *    MOVE CUST PO                  TO EDV412-CUST-PO-NBR.      *  TWADB201
      *    MOVE SDQ SEQ                  TO EDV412-SDQ-SEQ-NBR.      *  TWADB201
      *    MOVE CUST PO DATE             TO EDV412-CUST-PO-DT.       *  TWADB201
      *    MOVE CUST PO SEQ NBR          TO EDV412-CUST-PO-SEQ-NBR.  *  TWADB201
      *    MOVE CALLING PRG STATE CODE   TO EDV412-STATE-CD.         *          
      *    * NOT USED - MOVE SPACES *    TO EDV412-IN-TSQ-NAM.       *          
      *    * NOT USED - MOVE SPACES *    TO EDV412-OUT-TSQ-NAM.      *          
      *                                                              *          
      *    CALL 'EDV412' USING EDV412-COMMUNICATIONS-AREA.           *          
      *                                                              *          
      *     IF EDV412-STATUS-OKAY                                    *          
      *     THEN                                                     *          
      *          ..........                                          *          
      *     ELSE                                                     *          
      *          ..........                                          *          
      *                                                              *          
      *      NOTE: THIS EXAMPLE SHOWS A TYPICAL CALL FROM AN         *          
      *            APPLICATION PROGRAM. IN THIS CASE THE PROGRAMMER  *          
      *            IS REQUESTING AN  'INSERT' ACTION TO CREATE A NEW *          
      *            ROW ON THE ED_AUD_TRAIL_INFO TABLE.               *          
      *                                                              *          
      *            THE PROGRAMMER SHOULD ALWAYS CHECK MODULE RESULT  *          
      *            CODE RETURNED FROM EDV412 TO VALIDATE THAT IT     *          
      *            WORKED PROPERLY (SEE THE COPYBOOK EDT412 FOR A    *          
      *            LIST OF ERROR CODES).                             *          
      *                                                              *
