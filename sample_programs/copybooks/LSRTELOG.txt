      *----------------------------------------------------------------*        
      *  REAL-TIME EDI LOG MESSAGING INTERFACE DATA STRUCTURE          *        
      *----------------------------------------------------------------*        
      *  TO USE THIS COMMUNICATION AREA:                               *        
      *     1. IN YOUR WORKING STORAGE SECTION, CODE:                  *        
      *        01  USE-EDIR999                                         *        
      *            COPY LSRTELOG.                                      *        
      *     2. MOVE YOUR TEXT TO EDILOG-USER-TEXT, AND OPTIONALLY      *        
      *        A SEVERITY CODE TO EDILOG-USER-ERROR-SEVERITY AND AN    *        
      *        ERROR LEVEL TO EDILOG-USER-ERROR-LEVEL. VALUE RANGE:    *        
      *          SEVERITY CODE                  ERROR LEVEL            *        
      *          I - INFORMATIONAL MESSAGE        00                   *        
      *          W - WARNING                      04                   *        
      *          E - ERROR IN DATA                08                   *        
      *          S - SEVERE, PROCESS ENDS         12                   *        
      *          F - FATAL, PROCESS ENDS          16                   *        
      *        IF YOU ARE USING THE SYSTEM IMAGE OPTION, YOU MUST ALSO *        
      *        PROVIDE THIS 3 CHARACTER CODE IN EDILOG-USER-SYSIMAGE.  *        
      *     3. LINK TO EDIR999:                                        *        
      *             EXEC CICS LINK PROGRAM ('EDIR999')                 *        
      *                           COMMAREA (EDILOG-COMMAREA)           *        
      *                             LENGTH (EDILOG-COMMAREA-LENGTH)    *        
      *             END-EXEC.                                          *        
      *     4. EDIR999 WILL PUT YOUR TEXT WITH ITS SEVERITY, AND ERROR *        
      *        LEVEL ON THE EDILOG FILE. IF THERE IS A PROBLEM, THE    *        
      *        PROGRAM MAY ABEND WITH A DOCUMENTED ABEND CODE, OR IT   *        
      *        MAY PASS ERROR INFORMATION BACK TO YOUR PROGRAM TO USE. *        
      *     5. INQUIRE THE EDILOG-RTN-ERROR-LEVEL FOR 00 FOR GOOD RTN. *        
      *----------------------------------------------------------------*        
      *

                   15  EDILOG-USER-TEXT              PIC X(90).
