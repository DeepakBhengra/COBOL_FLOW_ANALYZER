      **>>>-------------------------------------------------------<<<**         
      **>>> SETUP THE GENERAL REQUEST PARAMETERS TO SUPPORT A     <<<**         
      **>>> SINGLE SKU PRICING REQUEST.                           <<<**         
      **>>>                                                       <<<**         
      **>>>-------------------------------------------------------<<<**         
                                                                                
       SP210-SETUP-GENERAL-REQUEST.                                             
                                                                                
      *   (INITIALIZE THE REQUEST AND RESPONSE AREAS)                           
           INITIALIZE SYWSPS-REQUEST-RESPONSE-AREAS                             
                   OF SYWSP-CONNECTOR-DATA.                                     
                                                                                
      *   (SET UP THE SINGLE SKU DATA LAYOUT)                                   
           SET SYWSPP-LAYOUT-PRICING-SNGL   TO TRUE.                            
                                                                                
      *   (A SINGLE SKU REQUEST SHOULD HAVE 1 REQUEST, 1 RESPONSE)              
           MOVE 1                           TO SYWSPH-NBR-OF-REQUESTS           
                                            OF SYWSP-CONNECTOR-DATA.            
           MOVE 1                           TO SYWSPH-NBR-OF-RESPONSES          
                                            OF SYWSP-CONNECTOR-DATA.            
                                                                                
      *   (INITIALIZE THE REQUEST AND RESPONSE INDEXES TO 1)                    
           MOVE 1                           TO SYWSPSRQ-IDX.                    
           MOVE 1                           TO SYWSPSRS-IDX.                    
                                                                                
                                                                                
       SP300-SETUP-SINGLE-SKU-REQUEST.                                          
                                                                                
      *   (SETUP LOGIC FOR A SINGLE SKU REQUEST IS DONE HERE)                   
                                                                                
      *   (PERFORM COMMON SKU REQUEST SETUP LOGIC IN SP310)                     
           PERFORM SP310-SETUP-SKU-REQUEST.
