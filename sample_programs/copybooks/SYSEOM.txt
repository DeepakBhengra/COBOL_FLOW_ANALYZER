      *                                                               *         
      *          STRATEGIC PRICING END ORDER MOVES                    *         
      *                                                               *         
      * PURPOSE: STANDARD PROCEDURE DIVISION ROUTINE TO INITIALIZE    *         
      *          A STRATEGIC PRICING END ORDER REQUEST.               *         
      *                                                               *         
      * USAGE:   COPY IN YOUR APPLICATION AND PERFORM THE EO200       *         
      *          PARAGRAPH, THEN POPULATE THE ORDER SPECIFIC ARRAY    *         
      *          BEFORE INVOKING SP900-STRATEGIC-PRICING IN SYSPCL.   *         
      *                                                               *         
      *****************************************************************         
      *     REVISION LOG:                                             *         
      * 11/02/04 AXR       *** STRATEGIC PRICING - FULL SOLUTION ***  * AXR04307
      *               1. CREATED COPYBOOK.                            * AXR04307
      *                                                               *         
      *****************************************************************         
                                                                                
                                                                                
      **>>>-------------------------------------------------------<<<**         
      **>>> THIS ROUTINE PERFORMS THE STANDARD MOVES TO SETUP     <<<**         
      **>>> THE END ORDER REQUEST FIELDS. THE APPLICATIONS        <<<**         
      **>>> THAT DO NOT HAVE THE SOURCE FIELDS CAN USE            <<<**         
      **>>> 'COPY REPLACING' TO SPECIFY THE CORRECT SOURCE        <<<**         
      **>>> FIELDS.                                               <<<**         
      **>>>                                                       <<<**         
      **>>>-------------------------------------------------------<<<**         
                                                                                
       EO200-SETUP-END-ORDER-REQUEST.                                           
                                                                                
      *   (SET ALL END ORDER CONNECTOR FIELDS TO SPACES AND ZEROS)              
           INITIALIZE SYWEO-CONNECTOR-DATA.                                     
                                                                                
      *   (SETUP CONNECTOR PARAMETERS)                                          
           SET SYWSPP-TARGET-END-ORD-ENGINE TO TRUE.                            
           SET SYWSPP-LAYOUT-END-ORDER      TO TRUE.                            
                                                                                
      *   (INITIALIZE END-ORDER RESPONSE FIELDS)                                
           SET SYWEO-R-RECORD-NO-ERRORS     TO TRUE.                            
           SET SYWEO-R-RSPNS-NO-ERROR       TO TRUE.                            
           MOVE SPACES                      TO SYWEO-R-ERROR-TEXT.              
                                                                                
      *   (SETUP END-ORDER HEADER FIELDS)                                       
           MOVE WS-PRC-COMPANY              TO SYWEO-CUST-CO-CD.                
           MOVE WS-PRC-BR-NBR               TO SYWEO-CUST-BR-CD.                
           MOVE WS-PRC-CUST-NBR             TO SYWEO-CUST-NBR.                  
                                                                                
      *   (THE ORDER ENTRY METHOD VALUE IS VERY IMPORTANT)                      
           MOVE SYRPWSA-ENTRY-METHOD       TO SYWEO-ORDER-ENTRY-METH-CD.        
                                                                                
      *   (AFTER PERFORMING THIS INITIALIZATION, THE APPLICATION MUST           
      *    POPULATE THE ACTUAL VALUES FOR SYWEO-NBR-OF-DISTS AND                
      *    FOR EACH ARRAY OCCURANCE OF SYWEO-DIST-NBR AND ITS                   
      *    CORRESPONDING SYWEO-TOT-SHIPABLE-SLS)                                
                                                                                
      *   (INITIALIZE END-ORDER REQUEST ARRAY)                                  
           PERFORM VARYING SYWEO-NBR-OF-DISTS                                   
              FROM +1 BY +1                                                     
              UNTIL SYWEO-NBR-OF-DISTS = 9                                      
                MOVE ZERO                                                       
                  TO SYWEO-DIST-NBR (SYWEO-NBR-OF-DISTS)                        
                     SYWEO-TOT-SHIPABLE-SLS (SYWEO-NBR-OF-DISTS)                
           END-PERFORM.                                                         
                                                                                
      *   (INITIALIZE THE COUNT OF NUMBER OF ORDER DISTRIBUTIONS)               
           MOVE ZERO                       TO SYWEO-NBR-OF-DISTS.
