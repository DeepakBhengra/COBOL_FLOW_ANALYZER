      *                                                              *          
      * OVERVIEW:                                                    *          
      *  USED IN SUB-ROUTINES EDV031 TO SUPPLY A CALLING PROGRAM     *          
      *  ACTIONS, DATA, AND AN AREA TO RETURN DATA AND RESULT CODE   *          
      *  INFORMATION.                                                *          
      *                                                              *          
      *     INPUT: EDV031-INPUT-DATA                                 *          
      *            - OBJECT ID                                       *          
      *            - ACTION CODE                                     *          
      *            - USER ID                                         *          
      *            - COMPANY CODE                                    *          
      *            - PARTNER ID                                      *          
      *     INPUT/OUTPUT: EDV031-INPUT-OUTPUT-ARRAY-AREA             *          
      *            - ARRAY COUNT                                     *          
      *            - EDV031-ARRAY (OCCURS UP TO 20 TIMES)            *          
      *              - EDV031-CO-CD                                  *          
      *              - EDV031-PARTNER-ID                             *          
      *              - EDV031-CREDIT-MEMO-FLG                        *          
      *              - EDV031-ASSET-TAG-FLG                          *          
      *              - EDV031-ZERO-VALUE-FLG                         *          
      *              - EDV031-REFUSAL-FLG                            *          
      *              - EDV031-COMPONENTS-FLG                         *          
      *              - EDV031-INTEREST-INV-FLG                       *          
      *              - EDV031-LST-CHG-TS                             *          
      *              - EDV031-LST-CHG-NAM                            *          
      *                                                              *          
      *    OUTPUT: EDV031-OUTPUT-DATA                                *          
      *          - EDV031-ROW-COUNT                                  *          
      *          - EDV031-MODULE-RESULT-CD                           *          
      *          - EDV031-MODULE-MESSAGE                             *          
      *          - EDV031-DATABASE-RESULT-CODES:                     *          
      *              - EDV031-SQLCA VALUES                           *          
      *              - EDV031-SQLCODE                                *          
      *              - EDV031-SQLSTATE                               *          
      *                                                              *          
      *                                                              *          
      *   EDV031 EXAMPLE FOR REQUESTING A SINGLETON SELECT ACTION.   *          
      *     INITIALIZE EDV031-COMMUNICATIONS-AREA.                   *          
      *     MOVE PGM-PARTNER-ID TO EDV031-PARTNER-ID.                *          
      *     MOVE 'S ' TO EDV031-ACTION-CD.     .                     *          
      *     MOVE 'IE_IN_PO_SW' TO EDV031-OBJECT-ID.                  *          
      *                                                              *          
      *     CALL 'EDV031' USING EDV031-COMMUNICATIONS-AREA.          *          
      *     IF EDV031-STATUS-OK                                      *          
      *     THEN                                                     *          
      *          CONTINUE WITH EXPECTED PROCESSING                   *          
      *     ELSE                                                     *          
      *          CONTINUE CHECK FOR DETAILED ERROR CONDITIONS AND    *          
      *          TAKE APPROPRIATE ACTIONS.                           *          
      *                                                              *          
      *      NOTE: THIS EXAMPLE SHOWS A TYPICAL CALL FROM AN         *          
      *            APPLICATION PROGRAM. IN THIS CASE THE PROGRAMMER  *          
      *            IS REQUESTING A SINGLETON SELECT ACTION TO RETURN *          
      *            DATA FOR A PARTICULAR PARTNER_ID.                 *          
      *                                                              *          
      *            THE PROGRAMMER SHOULD ALWAYS CHECK MODULE RESULT  *          
      *            CODE RETURNED FROM EDV031 TO VALIDTE THAT IT      *          
      *            WORKED PROPERLY (SEE THE COPYBOOK EDR001 FOR A    *          
      *            LIST OF ERROR CODES).                             *
