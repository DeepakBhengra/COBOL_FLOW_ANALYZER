      *                                                              *          
      * OVERVIEW:                                                    *          
      *  USED IN SUB-ROUTINES EDV401 TO SUPPLY A CALLING PROGRAM     *          
      *  ACTIONS, DATA, AND AN AREA TO RETURN DATA AND RESULT CODE   *          
      *  INFORMATION.                                                *          
      *                                                              *          
      *     INPUT: EDV401-INPUT-DATA                                 *          
      *            - OBJECT ID                                       *          
      *            - ACTION CODE                                     *          
      *            - USER ID                                         *          
      *            - COMPANY CODE                                    *          
      *            - PARTNER ID                                      *          
      *     INPUT/OUTPUT: EDV401-INPUT-OUTPUT-ARRAY-AREA             *          
      *            - ARRAY COUNT                                     *          
      *            - EDV401-ARRAY (OCCURS UP TO 20 TIMES)            *          
      *              - EDV401-PARTNER-ID                             *  AZS06016
      *              - EDV401-SRCE-SYS-KEY-ID                        *  AZS06016
      *              - EDV401-INTERNET-ADDR-TXT                      *  AZS06016
      *              - EDV401-SEND-THRU-ID                           *  AZS06016
      *              - EDV401-DATA-STORE-MECH-ID                     *  AZS06016
      *              - EDV401-FORMAT-ID                              *  AZS06016
      *              - EDV401-DOC-ID                                 *  AZS06016
      *              - EDV401-APPL-ID                                *  AZS06016
      *              - EDV401-TRANSLATOR-ID                          *  AZS06016
      *              - EDV401-TRANSLATION-ID                         *  AZS06016
      *              - EDV401-PRCS-OPTN-FLG                          *  AZS06016
      *              - EDV401-CYCLE-INTVL                            *  AZS06016
      *              - EDV401-CYCLE-LST-RUN-TS                       *  AZS06016
      *                                                              *  AZS06016
      *    OUTPUT: EDV401-OUTPUT-DATA                                *          
      *          - EDV401-ROW-COUNT                                  *          
      *          - EDV401-MODULE-RESULT-CD                           *          
      *          - EDV401-MODULE-MESSAGE                             *          
      *          - EDV401-DATABASE-RESULT-CODES:                     *          
      *              - EDV401-SQLCODE                                *          
      *              - EDV401-SQLSTATE                               *          
      *              - EDV401-SQL-MESSAGE                            *          
      *                                                              *          
      *                                                              *          
      *   EDV401 EXAMPLE FOR REQUESTING A SINGLETON SELECT ACTION.   *          
      *     INITIALIZE EDV401-COMMUNICATIONS-AREA.                   *          
      *     MOVE PGM-PARTNER-ID TO EDV401-PARTNER-ID.                *          
      *     MOVE 'S ' TO EDV401-ACTION-CD.     .                     *          
      *     MOVE 'PARTNER_LOOKUP  ' TO EDV401-OBJECT-ID.             *          
      *                                                              *          
      *     CALL 'EDV401' USING EDV401-COMMUNICATIONS-AREA.          *          
      *     IF EDV401-STATUS-OK                                      *          
      *     THEN                                                     *          
      *          CONTINUE WITH EXPECTED PROCESSING                   *          
      *     ELSE                                                     *          
      *          CONTINUE CHECK FOR DETAILED ERROR CONDITIONS AND    *          
      *          TAKE APPROPRIATE ACTIONS.                           *          
      *                                                              *          
      *      NOTE: THIS EXAMPLE SHOWS A TYPICAL CALL FROM AN         *          
      *            APPLICATION PROGRAM. IN THIS CASE THE PROGRAMMER  *          
      *            IS REQUESTING A SINGLETON SELECT ACTION TO RETURN *          
      *            DATA FOR A PARTICULAR PARTNER_ID.                 *          
      *                                                              *          
      *            THE PROGRAMMER SHOULD ALWAYS CHECK MODULE RESULT  *          
      *            CODE RETURNED FROM EDV401 TO VALIDTE THAT IT      *          
      *            WORKED PROPERLY (SEE THE COPYBOOK EDT401 FOR A    *          
      *            LIST OF ERROR CODES).                             *
