      ****************************************************************          
      *  COPYBOOK:  EDT025                                           *          
      ****************************************************************          
      *                                                              *          
      * OVERVIEW:                                                    *          
      *  USED IN SUB-ROUTINES EDV025 TO SUPPLY A CALLING PROGRAM     *          
      *  ACTIONS, DATA, AND AN AREA TO RETURN DATA AND RESULT CODE   *          
      *  INFORMATION.                                                *          
      *                                                              *          
      *     INPUT: EDV025-INPUT-DATA                                 *          
      *            - OBJECT ID                                       *          
      *            - ACTION CODE                                     *          
      *            - USER ID                                         *          
      *            - COMPANY CODE                                    *          
      *            - PARTNER ID                                      *          
      *     INPUT/OUTPUT: EDV025-INPUT-OUTPUT-ARRAY-AREA             *          
      *            - ARRAY COUNT                                     *          
      *            - EDV025-ARRAY (OCCURS UP TO 20 TIMES)            *          
      *              - EDV025-CO-CD                                  *          
      *              - EDV025-PARTNER-ID                             *          
      *              - EDV025-CREDIT-MEMO-FLG                        *          
      *              - EDV025-ASSET-TAG-FLG                          *          
      *              - EDV025-EDI-PO-FLG                             *          
      *              - EDV025-ZERO-VALUE-FLG                         *          
      *              - EDV025-REFUSAL-FLG                            *          
      *              - EDV025-COMPONENTS-FLG                         *          
      *              - EDV025-INTEREST-INV-FLG                       *          
      *              - EDV025-LST-CHG-TS                             *          
      *              - EDV025-LST-CHG-NAM                            *          
      *                                                              *          
      *    OUTPUT: EDV025-OUTPUT-DATA                                *          
      *          - EDV025-ROW-COUNT                                  *          
      *          - EDV025-MODULE-RESULT-CD                           *          
      *          - EDV025-MODULE-MESSAGE                             *          
      *          - EDV025-DATABASE-RESULT-CODES:                     *          
      *              - EDV025-SQLCA VALUES                           *          
      *              - EDV025-SQLCODE                                *          
      *              - EDV025-SQLSTATE                               *          
      *                                                              *          
      *                                                              *          
      *   EDV025 EXAMPLE FOR REQUESTING A SINGLETON SELECT ACTION.   *          
      *     INITIALIZE EDV025-COMMUNICATIONS-AREA.                   *          
      *     MOVE PGM-PARTNER-ID TO EDV025-PARTNER-ID.                *          
      *     MOVE 'S ' TO EDV025-ACTION-CD.     .                     *          
      *     MOVE 'IE_MISC_CHARGES' TO EDV025-OBJECT-ID.              *          
      *                                                              *          
      *     CALL 'EDV025' USING EDV025-COMMUNICATIONS-AREA.          *          
      *     IF EDV025-STATUS-OK                                      *          
      *     THEN                                                     *          
      *          CONTINUE WITH EXPECTED PROCESSING                   *          
      *     ELSE                                                     *          
      *          CONTINUE CHECK FOR DETAILED ERROR CONDITIONS AND    *          
      *          TAKE APPROPRIATE ACTIONS.                           *          
      *                                                              *          
      *      NOTE: THIS EXAMPLE SHOWS A TYPICAL CALL FROM AN         *          
      *            APPLICATION PROGRAM. IN THIS CASE THE PROGRAMMER  *          
      *            IS REQUESTING A SINGLETON SELECT ACTION TO RETURN *          
      *            DATA FOR A PARTICULAR PARTNER_ID.                 *          
      *                                                              *          
      *            THE PROGRAMMER SHOULD ALWAYS CHECK MODULE RESULT  *          
      *            CODE RETURNED FROM EDV025 TO VALIDTE THAT IT      *          
      *            WORKED PROPERLY (SEE THE COPYBOOK EDR001 FOR A    *          
      *            LIST OF ERROR CODES).                             *          
      *                                                              *
