      ****************************************************************          
      *  COPYBOOK:  EDT008                                           *          
      ****************************************************************          
      *                                                              *          
      * OVERVIEW:                                                    *          
      *  USED IN SUB-ROUTINES EDV008 TO SUPPLY A CALLING PROGRAM     *          
      *  ACTIONS, DATA, AND AN AREA TO RETURN DATA AND RESULT CODE   *          
      *  INFORMATION.                                                *          
      *                                                              *          
      *     INPUT: EDV008-INPUT-DATA                                 *          
      *            - OBJECT ID                                       *          
      *            - ACTION CODE                                     *          
      *            - USER ID                                         *          
      *            - COMPANY CODE                                    *          
      *            - PARTNER ID                                      *          
      *     INPUT/OUTPUT: EDV008-INPUT-OUTPUT-ARRAY-AREA             *          
      *            - ARRAY COUNT                                     *          
      *            - EDV008-ARRAY (OCCURS UP TO 20 TIMES)            *          
      *              - EDV008-CO-CD                                  *          
      *              - EDV008-PARTNER-ID                             *          
      *              - EDV008-CREDIT-MEMO-FLG                        *          
      *              - EDV008-ASSET-TAG-FLG                          *          
      *              - EDV008-EDI-PO-FLG                             *          
      *              - EDV008-ZERO-VALUE-FLG                         *          
      *              - EDV008-REFUSAL-FLG                            *          
      *              - EDV008-COMPONENTS-FLG                         *          
      *              - EDV008-INTEREST-INV-FLG                       *          
      *              - EDV008-LST-CHG-TS                             *          
      *              - EDV008-LST-CHG-NAM                            *          
      *                                                              *          
      *    OUTPUT: EDV008-OUTPUT-DATA                                *          
      *          - EDV008-ROW-COUNT                                  *          
      *          - EDV008-MODULE-RESULT-CD                           *          
      *          - EDV008-MODULE-MESSAGE                             *          
      *          - EDV008-DATABASE-RESULT-CODES:                     *          
      *              - EDV008-SQLCA VALUES                           *          
      *              - EDV008-SQLCODE                                *          
      *              - EDV008-SQLSTATE                               *          
      *                                                              *          
      *                                                              *          
      *   EDV008 EXAMPLE FOR REQUESTING A SINGLETON SELECT ACTION.   *          
      *     INITIALIZE EDV008-COMMUNICATIONS-AREA.                   *          
      *     MOVE PGM-PARTNER-ID TO EDV008-PARTNER-ID.                *          
      *     MOVE 'S ' TO EDV008-ACTION-CD.     .                     *          
      *     MOVE 'IE_PRICE_VARIANCE' TO EDV008-OBJECT-ID.            *          
      *                                                              *          
      *     CALL 'EDV008' USING EDV008-COMMUNICATIONS-AREA.          *          
      *     IF EDV008-STATUS-OK                                      *          
      *     THEN                                                     *          
      *          CONTINUE WITH EXPECTED PROCESSING                   *          
      *     ELSE                                                     *          
      *          CONTINUE CHECK FOR DETAILED ERROR CONDITIONS AND    *          
      *          TAKE APPROPRIATE ACTIONS.                           *          
      *                                                              *          
      *      NOTE: THIS EXAMPLE SHOWS A TYPICAL CALL FROM AN         *          
      *            APPLICATION PROGRAM. IN THIS CASE THE PROGRAMMER  *          
      *            IS REQUESTING A SINGLETON SELECT ACTION TO RETURN *          
      *            DATA FOR A PARTICULAR PARTNER_ID.                 *          
      *                                                              *          
      *            THE PROGRAMMER SHOULD ALWAYS CHECK MODULE RESULT  *          
      *            CODE RETURNED FROM EDV008 TO VALIDTE THAT IT      *          
      *            WORKED PROPERLY (SEE THE COPYBOOK EDR001 FOR A    *          
      *            LIST OF ERROR CODES).                             *          
      *                                                              *
