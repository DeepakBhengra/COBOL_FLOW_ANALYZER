      **************************************************************            
      *                   SYU001 DATE ROUTINE COPYBOOK                          
      *                     JULIAN TO GREGORIAN                                 
      *  GREGORIAN DATES MAY BE IN SEVERAL FORMATES, MMDDYY, DDMMYY,            
      *  OR YYMMDD FOR DIFFERENT COUNTRIES.   THIS JULIAN TO GREGORIAN          
      *  ROUTINE WILL RETURN ALL DATE FORMATS.  THIS WAY CALLING PROGRAM        
      *  MAY PICK DESIRED DATE FORMAT.                                          
      *                                                                         
      *    EXAMPLE    CALL 'SYU001' USING SYU1-INPUT-JULIAN-DATE                
      *                                   SYU1-EXISTING-GREG-DATE               
      *                                   SYU1-EXISTING-GREG-DATE-6             
      *                                   SYU1-NEW-FORMAT-FIELDS.               
      *  NOTE:  THE EXISTING CALL OF SYU001 ONLY CONTAINED THE INPUT            
      *         JULIAN DATE, AND THE OUTPUT GREGORIAN DATE.  AS OF              
      *         08/13/91 SYU001 CHANGED TO ALSO PASS SYU1-NEW-FORMAT-           
      *         FIELDS.  EXISTING PROGRAMS WITH ONLY THE TWO PARAMATERS         
      *         WILL WORK.                                                      
      *  NOTE2: SYU1-EXISTING-GREG-DATE WILL CONTAIN THE GREGORIAN              
      *         DATE IN THE FORMAT USED BY THIS CICS REGION,                    
      *         IE MM/DD/YY IF RUNNING IN US CICS REGION, OR DD/MM/YY           
      *         IF RUNNING IN UK REGION.                                        
      *  NOTE3: PLEASE MOVE COMPANY CODE TO FIELD SYU1-COUNTRY-                 
      *         INDICATOR BEFORE CALLING SYU001. FUTURE MAY CALL FOR            
      *         DIFFERENT COMPANIES WITHIN THE SAME REGION TO HAVE              
      *         DIFFERENT DEFAULT DATE FORMATS.                                 
      ***************************************************************   RMR99165
