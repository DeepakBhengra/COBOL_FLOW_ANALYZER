      *       SYR777B  - FOR BATCH                                              
      *       THIS IS COPYBOOK FOR PROGRAM SYV777 DATE ROUTINE                  
      ****  FUCTION  **********                                                 
      *     A. CHECK INPUT DATE ERROR       - IF ENTERED                        
      *     B. CONVERT JULIAN TO GREGORIAN  - IF ENTERED                        
      *     C. CONVERT GREGORIAN TO JULIAN  - IF ENTERED                        
      *     D. CONVERT ISO DATE  TO JULIAN  - IF ENTERED                        
      *     E. IF NO INPUT, RETURN CURRENT DATE                                 
      *     F. FOR BAD INPUT, RETURN ERROR MESSAGE                              
      *        (IF YOU WANT TO SEE IT, YOU MAY DISPLAY SYV-ERROR-SW     JBP98071
      *         & SYV-ERROR-MESSAGE ON YOUR SYSOUT).                    JBP98071
      *                                                                         
      *  GREGORIAN DATES MAY BE IN SEVERAL FORMATES FOR DIFFERENT               
      *  COUNTRIES.   THE ROUTINE WILL RETURN ALL DATE FORMATS.                 
      *  THE CALLING PROGRAMS PICK THE DESIRED DATE FORMAT.                     
      *                                                                         
      *    A. INITIALIZE SYV-DATE-ROUTINE-FIELDS (IF YOU WANT MORE THAN         
      *       ONE CALL IN A PROGRAM WITH DIFFERENT INPUT FIELDS).               
      *    B. COMPANY CODE - REQUIRED.                                          
      *    C. JULIAN OR GREGORIAN FIELD AS AN INPUT FIELD.                      
      *    D. TO GET CURRENT DATE, CALL THIS ROUTINE WITHOUT            JBP98098
      *       PASSING ANY INPUT DATE. ALSO MOVE 'Y' TO                  JBP98098
      *       SYV-INPUT-CURRENT-DATE-SW.                                JBP98098
      *                                                                         
      *    EXAMPLE   CALL 'SYV777' USING SYV-DATE-ROUTINE-FIELDS.               
      *                                                                         
      *  NOTE:  THE COMPANY CODE IS A REQUIRED FIELD WHEN YOU WANT      JBP98098
      *         TO CONVERT FROM JULIAN TO GREGORIAN OR FROM GREGORIAN   JBP98098
      *         /ISO TO JULIAN. IF COMPANY CODE IS NOT PASSED,          JBP98098
      *         THIS ROUTINE DEFAULTS TO 'MD' WHICH IS U.S.A.           JBP98098
      *                                                                         
      *   04/08/98  JBP ADDED CCYYMMDD OUTPUT FIELD                     JBP98098
