      ****************************************************************          
      *  COPYBOOK:  EDT024                                           *          
      ****************************************************************          
      *                                                              *          
      * OVERVIEW:                                                    *          
      *  USED IN SUB-ROUTINES EDV024 TO SUPPLY A CALLING PROGRAM     *          
      *  ACTIONS, DATA, AND AN AREA TO RETURN DATA AND RESULT CODE   *          
      *  INFORMATION.                                                *          
      *                                                              *          
      *     INPUT: EDV024-INPUT-DATA                                 *          
      *            - OBJECT ID                                       *          
      *            - ACTION CODE                                     *          
      *            - USER ID                                         *          
      *            - COMPANY CODE                                    *          
      *            - PARTNER ID                                      *          
      *     INPUT/OUTPUT: EDV024-INPUT-OUTPUT-ARRAY-AREA             *          
      *            - ARRAY COUNT                                     *          
      *            - EDV024-ARRAY (OCCURS UP TO 20 TIMES)            *          
      *              - EDV024-CO-CD                                  *          
      *              - EDV024-PARTNER-ID                             *          
      *              - EDV024-EDI-CO                                 *          
      *              - EDV024-LST-CHG-TS                             *          
      *              - EDV024-LST-CHG-NAM                            *          
      *                                                              *          
      *    OUTPUT: EDV024-OUTPUT-DATA                                *          
      *          - EDV024-ROW-COUNT                                  *          
      *          - EDV024-MODULE-RESULT-CD                           *          
      *          - EDV024-MODULE-MESSAGE                             *          
      *          - EDV024-DATABASE-RESULT-CODES:                     *          
      *              - EDV024-SQLCA VALUES                           *          
      *              - EDV024-SQLCODE                                *          
      *              - EDV024-SQLSTATE                               *          
      *                                                              *          
      *                                                              *          
      *   EDV024 EXAMPLE FOR REQUESTING A SINGLETON SELECT ACTION.   *          
      *     INITIALIZE EDV024-COMMUNICATIONS-AREA.                   *          
      *     MOVE PGM-CO-CD      TO EDV024-CO-CD.                     *          
      *     MOVE PGM-PARTNER-ID TO EDV024-PARTNER-ID.                *          
      *     MOVE PGM-CUST-CARR-CD TO EDV024-CUST-CARR-CD.            *          
      *     MOVE 'S ' TO EDV024-ACTION-CD.     .                     *          
      *     MOVE 'IE_CARRIER_XREF' TO EDV024-OBJECT-ID.              *          
      *                                                              *          
      *     CALL 'EDV024' USING EDV024-COMMUNICATIONS-AREA.          *          
      *                                                              *          
      *     IF EDV024-STATUS-OK                                      *          
      *     THEN                                                     *          
      *          CONTINUE WITH EXPECTED PROCESSING                   *          
      *     ELSE                                                     *          
      *          CONTINUE CHECK FOR DETAILED ERROR CONDITIONS AND    *          
      *          TAKE APPROPRIATE ACTIONS.                           *          
      *                                                              *          
      *      NOTE: THIS EXAMPLE SHOWS A TYPICAL CALL FROM AN         *          
      *            APPLICATION PROGRAM. IN THIS CASE THE PROGRAMMER  *          
      *            IS REQUESTING A SINGLETON SELECT ACTION TO RETURN *          
      *            DATA FOR A PARTICULAR PARTNER_ID.                 *          
      *                                                              *          
      *            THE PROGRAMMER SHOULD ALWAYS CHECK MODULE RESULT  *          
      *            CODE RETURNED FROM EDV024 TO VALIDTE THAT IT      *          
      *            WORKED PROPERLY (SEE THE COPYBOOK EDR001 FOR A    *          
      *            LIST OF ERROR CODES).                             *          
      ****************************************************************          
      ****************************************************************          
      *   SINGLETON SELECT                                           *          
      *  ==================                                          *          
      * INPUT  = EDV024-KEY-*        (SUPPLY ALL KEY VARIABLES)      *          
      *        = EDV024-ACTION-CD    (SET TO 'S ')                   *          
      * OUTPUT = EDV024-*(1)         (RESULT WILL APPEAR IN          *          
      *                               FIRST OCCURANCE OF THE ARRAY)  *          
      *        = EDV024-OUTPUT-DATA  (ALWAYS CHECK MODULE RESULT)    *          
      ****************************************************************          
      ****************************************************************          
      *   INSERT                                                     *          
      *  ========                                                    *          
      * INPUT  = EDV024-USER-ID      (NAME LISTED IN AUDIT TRAIL)    *          
      *        = EDV024-*(1)         (ALL REQUIRED VALUES FOR NEW    *          
      *                               RECORD MUST BE IN FIRST        *          
      *                               OCCURANCE OF THE ARRAY)        *          
      *        = EDV024-ACTION-CD    (SET TO 'I ')                   *          
      * OUTPUT = EDV024-OUTPUT-DATA  (ALWAYS CHECK MODULE RESULTS)   *          
      ****************************************************************          
      ****************************************************************          
      *   SINGLETON DELETE                                           *          
      *  ==================                                          *          
      * INPUT  = EDV024-KEY-*        (SUPPLY ALL KEY VARIABLES)      *          
      *        = EDV024-USER-ID      (NAME LISTED IN AUDIT TRAIL)    *          
      *        = EDV024-ACTION-CD    (SET TO 'D ')                   *          
      * OUTPUT = EDV024-OUTPUT-DATA  (ALWAYS CHECK MODULE RESULTS)   *          
      ****************************************************************          
      ****************************************************************          
      *   SINGLETON UPDATE                                           *          
      *  ==================                                          *          
      * INPUT  = EDV024-*(1)          (REQUIRED VALUES FOR UPDATED   *          
      *                                RECORD MUST BE IN FIRST       *          
      *                                OCCURANCE OF THE ARRAY)       *          
      *        = EDV024-ACTION-CODE   (SET TO 'U ')                  *          
      * OUTPUT = EDV024-OUTPUT-DATA   (ALWAYS CHECK MODULE RESULTS)  *          
      ****************************************************************          
      ****************************************************************          
      *   OPEN CURSOR                                                *          
      *  =============                                               *          
      * INPUT  = EDV024-ACTION-CODE   (SET TO 'CO')                  *          
      *        = EDV024-*(1)          (PLACE ANY/ALL PARTS OF THE    *          
      *                                SELECT STATEMENT IN THE FIRST *          
      *                                OCCURANCE OF THE ARRAY)       *          
      * OUTPUT = EDV024-OUTPUT-DATA   (ALWAYS CHECK MODULE RESULTS)  *          
      ****************************************************************          
      *   MASS SELECT (FETCH)                                        *          
      *  =====================                                       *          
      * INPUT  = EDV024-ACTION-CODE   (SET TO 'CF')                  *          
      *        = EDV024-*(1)          (PLACE ANY/ALL PARTS OF THE    *          
      *                                BEGINING KEY IN FIRST         *          
      *                                OCCURANCE OF THE ARRAY)       *          
      * OUTPUT = EDV024-OUTPUT-DATA   (ALWAYS CHECK MODULE RESULTS)  *          
      *        = EDV024-*(*)          (ARRAY RETURNS UP TO 20 ROWS.) *          
      * TO RETRIEVE THE NEXT 20, PLACE *(20) IN *(1) AND FETCH AGAIN *          
      ****************************************************************          
      *   CLOSE CURSOR                                               *          
      *  ==============                                              *          
      * INPUT  = EDV024-ACTION-CODE   (SET TO 'CL')                  *          
      * OUTPUT = EDV024-OUTPUT-DATA   (ALWAYS CHECK MODULE RESULTS)  *          
      ****************************************************************          
      ****************************************************************          
      *   COUNT                                                      *          
      *  =======                                                     *          
      * INPUT  = EDV024-ACTION-CODE   (SET TO 'C ')                  *          
      * OUTPUT = EDV024-OUTPUT-DATA   (ALWAYS CHECK MODULE RESULTS)  *          
      * NUMBER OF RECORDS IN THE TABLE WILL BE IN EDV024-ROW-COUNT   *          
      ****************************************************************
