      *                                                              *          
      *  COPYBOOK: RWW013                                            *          
      *                                                              *          
      *  PROGRAM FUNCTION:                                           *          
      *                                                              *          
      *  THE PROGRAM IS DESIGNED TO ACCESS A TABLE OF ZIP CODES      *          
      *  AND, IN CONJUNCTION WITH ORDER AND CUSTOMER INFORMATION,    *          
      *  DETERMINE WHETHER INGRAM MICRO OR THE CUSTOMER WILL PAY     *          
      *  THE FREIGHT CHARGES FOR THE ORDER.                          *          
      *                                                              *          
      *  THE FOLLOWING INFORMATION MUST BE PASSED FROM THE CALLING   *          
      *  PROGRAM TO RWP013.                                          *          
      *  1. THE COUNTRY/COMPANY CODE (ORH-COMPANY)                   *          
      *  2. THE SHIP FROM BRANCH (ORSH-BR-NBR-SHIP-FROM)             *          
      *  3. THE POSTAL CODE                                          *          
      *     A. FOR DESTINATIONS WITHIN THE UNITED STATES, THE        *          
      *        9 DIGIT ZIP CODE MUST BE USED (ORH-ZIP-CODE)          *          
      *        NOTE: THE LAST 4 DIGITS OF THE ZIP CODE ARE CHANGED   *          
      *              TO ZEROES WITHIN THIS PROGRAM. THIS WILL HAVE   *          
      *              TO BE ADDRESSED IF WE START DEALING WITH        *          
      *              SPECIFIC ADDRESSES WITHIN A ZIP CODE.           *          
      *     B. FOR DESTINATIONS OUTSIDE THE UNITED STATES, THE       *          
      *        POSTAL CODE MAY BE ALPHA NUMERIC AND 6 CHARACTERS     *          
      *        IN LENGTH (ORH-POSTAL-CODES)                          *          
      *  4. THE TOTAL VALUE OF THE ORDER (ORH-ORDER-VALUE-AT-ADD)    *          
      *  5. THE CURRENT FREIGHT OUT CODE FROM THE SHIPMENT HEADER    *          
      *     (ORSH-FRT-OUT-CODE)                                      *          
      *  6. THE FLAG ON THE SHIPMENT HEADER OVERFLOW INDICATING      *          
      *     THAT THE REP HAS CHANGED THE FREIGHT OUT CODE            *          
      *     (ORSHOF-FRT-OUT-REP-OVERIDE-FLG)                         *          
      *  7. THE NON-STANDARD FREIGHT OVERRIDE FLAG FROM THE          *          
      *     CUSTOMER OVERFLOW SEGMENT (CUOF-NON-STD-FRT-XMPT-FLG)    *          
      *  8. THE NON-STANDARD FREIGHT LIMIT AMOUNT FROM THE           *          
      *     CUSTOMER OVERFLOW SEGMENT (CUOF-NON-STD-FRT-LIMIT-AMT)   *          
      *  9. THE BILL ONLY FLAG FROM THE SHIPMENT HEADER              *          
      *     (ORSH-BILL-ONLY-SW).                                     *          
      * 10. THE CARRIER CODE FROM THE SHIPMENT HEADER                *          
      *     (ORSH-CARRIER-CODE).                                     *          
      * 11. THE CARRIER CODE CHANGE SWITCH FROM THE SHIPMENT HEADER  *          
      *     (ORSH-CARRIER-SW).                                       *          
      *     NOTE: THE CARRIER CODE CHANGE SWITCH SHOULD ONLY BE      *          
      *           POPULATED IN ECOMMERCE PROGRAMS. TELEMARKETERS     *          
      *           MAY OVERRIDE THE CARRIER CODE FOR VALID BUSINESS   *          
      *           REASONS AND THE CUSTOMER SHOULD NOT BE FORCED TO   *          
      *           PAY THE FREIGHT CHARGES IF THE TELEMARKETER HAS    *          
      *           CHANGED THE CARRIER.                               *          
      * 12. THE THIRD PARTY FREIGHT ACCOUNT FROM THE SHIPMENT HEADER *          
      *     (ORSH-THIRD-PARTY-FRT-ACCOUNT).                          *          
      * 13. WE PAY, WE PICK CARRIER CHANGE EXEMPT FLAG               *  MJF03035
      *     (CUOF-CARRIER-CHG-EXEMPT-IND).                           *  MJF03035
      * 14. CUSTOMER DEFAULT CARRIER CODE (CUA-DEF-CARRIER AND       *  MJF03035
      *     CUA-ALT-DEF-CAR).                                        *  MJF03035
      * 15. FUNCTION REQUEST:                                        *  JJU03260
      *        IF 'ALL'  THEN ALL FIELDS MUST BE PASSED TO PGM       *  JJU03260
      *            RWP013 FOR VERIFICATION.                          *  JJU03260
      *        IF 'STNS' THEN ONLY FOLLOWING 3 FIELDS NEED BE PASSED *  JJU03260
      *            TO PGM RWP013 FOR VERIFICATION:                   *  JJU03260
      *                  1. RWW013-COMPANY                           *  JJU03260
      *                  2. RWW013-POSTAL-CODE                       *  JJU03260
      *                  3. RWW013-BR-NBR-SHIP-FROM                  *  JJU03260
      *                                                              *          
      *  THE FOLLOWING INFORMATION MUST BE PASSED FROM RWP013 TO     *          
      *  THE CALLING PROGRAM.                                        *          
      *  1. THE CORRECT FREIGHT OUT CODE THAT SHOULD BE USED TO      *          
      *     REPLACE THE CURRENT FREIGHT OUT CODE ON THE SHIPMENT     *          
      *     HEADER (ORSH-FRT-OUT-CODE)                               *          
      *     NOTE: THIS FREIGHT OUT CODE MAY BE THE SAME AS THE ONE   *          
      *           PASSED TO RWP013.                                  *          
      *  2. THE CORRECT 'SPLIT' VARIABLE (RWW013-STD-OR-NONSTD)      *  JJU03260
      *     FOR USE IN THE FREIGHT MODULE.                           *  JJU03260
