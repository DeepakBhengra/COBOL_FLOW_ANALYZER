      ****************************************************************          
      *  COPYBOOK:  EDT042                                           *          
      ****************************************************************          
      *                                                              *          
      * OVERVIEW:                                                    *          
      *  USED IN SUB-ROUTINE  EDV042 TO SUPPLY A CALLING PROGRAM     *          
      *  ACTIONS, DATA, AND AN AREA TO RETURN DATA AND RESULT CODE   *          
      *  INFORMATION.                                                *          
      *                                                              *          
      *     INPUT: EDV042-INPUT-DATA                                 *          
      *            - OBJECT ID                                       *          
      *            - ACTION CODE                                     *          
      *            - USER ID                                         *          
      *            - COMPANY CODE                                    *          
      *            - PARTNER ID                                      *          
      *     INPUT/OUTPUT: EDV042-INPUT-OUTPUT-ARRAY-AREA             *          
      *            - ARRAY COUNT                                     *          
      *            - EDV042-ARRAY (OCCURS UP TO 20 TIMES)            *          
      *              - EDV042-CO-CD                                  *          
      *              - EDV042-PARTNER-ID                             *          
      *              - EDV042-PARTNER-DES                            *          
      *              - EDV042-PRNT-PARTNER-ID                        *          
      *              - EDV042-ACTV-DT                                *          
      *              - EDV042-DEACTV-DT                              *          
      *              - EDV042-NOTE-TXT                               *          
      *              - EDV042-CUST-VDR-NBR                           *  KXR02031
      *              - EDV042-LST-CHG-TS                             *          
      *              - EDV042-LST-CHG-NAM                            *          
      *              - EDV042-POS-SELLER-NBR                         *  RPB02109
      *                                                              *          
      *    OUTPUT: EDV042-OUTPUT-DATA                                *          
      *          - EDV042-ROW-COUNT                                  *          
      *          - EDV042-MODULE-RESULT-CD                           *          
      *          - EDV042-MODULE-MESSAGE                             *          
      *          - EDV042-DATABASE-RESULT-CODES:                     *          
      *              - EDV042-SQLCODE                                *          
      *              - EDV042-SQLSTATE                               *          
      *              - EDV042-SQL-MESSAGE                            *          
      *                                                              *          
      *                                                              *          
      *   EDV042 EXAMPLE FOR REQUESTING A SINGLETON SELECT ACTION.   *          
      *     INITIALIZE EDV042-COMMUNICATIONS-AREA.                   *          
      *     MOVE PGM-PARTNER-ID TO EDV042-PARTNER-ID.                *          
      *     MOVE 'S ' TO EDV042-ACTION-CD.     .                     *          
      *     MOVE 'IE_PARTNER' TO EDV042-OBJECT-ID.                   *          
      *                                                              *          
      *     CALL 'EDV042' USING EDV042-COMMUNICATIONS-AREA.          *          
      *     IF EDV042-STATUS-OK                                      *          
      *     THEN                                                     *          
      *          CONTINUE WITH EXPECTED PROCESSING                   *          
      *     ELSE                                                     *          
      *          CONTINUE CHECK FOR DETAILED ERROR CONDITIONS AND    *          
      *          TAKE APPROPRIATE ACTIONS.                           *          
      *                                                              *          
      *      NOTE: THIS EXAMPLE SHOWS A TYPICAL CALL FROM AN         *          
      *            APPLICATION PROGRAM. IN THIS CASE THE PROGRAMMER  *          
      *            IS REQUESTING A SINGLETON SELECT ACTION TO RETURN *          
      *            DATA FOR A PARTICULAR PARTNER_ID.                 *          
      *                                                              *          
      *            THE PROGRAMMER SHOULD ALWAYS CHECK MODULE RESULT  *          
      *            CODE RETURNED FROM EDV042 TO VALIDTE THAT IT      *          
      *            WORKED PROPERLY (SEE THE COPYBOOK EDT042 FOR A    *          
      *            LIST OF ERROR CODES).                             *          
      *                                                              *
