      ****************************************************************          
      *  COPYBOOK:  EDT011                                           *          
      ****************************************************************          
      *                                                              *          
      * OVERVIEW:                                                    *          
      *  USED IN SUB-ROUTINES EDV011 TO SUPPLY A CALLING PROGRAM     *          
      *  ACTIONS, DATA, AND AN AREA TO RETURN DATA AND RESULT CODE   *          
      *  INFORMATION.                                                *          
      *                                                              *          
      *     INPUT: EDV011-INPUT-DATA                                 *          
      *            - OBJECT ID                                       *          
      *            - ACTION CODE                                     *          
      *            - USER ID                                         *          
      *            - COMPANY CODE                                    *          
      *            - PARTNER ID                                      *          
      *     INPUT/OUTPUT: EDV011-INPUT-OUTPUT-ARRAY-AREA             *          
      *            - ARRAY COUNT                                     *          
      *            - EDV011-ARRAY (OCCURS UP TO 20 TIMES)            *          
      *              - EDV011-CO-CD                                  *          
      *              - EDV011-PARTNER-ID                             *          
      *              - EDV011-PROCS-OPTN-FLG                         *  CDA02202
      *              - EDV011-LIST-TYPE-TXT                          *  CDA02202
      *              - EDV011-MAIL-ADDR-TXT                          *  CDA02202
      *              - EDV011-LST-CHG-TS                             *          
      *              - EDV011-LST-CHG-NAM                            *          
      *                                                              *          
      *    OUTPUT: EDV011-OUTPUT-DATA                                *          
      *          - EDV011-ROW-COUNT                                  *          
      *          - EDV011-MODULE-RESULT-CD                           *          
      *          - EDV011-MODULE-MESSAGE                             *          
      *          - EDV011-DATABASE-RESULT-CODES:                     *          
      *              - EDV011-SQLCA VALUES                           *          
      *              - EDV011-SQLCODE                                *          
      *              - EDV011-SQLSTATE                               *          
      *                                                              *          
      *                                                              *          
      *   EDV011 EXAMPLE FOR REQUESTING A SINGLETON SELECT ACTION.   *          
      *     INITIALIZE EDV011-COMMUNICATIONS-AREA.                   *          
      *     MOVE PGM-PARTNER-ID TO EDV011-PARTNER-ID.                *          
      *     MOVE 'S ' TO EDV011-ACTION-CD.     .                     *          
      *     MOVE 'IE_MAILING_LIST' TO EDV011-OBJECT-ID.              *          
      *                                                              *          
      *     CALL 'EDV011' USING EDV011-COMMUNICATIONS-AREA.          *          
      *     IF EDV011-STATUS-OK                                      *          
      *     THEN                                                     *          
      *          CONTINUE WITH EXPECTED PROCESSING                   *          
      *     ELSE                                                     *          
      *          CONTINUE CHECK FOR DETAILED ERROR CONDITIONS AND    *          
      *          TAKE APPROPRIATE ACTIONS.                           *          
      *                                                              *          
      *      NOTE: THIS EXAMPLE SHOWS A TYPICAL CALL FROM AN         *          
      *            APPLICATION PROGRAM. IN THIS CASE THE PROGRAMMER  *          
      *            IS REQUESTING A SINGLETON SELECT ACTION TO RETURN *          
      *            DATA FOR A PARTICULAR PARTNER_ID.                 *          
      *                                                              *          
      *            THE PROGRAMMER SHOULD ALWAYS CHECK MODULE RESULT  *          
      *            CODE RETURNED FROM EDV011 TO VALIDTE THAT IT      *          
      *            WORKED PROPERLY (SEE THE COPYBOOK EDT001 FOR A    *          
      *            LIST OF ERROR CODES).                             *          
      *                                                              *
