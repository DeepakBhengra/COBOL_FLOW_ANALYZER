003300*                                                                *        
003400* ORLOF-ORSLNEOF IS THE GENERIC GROUP LEVEL ITEM FOR ALL IO      *        
003500* MODULES. THESE MODULES READ INTO AND WRITE FROM THIS GROUP     *        
003600* ITEM.                                                          *        
003700* THE ACTUAL DATA ELEMENTS ARE DEFINED IN THE OTHER LAYOUTS.     *        
003800* THIS METHODOLOGY WAS ESTABLISHED TO PERMIT AVAILABILITY OF     *        
003900* INFORMATION FROM MULTIPLE ORSLNE OVERLOW SEGMENTS. THIS        *        
004000* ELIMINATES THE NEED TO SAVE DATA IN PROGRAM SPECIFIC           *        
004100* WORKING-STORAGE FIELDS AS WOULD OCCUR IF ORLOF-ORSLNEOF WERE   *        
004200* REDEFINED FOR OTHER SEGMENT TYPES.                             *        
004300*                                                                *        
004400* FOR EXAMPLE, FIELDS IN ORLOF-ORSLNEOF-0 WOULD BE POPULATED     *        
004500* WITH DATA, TO INCLUDE ORLOF-ORSLNEOF-KEY-0 WHICH IS '0'.       *        
004600* GROUP ITEM ORLOF-ORSLNEOF-0 WOULD THEN BE MOVED TO GROUP       *        
004700* ITEM ORLOF-ORSLNEOF WHICH WOULD THEN BE WRITTEN TO THE         *        
004800* DATABASE.                                                      *        
004900*                                                                *        
005000* THE REVERSE WOULD OCCUR DURING A READ FROM THE DATABASE. THE   *        
005100* DATA WOULD BE READ INTO ORLOF-ORSLNEOF AND THEN MOVED TO       *        
005200* ORLOF-ORSLNEOF-0 (OR OTHER LAYOUT AS REQUIRED) SO THE          *        
005300* INFORMATION CAN BE USED BY THE PROGRAM.                        *        
005400*                                                                *        
005500* AVAILABLE SPACE THAT WOULD NORMALLY BE LABELLED AS FILLER      *        
005600* WAS GIVEN A FIELD NAME (AS IN ORLOF-FILLER OR ORLOF-FILLER-0)  *        
005700* TO FACILITATE THE USE OF THE INITIALIZE VERB. THIS VERB MOVES  *        
005800* SPACES AND ZEROES TO VALID FIELD NAMES BASED UPON THEIR        *        
005900* DEFINITION. IT DOES NOT MOVE SPACES TO AREAS LABELLED WITH     *        
006000* THE RESERVED WORD 'FILLER'.                                    *        
006100*                                                                *
