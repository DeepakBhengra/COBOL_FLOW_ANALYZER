      *                      REQUEST/RESPONSE AREAS                             
      *****************************************************************         
                                                                                
                                                                                
         02 SYWSPS-REQUEST-RESPONSE-AREAS.                                      
                                                                                
      ***************************************************************           
      *    THE STRATEGIC PRICING REQUEST AREA FOR A SINGLE SKU                  
      ***************************************************************           
                                                                                
           03 SYWSPS-REQUEST-GROUP.                                             
                                                                                
            04 SYWSPS-REQUEST-AREAS                                             
                 OCCURS 1 TIMES.                                                
               05 SYWSPS-REQUEST-AREA.                                          
                                                                                
      *    (THE REQUEST AREA CONTAINS THE SINGLE SKU TO BE PRICED)              
       COPY SYWSPSRQ.                                                           
                                                                                
                                                                                
      ***************************************************************           
      *    THE STRATEGIC PRICING RESPONSE AREA FOR A SINGLE SKU                 
      ***************************************************************           
                                                                                
           03 SYWSPS-RESPONSE-GROUP.                                            
                                                                                
            04 SYWSPS-RESPONSE-AREAS                                            
                 OCCURS 1 TIMES.                                                
               05 SYWSPS-RESPONSE-AREA.                                         
                                                                                
      *    (THE RESPONSE AREAS REPEAT TO RETURN EACH QTY BREAK PRICE)           
       COPY SYWSPSRS.
