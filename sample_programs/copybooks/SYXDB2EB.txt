      *    BATCH DB2 ERROR TEXT MESSAGE HANDLER.                                
      *    FUNCTIONS:                                                           
      *       1)  CONVERT SQL RETURN CODE INTO A TEXT MESSAGE.                  
      *       2)  DISPLAY THE CONVERTED SQL TEXT MESSAGE                        
      *       3)  DISPLAY THE 'EXTRA' DIAGNOSTIC MESSAGE LINES.                 
      *                                                                         
      *    NOTE: REQUIRES WORKING-STORAGE COPYBOOK SYWDB2ER.                    
      ******************************************************************        
      *                                                                         
      * PROGRAM EXAMPLE:                                                        
      *    .                                                                    
      * WORKING-STORAGE.                                                        
      *    COPY SYWDB2ER.                                                       
      *    .                                                                    
      *    .                                                                    
      * PROCEDURE DIVISION.                                                     
      *    .                                                                    
      *    EXEC SQL XXXXXXX    END-EXEC                                         
      *    .                                                                    
      *    IF TROUBLE                                                           
      *       MOVE 'RECORD NOT FOUND'     TO  SYWDB2-EXTRA-MESSAGE-1            
      *       MOVE WS-KEY-INFO            TO  SYWDB2-EXTRA-MESSAGE-2            
      *       PERFORM 990-SQL-MESSAGE                                           
      *    ELSE                                                                 
      *       IF BIG-TROUBLE                                                    
      *          MOVE 'UPDATE ERROR'      TO  SYWDB2-EXTRA-MESSAGE-1            
      *          MOVE WS-KEY-INFO         TO  SYWDB2-EXTRA-MESSAGE-2            
      *          PERFORM 990-SQL-MESSAGE                                        
      *          PERFORM 999-ABEND.                                             
      *    .                                                                    
      *    .                                                                    
      *                             COPY SYXDB2EB.                              
      *    .

      *    CONVERT SQL RETURN CODE TO TEXT MESSAGE

                                           SYWDB2-ERROR-MESSAGE

                UNTIL  SYWDB2-ERROR-INDEX > +10                                 
              IF SYWDB2-ERROR-TEXT (SYWDB2-ERROR-INDEX) > SPACES                
                 DISPLAY SYWDB2-ERROR-TEXT (SYWDB2-ERROR-INDEX)
