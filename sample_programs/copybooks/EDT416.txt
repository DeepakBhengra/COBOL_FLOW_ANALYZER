      ****************************************************************          
      *  COPYBOOK:  EDT416                                           *          
      ****************************************************************          
      *                                                              *          
      * OVERVIEW:                                                    *          
      *  USED IN SUB-ROUTINE  EDV416 TO SUPPLY A CALLING PROGRAM     *          
      *  ACTIONS, DATA, AND AN AREA TO RETURN DATA AND RESULT CODE   *          
      *  INFORMATION.                                                *          
      *                                                              *          
      *     INPUT: EDV416-INPUT-DATA                                 *          
      *            - ACTION CODE                                     *          
      *            - COMPANY CODE                                    *          
      *     INPUT/OUTPUT: EDV416-INPUT-OUTPUT-ARRAY-AREA             *          
      *            - ARRAY COUNT                                     *          
      *            - EDV416-ARRAY (OCCURS UP TO 20 TIMES)            *          
      *            - EDV416-CO-CD                                    *          
      *            - EDV416-CO-NAM                                   *          
      *            - EDV416-PARTITON-NBR                             *          
      *            - EDV416-BUS-REGN-CD                              *          
      *            - EDV416-CNTRY-CD                                 *          
      *                                                              *          
      *    OUTPUT: EDV416-OUTPUT-DATA                                *          
      *             - EDV416-MODULE-RESULT-CD                        *          
      *             - EDV416-MODULE-MESSAGE                          *          
      *             - EDV416-DATABASE-RESULT-CODES:                  *          
      *                 - EDV416-SQLCODE                             *          
      *                 - EDV416-SQLSTATE                            *          
      *                 - EDV416-SQL-MESSAGE                         *          
      *                                                              *          
      *   PROCESS:                                                   *          
      *            1) VALIDATE THE ACTION CODE.                      *          
      *            2) EVALUTE THE ACTION CODE AND PERFORM THE        *          
      *               REQUESTED FUNCTION DOING THE FOLLOWING:        *          
      *               A. EDIT THE INPUT PARAMETERS RELATED TO THE    *          
      *                  ACTION CODE REQUEST.                        *          
      *               B. PERFORM THE REQUESTED ACTION AGAINST THE    *          
      *                  WW.COMPANY TABLE.                           *          
      *                  DATA AREAS AND CALL THE AUDIT TRAIL LOGGING *          
      *            3) WHEN ANY PARAMETER EDITS FAIL, TABLE I/O       *          
      *               RETURNS AN INVALID SQLCODE,                    *          
      *               FORMAT THE APPROPRIATE RESULT CODE AND MESSAGE *          
      *               BEFORE RETURNING TO THE CALLING PROGRAM.       *          
      *            4) IF ALL EDITS AND I/O ARE SUCCESSFULLY COMPLETED*          
      *               FORMAT THE APPROPRIATE RESULT CODE AND MESSAGE *          
      *               BEFORE RETURNING TO THE CALLING PROGRAM.       *          
      *                                                              *          
      *   EDV416 EXAMPLE CALL FOR AN SELECT ACTION FOR WW_COMPANY:   *          
      *                                                              *          
      *    INITIALIZE     EDV416-COMMUNICATIONS-AREA.                *          
      *    SET EDV416-SELECT            TO TRUE.                     *          
      *                                                              *          
      *  DEFAULT THE MODULE STATUS CODE TO 'OK' FOR THE START OF THE *          
      *  EDIT AND I/O PROCESS.                                       *          
      *                                                              *          
      *    SET EDV416-STATUS-OKAY      TO TRUE.                      *          
      *                                                              *          
      *    MOVE "COMPANY CODE"         TO EDV416-KEY-CO-CD.          *          
      *                                                              *          
      *    MOVE 1                      TO EDV416-ARRAY-COUNT.        *          
      *    MOVE "COMPANY CODE"         TO EDV416-CO-CD(1).           *          
      *                                                              *          
      *    CALL 'EDV416' USING EDV416-COMMUNICATIONS-AREA.           *          
      *                                                              *          
      *     IF EDV416-STATUS-OKAY                                    *          
      *     THEN                                                     *          
      *          ..........                                          *          
      *     ELSE                                                     *          
      *          ..........                                          *          
      *                                                              *          
      *      NOTE: THIS EXAMPLE SHOWS A TYPICAL CALL FROM AN         *          
      *            APPLICATION PROGRAM. IN THIS CASE THE PROGRAMMER  *          
      *            IS REQUESTING AN  'SELECT' ACTION                 *          
      *                                                              *          
      *                                                              *          
      *            THE PROGRAMMER SHOULD ALWAYS CHECK MODULE RESULT  *          
      *            CODE RETURNED FROM EDV416 TO VALIDTE THAT IT      *          
      *            WORKED PROPERLY (SEE THE COPYBOOK EDT042 FOR A    *          
      *            LIST OF ERROR CODES).                             *
