       SP910-MOVE-SKU-RESPONSE.                                                 
                                                                                
      *   (WHEN BOTH THE OVERALL PRICE REQUEST AND INDIVIDUAL RESPONSE          
      *    STATUSES ARE OKAY MOVE STRATAGIC PRICING RESPONSE FIELDS TO          
      *    STANDARD WS FIELDS WHERE APPLICATIONS CURRENTLY EXPECT THEM)         
                                                                                
           IF  SYWSPH-STATUS-OK                                                 
               OF SYWSP-CONNECTOR-DATA                                          
           AND (   SYWSPS-R-RECORD-NO-ERRORS                                    
                   OF SYWSP-CONNECTOR-DATA (SYWSPSRS-IDX)                       
      *        (WARNINGS ALSO RETURN A PRICE TO BE MOVED)                       
                OR SYWSPS-R-RECORD-WARNING-FOUND                                
                   OF SYWSP-CONNECTOR-DATA (SYWSPSRS-IDX)                       
               )                                                                
      *       (POPULATE STANDARD PRICING RESPONSE FIELDS)                       
               PERFORM SP912-MOVE-RESPONSE-FIELDS                               
           ELSE                                                                 
      *       (PERFORM STANDARD STRATEGIC PRICING ERROR HANDLING)               
               PERFORM SP918-SP-ERROR-HANDLING                                  
           END-IF.                                                              
                                                                                
                                                                                
      **>>>-------------------------------------------------------<<<**         
      **>>> THIS ROUTINE IS PERFORMED TO MOVE ALL THE RESPONSE    <<<**         
      **>>> FIELDS TO STANDARD PRICING WORKING STORAGE FIELDS.    <<<**         
      **>>>                                                       <<<**         
      **>>> ONCE THE RESPONSE VALUES HAVE BEEN RETURNED FROM THE  <<<**         
      **>>> PRICING ENGINE, IT IS VERY IMPORTANT THAT THE         <<<**         
      **>>> APPLICATIONS DO NOT MODIFY ANY OF THESE VALUES        <<<**         
      **>>> IN ANY WAY (IN EITHER WORKING STORAGE OR THE ORDER    <<<**         
      **>>> LINE).                                                <<<**         
      **>>>                                                       <<<**         
      **>>>-------------------------------------------------------<<<**         
                                                                                
       SP912-MOVE-RESPONSE-FIELDS.                                              
                                                                                
      *   (INITIALLY SET THE UNIT PRICE WITH AN UNSIGNED VALUE)                 
           MOVE SYWSPS-R-UNIT-PRICE                                             
             OF SYWSP-CONNECTOR-DATA (SYWSPSRS-IDX)                             
             TO WS-UNIT-PRICE                                                   
      *      (WHEN UNIT PRICE NEGATIVE, SET IT TO A NEGATIVE VALUE)             
           IF SYWSPS-R-UNIT-PRICE-NEG                                           
              OF SYWSP-CONNECTOR-DATA (SYWSPSRS-IDX)                            
              MULTIPLY -1 BY WS-UNIT-PRICE                                      
           END-IF.                                                              
                                                                                
      *   (INITIALLY SET THE FLOOR PRICE WITH AN UNSIGNED VALUE)                
           MOVE SYWSPS-R-FLOOR-PRICE                                            
             OF SYWSP-CONNECTOR-DATA (SYWSPSRS-IDX)                             
             TO SYWSPV-FLOOR-PRICE                                              
      *   (WHEN FLOOR PRICE NEGATIVE, SET IT TO A NEGATIVE VALUE)               
           IF SYWSPS-R-FLOOR-PRICE-NEG                                          
              OF SYWSP-CONNECTOR-DATA (SYWSPSRS-IDX)                            
              MULTIPLY -1 BY SYWSPV-FLOOR-PRICE                                 
           END-IF.                                                              
                                                                                
      *   (INITIALLY SET THE RESELLER BASE WITH AN UNSIGNED VALUE)              
            MOVE SYWSPS-R-RSLR-BASE-PRICE                                       
              OF SYWSP-CONNECTOR-DATA (SYWSPSRS-IDX)                            
              TO WS-PRC-RESELLER-BASE-PRICE                                     
      *   (WHEN RESLR BASE NEGATIVE, SET IT TO A NEGATIVE VALUE)                
           IF SYWSPS-R-RSLR-BASE-PRC-NEG                                        
              OF SYWSP-CONNECTOR-DATA (SYWSPSRS-IDX)                            
              MULTIPLY -1 BY WS-PRC-RESELLER-BASE-PRICE                         
           END-IF.                                                              
                                                                                
      *   (INITIALLY SET THE ACOP APPLIED WITH AN UNSIGNED VALUE)               
           MOVE SYWSPS-R-ACOP-AMT-APPLIED                                       
             OF SYWSP-CONNECTOR-DATA (SYWSPSRS-IDX)                             
             TO ICWCOP-ACOP-DELTA-TO-PRICE                                      
      *   (WHEN ACOP APPLIED NEGATIVE, SET IT TO A NEGATIVE VALUE)              
           IF SYWSPS-R-ACOP-AMT-APLD-NEG                                        
              OF SYWSP-CONNECTOR-DATA (SYWSPSRS-IDX)                            
              MULTIPLY -1 BY ICWCOP-ACOP-DELTA-TO-PRICE                         
           END-IF.                                                              
                                                                                
      *   (SET THE ACOP SOURCE RETURNED FROM THE PRICING ENGINE)                
           MOVE SYWSPS-R-ACOP-SRC-CD                                            
             OF SYWSP-CONNECTOR-DATA (SYWSPSRS-IDX)                             
             TO ICWCOP-APPLY-ACOP-IND-SRC.                                      
                                                                                
      *   (SET THE ACOP INDICATOR RETURNED FROM THE PRICING ENGINE)             
           MOVE SYWSPS-R-ACOP-DELTA-FLAG                                        
             OF SYWSP-CONNECTOR-DATA (SYWSPSRS-IDX)                             
             TO ICWCOP-APPLY-ACOP-DELTA-IND.                                    
                                                                                
      *    (INITIALLY SET THE ENGINE PRICE WITH AN UNSIGNED VALUE)              
            MOVE SYWSPS-R-ENGINE-PRICE                                          
              OF SYWSP-CONNECTOR-DATA (SYWSPSRS-IDX)                            
              TO WS-UNIT-PRICE-END-USER                                         
      *      (WHEN PRICE NEGATIVE, SET IT TO A NEGATIVE VALUE)                  
           IF SYWSPS-R-ENGINE-PRICE-NEG                                         
              OF SYWSP-CONNECTOR-DATA (SYWSPSRS-IDX)                            
              MULTIPLY -1 BY WS-UNIT-PRICE-END-USER                             
           END-IF.                                                              
                                                                                
      *   (THE PRICING ENGINE RETURNS NEW/UNIQUE PRICE SWITCH VALUES)           
           MOVE SYWSPS-R-PRICE-CD                                               
             OF SYWSP-CONNECTOR-DATA (SYWSPSRS-IDX)                             
             TO WS-PRICE-SW.

       SP918-SP-ERROR-HANDLING.                                                 
                                                                                
      *   (WHEN THE OVERALL STATUS IS OKAY, BUT AN ERROR WAS RETURNED           
      *    AT THE SKU REQUEST LEVEL, PERFORM THIS STANDARD ERROR                
      *    HANDLING)                                                            
                                                                        AXR05039
      *   (INITIALIZE NUMERIC RESPONSE FIELDS)                          AXR05039
           MOVE ZERO                                                    AXR05039
             TO WS-UNIT-PRICE                                           AXR05039
                SYWSPV-FLOOR-PRICE                                      AXR05039
                WS-PRC-RESELLER-BASE-PRICE                              AXR05039
                ICWCOP-ACOP-DELTA-TO-PRICE                              AXR05039
                WS-UNIT-PRICE-END-USER.                                 AXR05039
                                                                        AXR05039
      *   (INITIALIZE ALPHANUMERIC RESPONSE FIELDS)                     AXR05039
           MOVE SPACES                                                  AXR05039
             TO ICWCOP-APPLY-ACOP-IND-SRC                               AXR05039
                ICWCOP-APPLY-ACOP-DELTA-IND.                            AXR05039
                                                                                
                                                                                
      *   (WHEN A SKU LEVEL ERROR EXISTS AND THERE WAS AN OVERRIDE              
      *    PRICE, SAVE THE OVERRIDE PRICE IN THE UNIT PRICE FIELD)              
           IF  SYWSPH-STATUS-OK                                                 
               OF SYWSP-CONNECTOR-DATA                                          
           AND SYWSPS-R-RECORD-ERROR-FOUND                                      
               OF SYWSP-CONNECTOR-DATA (SYWSPSRS-IDX)                           
      *       (PRICE CD OF 'Z' IS DEFAULTED BEFORE INVOKING CONNECTOR)          
               MOVE SYWSPS-R-PRICE-CD                                           
                 OF SYWSP-CONNECTOR-DATA (SYWSPSRS-IDX)                         
                 TO WS-PRICE-SW                                                 
      *       (WHEN OVERRIDE, SAVE OVERRIDE AMOUNT TO UNIT PRICE)               
               IF  SYWSPS-OVERRIDE-PRC-YES                                      
                   OF SYWSP-CONNECTOR-DATA (SYWSPSRS-IDX)                       
      *           (SAVE THE OVERRIDE PRICE)                                     
                   MOVE SYWSPS-OVERRIDE-PRICE                                   
                     OF SYWSP-CONNECTOR-DATA (SYWSPSRS-IDX)                     
                     TO SYWSPS-R-UNIT-PRICE                                     
                        OF SYWSP-CONNECTOR-DATA (SYWSPSRS-IDX)                  
                        WS-UNIT-PRICE                                           
      *           (SAVE THE OVERRIDE PRICE SIGN)                                
                   MOVE SYWSPS-OVERRIDE-PRICE-SGN                               
                     OF SYWSP-CONNECTOR-DATA (SYWSPSRS-IDX)                     
                     TO SYWSPS-OVERRIDE-PRICE-SGN                               
                        OF SYWSP-CONNECTOR-DATA (SYWSPSRS-IDX)                  
      *           (WHEN NEGATIVE SIGN SET UNIT PRICE TO NEGATIVE)               
                   IF SYWSPS-R-UNIT-PRICE-NEG                                   
                      OF SYWSP-CONNECTOR-DATA (SYWSPSRS-IDX)                    
                      MULTIPLY -1 BY WS-UNIT-PRICE                              
                   END-IF                                                       
               END-IF                                                           
           END-IF.
