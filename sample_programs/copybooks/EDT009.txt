      *                                                              *          
      * OVERVIEW:                                                    *          
      *  USED IN SUB-ROUTINES EDV009 TO SUPPLY A CALLING PROGRAM     *          
      *  ACTIONS, DATA, AND AN AREA TO RETURN DATA AND RESULT CODE   *          
      *  INFORMATION.                                                *          
      *                                                              *          
      *     INPUT: EDV009-INPUT-DATA                                 *          
      *            - OBJECT ID                                       *          
      *            - ACTION CODE                                     *          
      *            - USER ID                                         *          
      *            - COMPANY CODE                                    *          
      *            - PARTNER ID                                      *          
      *     INPUT/OUTPUT: EDV009-INPUT-OUTPUT-ARRAY-AREA             *          
      *            - ARRAY COUNT                                     *          
      *            - EDV009-ARRAY (OCCURS UP TO 20 TIMES)            *          
      *              - EDV009-CO-CD                                  *          
      *              - EDV009-PARTNER-ID                             *          
      *              - EDV009-CREDIT-MEMO-FLG                        *          
      *              - EDV009-ASSET-TAG-FLG                          *          
      *              - EDV009-EDI-PO-FLG                             *          
      *              - EDV009-ZERO-VALUE-FLG                         *          
      *              - EDV009-REFUSAL-FLG                            *          
      *              - EDV009-COMPONENTS-FLG                         *          
      *              - EDV009-INTEREST-INV-FLG                       *          
      *              - EDV009-LST-CHG-TS                             *          
      *              - EDV009-LST-CHG-NAM                            *          
      *                                                              *          
      *    OUTPUT: EDV009-OUTPUT-DATA                                *          
      *          - EDV009-ROW-COUNT                                  *          
      *          - EDV009-MODULE-RESULT-CD                           *          
      *          - EDV009-MODULE-MESSAGE                             *          
      *          - EDV009-DATABASE-RESULT-CODES:                     *          
      *              - EDV009-SQLCA VALUES                           *          
      *              - EDV009-SQLCODE                                *          
      *              - EDV009-SQLSTATE                               *          
      *                                                              *          
      *                                                              *          
      *   EDV009 EXAMPLE FOR REQUESTING A SINGLETON SELECT ACTION.   *          
      *     INITIALIZE EDV009-COMMUNICATIONS-AREA.                   *          
      *     MOVE PGM-PARTNER-ID TO EDV009-PARTNER-ID.                *          
      *     MOVE 'S ' TO EDV009-ACTION-CD.     .                     *          
      *     MOVE 'IE_STORE_XREF ' TO EDV009-OBJECT-ID.               *          
      *                                                              *          
      *     CALL 'EDV009' USING EDV009-COMMUNICATIONS-AREA.          *          
      *     IF EDV009-STATUS-OK                                      *          
      *     THEN                                                     *          
      *          CONTINUE WITH EXPECTED PROCESSING                   *          
      *     ELSE                                                     *          
      *          CONTINUE CHECK FOR DETAILED ERROR CONDITIONS AND    *          
      *          TAKE APPROPRIATE ACTIONS.                           *          
      *                                                              *          
      *      NOTE: THIS EXAMPLE SHOWS A TYPICAL CALL FROM AN         *          
      *            APPLICATION PROGRAM. IN THIS CASE THE PROGRAMMER  *          
      *            IS REQUESTING A SINGLETON SELECT ACTION TO RETURN *          
      *            DATA FOR A PARTICULAR PARTNER_ID.                 *          
      *                                                              *          
      *            THE PROGRAMMER SHOULD ALWAYS CHECK MODULE RESULT  *          
      *            CODE RETURNED FROM EDV009 TO VALIDTE THAT IT      *          
      *            WORKED PROPERLY (SEE THE COPYBOOK EDT009 FOR A    *          
      *            LIST OF ERROR CODES).                             *
