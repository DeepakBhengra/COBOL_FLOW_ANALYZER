      ****************************************************************          
      *  COPYBOOK:  EDT072                                           *          
      ****************************************************************          
      *                                                              *          
      * OVERVIEW:                                                    *          
      *  USED IN SUB-ROUTINE EDV072 TO SUPPLY A CALLING PROGRAM      *          
      *  ACTIONS, DATA, AND AN AREA TO RETURN DATA AND RESULT CODE   *          
      *  INFORMATION                                                 *          
      *                                                              *          
      *     INPUT: EDV072-INPUT-DATA                                 *          
      *            - ACTION CODE                                     *          
      *            - COMPANY CODE                                    *          
      *            - SRCE SYS ID                                     *          
      *            - SRCE SYS KEY ID                                 *          
      *            - PARTNER ID                                      *          
      *            - OBJECT ID                                       *          
      *            - USER ID                                         *          
      *                                                              *          
      *     INPUT/OUTPUT: EDV072-INPUT-OUTPUT-ARRAY-AREA             *          
      *            - ARRAY COUNT                                     *          
      *            - EDV072-ARRAY (OCCURS UP TO 20 TIMES)            *          
      *              - EDV072-CO-CD                                  *          
      *              - EDV072-SRCE-SYS-ID                            *          
      *              - EDV072-SRCE-SYS-KEY-ID                        *          
      *              - EDV072-PARTNER-ID                             *          
      *              - EDV072-LST-CHG-TS                             *          
      *              - EDV072-LST-CHG-NAM                            *          
      *                                                              *          
      *    OUTPUT: EDV072-OUTPUT-DATA                                *          
      *          - EDV072-ROW-COUNT                                  *          
      *          - EDV072-MODULE-RESULT-CD                           *          
      *          - EDV072-MODULE-MESSAGE                             *          
      *          - EDV072-DATABASE-RESULT-CODES:                     *          
      *              - EDV072-SQLCA VALUES                           *          
      *              - EDV072-SQLCODE                                *          
      *              - EDV072-SQLSTATE                               *          
      *                                                              *          
      *   PROCESS:                                                   *          
      *            1) VALIDATE THE ACTION CODE.                      *          
      *            2) EVALUTE THE ACTION CODE AND PERFORM THE        *          
      *               REQUESTED FUNCTION DOING THE FOLLOWING:        *          
      *               A. EDIT THE INPUT PARAMETERS RELATED TO THE    *          
      *                  ACTION CODE REQUEST.                        *          
      *               B. PERFORM THE REQUESTED ACTION AGAINST THE    *          
      *                  IE_PID_SRC_SYS_XRF TABLE.                   *          
      *               C. FORMAT ALL REQUIRED BEFORE AND AFTER IMAGE  *          
      *                  DATA AREAS AND CALL THE AUDIT TRAIL LOGGING *          
      *                  MODULE.                                     *          
      *            3) WHEN ANY PARAMETER EDITS FAIL, TABLE I/O       *          
      *               RETURNS AN INVALID SQLCODE, OR THE AUDIT TRAIL *          
      *               LOGGING PROGRAM RETURNS A FAILURE STATUS;      *          
      *               FORMAT THE APPROPRIATE RESULT CODE AND MESSAGE *          
      *               BEFORE RETURNING TO THE CALLING PROGRAM.       *          
      *            4) IF ALL EDITS AND I/O ARE SUCCESSFULLY COMPLETED*          
      *               FORMAT THE APPROPRIATE RESULT CODE AND MESSAGE *          
      *               BEFORE RETURNING TO THE CALLING PROGRAM.       *          
      *                                                              *          
      *   EDV072 EXAMPLE CALL FOR AN INSERT ACTION:                  *          
      *                                                              *          
      *    INITIALIZE     EDV072-COMMUNICATIONS-AREA.                *          
      *    SET EDV072-INSERT            TO TRUE.                     *          
      *                                                              *          
      *  DEFAULT THE MODULE STATUS CODE TO 'OK' FOR THE START OF THE *          
      *  EDIT AND I/O PROCESS.                                       *          
      *                                                              *          
      *    SET EDV072-STATUS-OKAY      TO TRUE.                      *          
      *                                                              *          
      * - KEYED SELECTS/UPDATES                                      *          
      *    MOVE WS-CO-CD               TO EDV072-KEY-CO-CD.          *          
      *    MOVE WS-SRC-SYS-ID          TO EDV072-KEY-SRCE-SYS-ID.    *          
      *    MOVE WS-SRC-SYS-KEY-ID      TO EDV072-KEY-SRCE-SYS-KEY-ID.*          
      *                                                              *          
      * - INSERTS                                                    *          
      *    MOVE WS-CO-CD               TO EDV072-CO-CD(1).           *          
      *    MOVE 'IMPULS'               TO EDV072-SRCE-SYS-ID(1).     *          
      *    MOVE WS-VENDOR-ID           TO EDV072-SRCE-SYS-KEY-ID(1). *          
      *    MOVE WS-PARTNER-ID          TO EDV072-PARTNER-ID(1).      *          
      *    ... ETC. TO LOAD OTHER FLAG VALUES.....                   *          
      *    MOVE WS-TIMESTAMP           TO EDV072-LST-CHG-TS(1).      *          
      *    REMINDER: TIMESTAMP FORMAT IS:'2000-11-01-08.51.19.324816'*          
      *    MOVE 'BATCHJNM'             TO EDV072-LST-CHG-NAM(1).     *          
      *                                                              *          
      *    CALL 'EDV072' USING EDV072-COMMUNICATIONS-AREA.           *          
      *                                                              *          
      *     IF EDV072-STATUS-OKAY                                    *          
      *     THEN                                                     *          
      *          ..........                                          *          
      *     ELSE                                                     *          
      *          ..........                                          *          
      *                                                              *          
      *      NOTE: THIS EXAMPLE SHOWS A TYPICAL CALL FROM AN         *          
      *            APPLICATION PROGRAM. IN THIS CASE THE PROGRAMMER  *          
      *            IS REQUESTING AN 'INSERT' ACTION TO CREATE A NEW  *          
      *            TABLE ENTRY.                                      *          
      *                                                              *          
      *            THE PROGRAMMER SHOULD ALWAYS CHECK MODULE RESULT  *          
      *            CODE RETURNED FROM EDV072 TO VALIDATE THAT IT     *          
      *            WORKED PROPERLY (SEE THE COPYBOOK EDT072 FOR A    *          
      *            LIST OF ERROR CODES).                             *          
      *                                                              *          
      * - FOR CURSOR PROCESSING, USE CODE LIKE:                      *          
      *  > MOVE WS-CO-CD               TO EDV072-KEY-CO-CD.          *          
      *  > MOVE WS-SRC-SYS-ID          TO EDV072-KEY-SRCE-SYS-ID.    *          
      *  > MOVE WS-PARTNER-ID          TO EDV072-PARTNER-ID(1).      *          
      *   DATA IS RETURNED IN ORDER BY CO, SRCE-SYS-ID, SRCE-SYS-KEY-*          
      *   ID AND PARTNER.                                            *          
      *                                                              *
