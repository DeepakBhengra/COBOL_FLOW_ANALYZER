       P050-CHECK-PRICE-VARIANCE.                                               
      *                                                                         
      *   MAKE SURE WE COME IN TO THIS PARA FROM CALLING PROGRAM                
      *   ONLY FOR VALID PRODUCT LINES.                                         
      *   ONLY WHEN CUSTOMER ENTERED PRICE IS GREATER THAN ZEROES.              
      *   ASSUMPTION IS CUSTOMERS KNOW ON WHAT TYPE OF ORDERS THEY ARE          
      *   TRYING TO OVERRIDE THE PRICE.                                         
      *                                                                         
           IF (WS-ORWPRCVR-OVER-FLG     = 'D' OR                                
               WS-ORWPRCVR-OVER-FLG     = 'P' OR                                
               WS-ORWPRCVR-OVER-FLG     = 'M' OR                                
               WS-ORWPRCVR-UNDER-FLG    = 'D' OR                                
               WS-ORWPRCVR-UNDER-FLG    = 'P' OR                                
               WS-ORWPRCVR-UNDER-FLG    = 'M')                                  
               IF WS-ORWPRCVR-FREE-ITEM-LINE                                    
                  NEXT SENTENCE                                                 
               ELSE                                                             
                  PERFORM P051-PROCESS-PRICE-VARIANCE THRU P051-EXIT            
               END-IF                                                           
           ELSE                                                                 
               GO TO P050-EXIT                                                  
           END-IF.                                                              
      *                                                                         
      *  ANY ERROR FROM P051- PARA , WE SHOULD SKIP THE REST OF                 
      *  THE PROCESS AND GO OUT FROM HERE.                                      
      *                                                                         
           IF WS-ORWPRCVR-ERROR-ON                                              
              GO TO P050-EXIT                                                   
           END-IF.                                                              
      *                                                                         
      ***************************************************************           
      * OVERRIDE PRICE VARIANCE SWITCH IF NO VARIANCE IS SPECIFIED  *           
      ***************************************************************           
      *                                                                         
           IF (WS-ORWPRCVR-CHK-CUST-PRC-FLG = 'U' OR                            
               WS-ORWPRCVR-CHK-CUST-PRC-FLG = 'W' OR                            
               WS-ORWPRCVR-CHK-CUST-PRC-FLG = 'Y' OR                            
               WS-ORWPRCVR-CHK-CUST-PRC-FLG = 'C')                              
               IF WS-ORWPRCVR-OVER-FLG   = 'N'                                  
                  IF WS-ORWPRCVR-CUST-PRC > WS-ORWPRCVR-INGRAM-PRC              
                     MOVE 'Y'            TO WS-ORWPRCVR-PRC-VARIANCE-SW         
                  END-IF                                                        
               END-IF                                                           
               IF WS-ORWPRCVR-UNDER-FLG   = 'N'                                 
                  IF WS-ORWPRCVR-CUST-PRC < WS-ORWPRCVR-INGRAM-PRC              
                     MOVE 'Y'            TO WS-ORWPRCVR-PRC-VARIANCE-SW         
                  END-IF                                                        
               END-IF                                                           
           END-IF.                                                              
      *                                                                         
           IF WS-ORWPRCVR-FREE-ITEM-LINE                                        
              MOVE 'Y'                   TO WS-ORWPRCVR-PRC-VARIANCE-SW.        
      *

      *   TO HANDLE PER EACH CALLING PROGRAM'S NEEDS.

           PERFORM P052-CHECK-VARIANCE-ERR-WARN THRU P052-EXIT.

       P052-CHECK-VARIANCE-ERR-WARN.                                            
      *                                                                         
      ***************************************************************           
      ** CHECK PRICE VARIANCE LOGIC:                               **           
      ** 5 OPTIONS:                                                **           
      ** 'N' - DEFAULT / NO PRICE LOGIC. ACCEPT INGRAM PRICE       **           
      **                                                           **           
      ** +NOTE+ IF VARIANCE SETTINGS ARE BLANK,PRICE VARIANCE FLAG **           
      **        WILL BE SET TO ACCEPT VARIANCE.                    **           
      **                                                           **           
      ** 'Y' - CHECK-CUST-PRICE / USE IM PRICE. ACCEPT IF WITHIN   **           
      **       VARIANCE OTHERWISE REJECT.                          **           
      ** 'C' - CHECK-PRICE-ACCEPT / USE IM PRICE. ACCEPT PRICE IF  **           
      **       WITHIN VARIANCE OTHERWISE ACCEPT WITH WARNING.      **           
      ** 'U' - USE-CUST-PRICE / USE CUSTOMER PRICE. ACCEPT IF      **           
      **       WITHIN VARIANCE OTHERWISE REJECT                    **           
      ** 'W' - USE-CUST-PRICE-ACCEPT / USE CUSTOMER PRICE. ACCEPT  **           
      **       PRICE WITHIN VARIANCE OTHERWISE ACCEPT WITH WARNING **           
      ***************************************************************           
      *                                                                         
      ***************************************************************           
      **  'Y'  CHECK CUST PRICE, IF OUTSIDE OF VARIANCE REJECT.    **           
      ***************************************************************           
           IF WS-ORWPRCVR-CHK-CUST-PRC-FLG = 'Y'                                
              IF WS-ORWPRCVR-INGRAM-PRC = WS-ORWPRCVR-CUST-PRC                  
                 NEXT SENTENCE                                                  
              ELSE                                                              
                 IF WS-ORWPRCVR-INGRAM-PRC > WS-ORWPRCVR-CUST-PRC               
                    IF WS-ORWPRCVR-ACCEPT-VARIANCE                              
                       NEXT SENTENCE                                            
                    ELSE                                                        
                       SET WS-ORWPRCVR-ERROR-ON TO TRUE                         
                 ELSE                                                           
                    IF WS-ORWPRCVR-INGRAM-PRC < WS-ORWPRCVR-CUST-PRC            
                       IF WS-ORWPRCVR-ACCEPT-VARIANCE                           
                          NEXT SENTENCE                                         
                       ELSE                                                     
                          SET WS-ORWPRCVR-ERROR-ON TO TRUE.                     
      *                                                                         
      ***************************************************************           
      **  'C' CHECK CUST PRICE ACCEPT, WARN IF OUT OF VARIANCE     **           
      ***************************************************************           
      *                                                                         
           IF WS-ORWPRCVR-CHK-CUST-PRC-FLG = 'C'                                
              IF WS-ORWPRCVR-INGRAM-PRC = WS-ORWPRCVR-CUST-PRC                  
                  NEXT SENTENCE                                                 
              ELSE                                                              
                 IF WS-ORWPRCVR-INGRAM-PRC > WS-ORWPRCVR-CUST-PRC               
                    IF WS-ORWPRCVR-ACCEPT-VARIANCE                              
                       NEXT SENTENCE                                            
                    ELSE                                                        
                        SET WS-ORWPRCVR-WARNING-ON TO TRUE                      
               ELSE                                                             
                  IF WS-ORWPRCVR-INGRAM-PRC < WS-ORWPRCVR-CUST-PRC              
                     IF WS-ORWPRCVR-ACCEPT-VARIANCE                             
                        NEXT SENTENCE                                           
                     ELSE                                                       
                        SET WS-ORWPRCVR-WARNING-ON TO TRUE.                     
      *                                                                         
      ***************************************************************           
      **  'U'   USE CUST PRICE IF OUTSIDE OF VARIANCE REJECT       **           
      ***************************************************************           
      *                                                                         
           IF WS-ORWPRCVR-CHK-CUST-PRC-FLG = 'U'                                
              IF WS-ORWPRCVR-INGRAM-PRC = WS-ORWPRCVR-CUST-PRC                  
                   NEXT SENTENCE                                                
               ELSE                                                             
                  IF WS-ORWPRCVR-INGRAM-PRC > WS-ORWPRCVR-CUST-PRC              
                     IF WS-ORWPRCVR-ACCEPT-VARIANCE                             
                         NEXT SENTENCE                                          
                     ELSE                                                       
                        SET WS-ORWPRCVR-ERROR-ON TO TRUE                        
                  ELSE                                                          
                     IF WS-ORWPRCVR-INGRAM-PRC < WS-ORWPRCVR-CUST-PRC           
                        IF WS-ORWPRCVR-ACCEPT-VARIANCE                          
                           NEXT SENTENCE                                        
                        ELSE                                                    
                           SET WS-ORWPRCVR-ERROR-ON TO TRUE.                    
      *                                                                         
      ***************************************************************           
      **   'W' USE CUST PRICE ACCEPT, IF OUT OF VARIANCE WARN      **           
      ***************************************************************           
      *                                                                         
           IF WS-ORWPRCVR-CHK-CUST-PRC-FLG = 'W'                                
              IF WS-ORWPRCVR-INGRAM-PRC = WS-ORWPRCVR-CUST-PRC                  
                 NEXT SENTENCE                                                  
               ELSE                                                             
                  IF WS-ORWPRCVR-INGRAM-PRC > WS-ORWPRCVR-CUST-PRC              
                     IF WS-ORWPRCVR-ACCEPT-VARIANCE                             
                        NEXT SENTENCE                                           
                     ELSE                                                       
                        SET WS-ORWPRCVR-WARNING-ON TO TRUE                      
                   ELSE                                                         
                      IF WS-ORWPRCVR-INGRAM-PRC < WS-ORWPRCVR-CUST-PRC          
                         IF WS-ORWPRCVR-ACCEPT-VARIANCE                         
                            NEXT SENTENCE                                       
                         ELSE                                                   
                            SET WS-ORWPRCVR-WARNING-ON TO TRUE.                 
      *                                                                         
       P052-EXIT.                                                               
           EXIT.
