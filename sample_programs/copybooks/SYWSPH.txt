      *            SKU/EXPLAIN COPYBOOKS.                             *         
      *                                                               *         
      *            THE HEADER REQUEST DATA IS GENERALLY POPULATED     *         
      *            BY UTILITY COPYBOOK SYSPMH BEFORE INVOKING         *         
      *            THE ENGINE CONNECTOR/PRICING ENGINE.               *

          02  SYWSPH-HEADER-AREA.                                               
                                                                                
      ***************************************************************           
      *    THE STRATEGIC PRICING HEADER REQUEST AREA                            
      ***************************************************************           
                                                                                
            03  SYWSPH-HEADER-REQUEST-AREA.                                     
                                                                                
      *      (THE COMPANY CODE FOR THIS PRICING REQUEST)                        
              05 SYWSPH-COMPANY-CODE             PIC X(02).                     
                                                                                
      *      (THE CUSTOMER TO USE FOR ALL SKUS TO BE PRICED)                    
              05 SYWSPH-CUSTOMER-KEY.                                           
                 10 SYWSPH-CUST-CO-CD            PIC X(02).                     
                 10 SYWSPH-CUST-BR-CD            PIC X(02).                     
                 10 SYWSPH-CUST-NBR              PIC X(06).                     
                                                                                
      *      THESE FLAGS CONTROL FUNCTIONS FOR ALL INPUT SKUS                   
                                                                                
      *      (REQUESTS RETURN OF A FULL EXPLAIN PLAN IN COMM AREA)              
              05 SYWSPH-RETURN-EXPLAIN-FLAG      PIC X(01) VALUE 'N'.           
                 88 SYWSPH-RETURN-EXPLAIN        VALUE 'Y'.                     
                                                                                
      *      (REQUESTS EXPLAIN PLAN TO BE SAVED TO THE DATABASE)                
              05 SYWSPH-SAVE-EXPLAIN-FLAG        PIC X(01) VALUE 'N'.           
                 88 SYWSPH-SAVE-EXPLAIN          VALUE 'Y'.                     
                                                                                
      *      (REQUESTS RETURN OF PRICING AT EACH QUANTITY BREAK LEVEL)          
              05 SYWSPH-RETURN-QTYBRK-FLAG       PIC X(01) VALUE 'N'.           
                 88 SYWSPH-RETURN-QTYBRK         VALUE 'Y'.                     
                                                                                
      *      (INDICATOR THAT THIS PRICING REQUEST IS FOR AN RMA)                
              05 SYWSPH-RMA-FLAG                 PIC X(01) VALUE 'N'.           
                 88 SYWSPH-RMA                   VALUE 'Y'.                     
                                                                                
      *      (PRICING TRANSACTION OPERATOR ID, FOR EXPLAIN PLAN)                
              05  SYWSPH-OPER-ID                 PIC X(04).                     
                                                                                
      *      (THE EFFECTIVE DATE FOR ALL PRICING REQUESTS)                      
              05 SYWSPH-PRICE-DATE-YYDDD.                                       
                 10 SYWSPH-PRICE-DATE-YY         PIC X(02).                     
                 10 SYWSPH-PRICE-DATE-DDD        PIC X(03).                     
                                                                                
      *      (THE NUMBER OF INPUT SKUS IN THE REQUEST AREA)                     
              05  SYWSPH-NBR-OF-REQUESTS         PIC 9(02) VALUE ZERO.          
                                                                                
      *      (THE NUMBER OF PRICES EXPECTED IN THE RESPONSE AREA)               
              05  SYWSPH-NBR-OF-RESPONSES        PIC 9(02) VALUE ZERO.          
                                                                                
              05  SYWSPH-HDR-RQST-FILLER         PIC X(10) VALUE SPACES.AXR06213
                                                                                
      ***************************************************************           
      *    THE STRATEGIC PRICING HEADER REQUEST AREA                            
      ***************************************************************           
                                                                                
            03  SYWSPH-HEADER-RESPONSE-AREA.                                    
                                                                                
      *      (THE OVERALL STRATEGIC PRICING REQUEST STATUS CODE:)               
                                                                                
      *      (  SEVERE - SHOULD RESULT IN AN APPLICATION ABEND)                 
      *      (  ERRORS - SHOULD RESULT IN MESSAGE AND/OR SALES HOLD)            
      *      (  WARNINGS - CAN USUALLY BE IGNORED, A PRICE IS RETURNED)         
      *      (  UNDETERMINED - IS SET AT START OF ENGINE CONNECTOR)             
                                                                                
              05  SYWSPH-OVERALL-STATUS-CD       PIC X(01).                     
                  88 SYWSPH-STATUS-OK            VALUE SPACE.                   
                  88 SYWSPH-STATUS-SEVERE        VALUE 'S'.                     
                  88 SYWSPH-STATUS-ERROR         VALUE 'E'.                     
                  88 SYWSPH-STATUS-WARNING       VALUE 'W'.                     
                  88 SYWSPH-STATUS-UNDETERMINED  VALUE 'U'.                     
                                                                                
      *      (TEXT OR A CODE TO DESCRIBE THE OVERALL STATUS)                    
              05  SYWSPH-OVERALL-STATUS-TXT      PIC X(20) VALUE SPACES.        
                                                                                
      *      (THE TIMESTAMP OF THE PRICING ENGINE ERROR LOG)                    
              05  SYWSPH-RESPONSE-ERROR-TS       PIC X(26) VALUE SPACES.        
                                                                                
              05  SYWSPH-HDR-RSPN-FILLER         PIC X(10) VALUE SPACES.AXR06213
