      *    SYXDB2EC -- CICS DB2 UTILITY COPYBOOK.                               
      *                                                                         
      * !!!  THIS ROUTINE MUST BE TRANSLATED                                    
      *                                                                         
      *       FUNCTIONS: CHECK DB2 AVAILABILITY, FORMAT DB2 SQL ERRORS          
      *    NOTE: REQUIRES WORKING-STORAGE COPYBOOK SYWDB2ER.                    
      *                                                                         
      * A)    CHECK DB2 AVAILABILITY.                                           
      *                                                                         
      *       ALL CICS DB2 PROGRAMS MUST VERIFY THAT THE DB2 SYSTEM IS          
      *    AVAILABLE AT PROGRAM INITIATION.  THIS  PROCEDURAL COPYBOOK          
      *    WILL CALL PROGRAM SYU090 AND RETURN THE STATUS OF THE DB2            
      *    SYSTEM.                                                              
      *       THE STATUS IS CHECKED BY INTERROGATING THE WS-DB2-RESP            
      *    CONDITION NAMES:                                                     
      *                                                                         
      *            WS-DB2-AVAIL   - DB2 IS AVAILABLE;                           
      *            WS-DB2-UNAVAIL - DB2 IS NOT AVAILABLE.                       
      *                                                                         
      *       IF DB2 IS UNAVAILABLE, THEN THE STANDARD MESSAGE,                 
      *    WS-DB2-RESP-MSG, SHOULD DISPLAYED TO THE USER AND THE TASK           
      *    IMMEDIATELY TERMINATED.  THE TASK SHOULD NOT ABEND UNLESS            
      *    IT'S RUNNING IN THE BACKGROUND AND THERE IS NO METHOD OF             
      *    INFORMING THE USER OF DB2'S UNAVAILABILITY.                          
      *       NOTE, IF THE TASK IS STARTED, THEN THE DFHCOMMAREA IS             
      *    REPLACED BY RETRIEVED WORKING-STORAGE COMMAREA VARIABLE,             
      *    E.G., TC-SYXCOM.  CICS DB2 ERROR HANDLER:                            
      *                                                                         
      *                                                                         
      * B)   FORMAT DB2 SQL ERRORS.                                             
      *                                                                         
      *       EXECUTE THIS COPYBOOK BEFORE ABENDING THE TASK DUE TO A           
      *    SQL ERROR TO FORMAT THE SQL COMMUNICATION AREA INTO A TEXT           
      *    ERROR MESSAGE AND WRITE THE MESSAGE TO THE CICS LOG.                 
      *    THE FORMATTING PARAGRAPH CAN BE EXECUTED DIRECTLY WITHOUT            
      *    WRITING TO THE LOG IF DESIRED.                                       
      *                                                                         
      * !! NOTE: STARTED TASKS MUST REPLACE DFHCOMMAREA BY THE THE              
      * !!       APPROPRIATE WORKING-STORAGE COMMAREA VARIABLE, E.G.,           
      * !!       TC-SYXCOM.                                                     
      *                                                                         
      * PROGRAM EXAMPLE:                                                        
      *    .                                                                    
      * WORKING-STORAGE.                                                        
      *    COPY SYWDB2ER.                                                       
      *    .                                                                    
      *    .                                                                    
      * PROCEDURE DIVISION.                                                     
      *    .

      *    .                                                                    
      *    IF WS-DB2-UNAVAIL

      *       SET WS-ERROR-FOUND          TO  TRUE                              
      *       PERFORM 960-EXIT-ROUTINE.

      *    .                                                                    
      *    .

      *    .

      *       PERFORM 990-SQL-MESSAGE
