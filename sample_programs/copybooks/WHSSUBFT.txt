001100*-          ****   SUBSIDIZED FREIGHT LOGIC  ****                         
001200*-                                                                        
001300*-  OBJECTIVE: WHEN A WHSE RUNS OVER CAPACITY, ORDERS MAY BE              
001400*-  REDIRECTED AND SHIPPED FROM ANOTHER BRANCH.  INGRAM MAY PAY A         
001500*-  HIGHER FRT WITH ANOTHER CARRIER TO GET THE SHIPMENT TO THE            
001600*-  CUSTOMER WITHOUT DELAY.  SUBSIDZIED FREGHTING MAKES SURE A            
001700*-  CUSTOMER WILL PAY SAME FREIGHT CHARGES AS THEY WOULD HAVE IF          
001800*-  SHIPPED FROM ORIGINAL WHSE VIA ORIGINAL CARRIER.                      
001900*-                                                                        
002000*-  TO QUALIFY FOR SUBSIDIZED FREIGHTING FOLLOWING CONDITIONS             
002100*-  MUST BE MET:                                                          
002200*-   - SUBSIDIZED-SW IN TBXBRN2 MUST BE 'Y'                               
002300*-   - CUSTOMER-SHIP-FROM (CUA-SHIP-FROM) MUST BE SAME AS                 
002400*-     ORDER-SHIP-FROM.                                                   
002500*-                                                                        
002600*-  HOW IT WORKS?                                                         
002700*-  WHEN ORDER QUALIFIES FOR SUBSIDIZED FREIGHTING, WE READ THE           
002800*-  BASERATE VSAM FILE(R80D0200) FIRST BY CUSTOMER-NBR;  IF               
002900*-  NOT FOUND WE THEN READ R80D0200 BY ZIP CODE.  IF WE GET               
003000*-  SUCCESSFUL READ WE EXTRACT SHIP-FROM AND CARRIER-CODE                 
003100*-  FROM THE RECORD.  WE USE THESE 2 FIELDS TO RATE THE                   
003200*-  SHIPMENT FOR FREIGHT FOR WHAT CUSTOMER WILL PAY                       
003300*-  (ORSH-FRT-OUT-AMT, SM-FRT-CUS-PAYS).                                  
003400*-                                                                        
003500*-  WHAT WE NEED?                                                         
003600*-  - ORSHED AND ORSSHH IS AVAILABLE                                      
003700*-  - FOLLOWING FIELDS NEED TO BE DEFINED IN THE PGM:                     
003800*-    WS-SF               PIC X(2)                                        
003900*-    WS-CC               PIC X(2)                                        
004000*-    WS-R80-CUS-SW       PIC X(1)                                        
004100*-    WS-R802-REC-LENGTH  PIC S9(4) COMP.                                 
004200*-    WS-GENERIC-R802-KEYLENGTH                                           
004300*-    WS-WHERE-R80-SW     PIC X(1) VALUES ARE:                            
004400*-                             'B' FROM BILLING(MDP660/RWP620)            
004500*-                             ' ' FROM ORDER ENTRY SYSTEM
