                                          WS-NEXUS-ERROR-MESSAGE-CODE           
                                          WS-NEXUS-VALID-RESELLER-SW.           
                                                                                
      *  IF THIS IS A NEW ORDER START AT THE BEGINNING                          
      *  IF NOT WE ALREADY KNOW WE HAVE AN AGENCY ORDER CONTINUE                
      *  AT CARRIER CODE/SHIP FROM CHANGE LOGIC                                 
                                                                                
           IF NEXUS-NEW-ORDER                                                   
              CONTINUE                                                          
           ELSE                                                                 
              GO                       TO A1000-CC-SF-CHANGE.                   
                                                                                
      *    CHECK IF NEXUS IS ACTIVE

      *    IF IT IS NOT WE HAVE TO CHECK IF THE CUSTOMER IS TURNED ON           
      *    FOR EITHER NEXUS OR TO BE TAXED                                      
                                                                                
           IF NEXUS-ACTIVE                                                      
              CONTINUE                                                          
           ELSE                                                                 
              IF WS-NEXUS-CU-AGENCY-TAX                                         
                 MOVE 'Y'              TO WS-NEXUS-STATUS-SW                    
                 GO                    TO A1000-EXIT                            
              ELSE                                                              
                 IF WS-NEXUS-CU-AGENCY-CUSTOMER                                 
                    CONTINUE                                                    
                 ELSE                                                           
                    MOVE 'N'           TO WS-NEXUS-STATUS-SW                    
                    GO                 TO A1000-EXIT.                           
                                                                                
      *  ONLY FULFILLMENT ORDERS WITH A TAX CODE OF 'N' (DO NOT TAX)            
      *  SHOULD GO THRU THIS ROUTINE                                            
                                                                                
           IF WS-NEXUS-FULFILLMENT AND WS-NEXUS-TAX-CODE = 'N'                  
              CONTINUE                                                          
           ELSE                                                                 
              MOVE 'N'                 TO WS-NEXUS-STATUS-SW                    
              GO                       TO A1000-EXIT.

      * CHECK IF CUSTOMER WILL USE AGENT IN SHIP-TO STATE.  IF YES,     DGH99295

      *                                                                 DGH99295

           MOVE WS-NEXUS-BILL-TO-CUST-NBR                               DGH99295

                                                                        DGH99295

              GO TO A1000-CC-SF-CHANGE                                  DGH99295
           END-IF.                                                      DGH99295
                                                                        DGH99295

                                       THRU A2000-EXIT                          
              IF WS-NEXUS-STATUS-SW > SPACE                                     
                 GO                    TO A1000-EXIT.

              GO                       TO A1000-EXIT.

      *  ROUTINE AND PROCESS THE ORDER AS NORMAL                                
                                                                                
           MOVE WS-NEXUS-COMPANY       TO TB-NEXUS-COMPANY-CODE.                
           MOVE WS-NEXUS-SHIP-TO-STATE TO TB-NEXUS-STATE-CODE.                  
           CALL 'SYU510'               USING TB-NEXUS-TABLE-IA.                 
           IF TB-NEXUS-NORESP AND TB-NEXUS-TAX-SW = 'Y'                         
              CONTINUE                                                          
           ELSE                                                                 
              MOVE 'N'                 TO WS-NEXUS-STATUS-SW                    
              GO                       TO A1000-EXIT.

              CONTINUE

      *                                                                 DGH99295

           ELSE
